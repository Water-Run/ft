# 电子发展史

按厂商与产品线梳理电子软硬件的发展：每一代改了什么、为什么这样改、结果如何。

## 定位

| | |
|---|---|
| 讲什么 | 电子软硬件的发展：每一代产品改了什么、为什么这样改、结果如何 |
| 面向谁 | 关注硬件、想理清脉络的观众 |
| 怎么讲 | 深入、通俗易懂，不遗漏任何主要节点和它们的意义；指标口径全系列统一，每一项给出处并注明日期；统一视觉风格与节奏 |
| 每集多长 | 5–15 分钟 |
| 语言 | 中文与英文（缺省） |

**收录的范围**（片单顺序）：英特尔的三个时代、AMD 与 Ryzen、英伟达的三条显卡线、英特尔独显、高通、苹果自研芯片、Windows Server、Linux 内核，以及 Python、Lua、C、Java、C#、JavaScript 与 TypeScript 六门语言的发展史。

**与「编程语言哲学」系列的分界**：`../language-philosophy/` 讲一门语言的设计哲学——一条统一思想、为什么长成这样、在什么地方取舍；本系列讲同一门语言在时间线上的演进与版本转折。两边可以各有同一门语言，不要互相照搬。

## 共同约定
各集真正共享的约定记在这里，一项一行。视觉与配乐默认每集取自本集的讲解对象（经验规则 F16、F21），除非下面写明了策划者的决定；某一集的设计决定写在那一集的 README。要改约定先改这里。写法见 [系列](../docs/guides/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | `<厂商>——<产品线或时代>` |
| 结构（建议） | 时代背景与对手 → 逐代产品（架构、工艺、关键指标）→ 转折点 → 小结，引出下一段 |
| 衔接 | 同一厂商的各集按时间衔接；指标口径全系列统一（工艺、核心数、频率、功耗、发布时间），数据逐项给出处；时间线全系列共用一种画法；软件条目以版本号与发布时间代替工艺、核心数与频率 |
| 视觉与声音 | 策划者在「定位」里要求全系列统一的视觉风格与节奏：首集定下后写回这里。统一的是版式骨架、字体与节奏，各集的主画面仍取自本集的讲解对象（F16） |
