# 游戏物理学

每集讲一款游戏的物理模拟：它用什么方法逼近真实物理、换来了什么、放弃了什么。面向玩过这些游戏、想知道背后原理的观众。

## 定位

|---|---|

## 共同约定
各集真正共享的约定记在这里，一项一行。视觉与配乐默认每集取自本集的讲解对象（经验规则 F16、F21），除非下面写明了策划者的决定；某一集的设计决定写在那一集的 README。要改约定先改这里。写法见 [系列](../docs/guides/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | `<游戏名>物理学` |
| 结构 | 待首集确定 |
| 演示与取证 | 待首集确定；各集尽量用同一种可复现的实验（同一组碰撞、同一组初始条件），便于跨游戏对照 |
| 视觉 | 每集取自本集的讲解对象，不设系列统一的视觉与配乐（F16、F21） |
| 声音 | 待首集确定 |
