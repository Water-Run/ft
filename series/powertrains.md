# 动力总成

讲具体的发动机与变速器组合：结构、特性、演进与已知问题。

## 定位

| | |
|---|---|
| 讲什么 | 对汽车某一套特定的动力总成做详细解析：结构、匹配、特性、演进与已知问题 |
| 面向谁 | 对机械与汽车工程有兴趣的观众 |
| 怎么讲 | 一集只讲一套总成，讲透为止；参数、齿比、扭矩曲线等逐项给出处并注明数据来源与年份；全系列保持同一套数据口径 |
| 每集多长 | 3–7 分钟 |
| 语言 | 中文与英文（缺省） |

## 共同约定
各集真正共享的约定记在这里，一项一行。视觉与配乐默认每集取自本集的讲解对象（经验规则 F16、F21），除非下面写明了策划者的决定；某一集的设计决定写在那一集的 README。要改约定先改这里。写法见 [系列](../docs/guides/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | 待首集确定 |
| 结构（建议） | 组合与搭载车型 → 发动机 → 变速器 → 两者的匹配与实际表现 → 演进与已知问题 |
| 演示与取证 | 结构与参数以厂商技术资料与维修手册为准；故障与口碑类的说法须有可查的出处，区分设计原因与个案 |
| 视觉与声音 | 每集取自本集的讲解对象，不设系列统一的视觉与配乐（F16、F21） |
