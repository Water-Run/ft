# f(t)

![f(t)：旋转矢量随时间 t 画出流动的波形，依次演示运行、研究、修改、分发四项自由——自由视频，GPL-3.0-or-later](docs/media/ft.gif)

f(t) 用大语言模型协助制作科普与项目介绍视频。首要任务是把内容讲清楚：事实可靠，问题值得回答，叙事让观众跟得上。视觉、动画和声音为内容服务。

好的文档是制作的一部分：事实能追溯，文案能通读，取舍有理由，接手的人知道下一步做什么。这里公开视频的事实依据、文案、审稿记录、动画源码与制作工具。名字来自画面本身——任意一帧都是时间 t 的纯函数 f(t)。

成片为 1920×1080、60 帧/秒，发布在 [哔哩哔哩](https://space.bilibili.com/68328330) 与 [YouTube](https://www.youtube.com/@waterrun1978)。全部作品、制作状态、发布记录与评分见 **[片单](videos/README.md)**。

## 自由软件，自由视频

本项目对有权授权的源码、文档、视听作品采用 **GPL-3.0-or-later**。可以研究、修改、重新制作和再发布；分发受 GPL 覆盖的改编作品时，须履行相应的源码与许可义务。**本项目交给第三方制作的成果也必须开源**，交付可编辑材料、制作步骤及相应许可，不能只交 MP4。范围与交付方式见[开源交付与第三方许可](docs/reference/third-party.md)。

我们以**共产主义精神**组织协作：知识共享，生产资料公开，各尽所能，劳动如实署名，改进回到公共。工具、方法与失败的教训都应帮助后来者继续工作。详见[宗旨与原则](docs/principles.md)。

## 怎样做出来的

- **内容大于形式。** 事实、解释与叙事是作品的核心，视听表达为理解服务。先确定问题、取证并写好文案，确认后再铺开制作。流程见[制作周期](docs/process.md)。
- **画面是时间的纯函数。** 每部视频是一段以 t 为唯一输入的 HTML 动画。不用 CSS 动画、定时器与回调，任意一帧都能独立渲染，多个无头浏览器并行出帧，再由 ffmpeg 编码封装。
- **旁白决定时间。** 旁白逐句合成，取回每个词被读到的时刻；动画挂在「某句里某个词」上，文案一改，画面自动重排。同一套场景代码可以配多种语言。
- **事实有出处。** 画面与旁白里的每一项事实都记在该片的 `research/FACTS.md`；画面上的字节、数字、终端回显由脚本从实验数据生成。
- **人审定内容。** 文案经校对者明确确认后才配音；成片由策划者观看、试听并同意后交付。
- **自动检查辅助审查。** 工具检查版面、规格与确定性；内容是否可靠、叙事是否清楚、声音是否合适，仍要通过读稿、观看和试听判断。
- **声音由程序合成。** 配乐与音效不用外部素材，混音是确定性的。
- **分工按能力。** 人负责选题、审定与评价；准备方完成取证与文案，制作方负责视听制作。片尾记录实际贡献：人使用本人选定的公开署名，模型注明准确型号和版本。

## 仓库的结构

| 路径 | 层级 | 内容 |
|---|---|---|
| `docs/` | 仓库 | 宗旨、角色、制作周期、质量标准、经验规则、专题与参考，入口是 [文档地图](docs/README.md) |

## 快速开始

需要 Git 与 Node.js 22.12 或更新；看画面另需 Chrome 与字体。下面的命令不调用在线配音，也不改动任何影片：

```bash
npm ci
npm test
npm run check:repo
npm run assets -- --fetch
npm run doctor -- --visual
npm run smoke
```

新建一部视频：

```bash
node kit/tools/new.js <片> --title "中文标题" --title-en "English title"
node kit/tools/new.js <片> --series <系列>          # 系列里的一集；片单里已有的条目取片单的标题
```

之后的步骤见 [快速入门](docs/getting-started.md) 与 [制作周期](docs/process.md)。独立 fork 时，在 `kit/studio.json` 填写自己的策划、校对者与源码仓库。
