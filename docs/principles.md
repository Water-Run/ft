# 宗旨与原则

本仓库做两件事：用大语言模型制作讲清楚一件事的视频，并把怎样做、做成什么样、哪里做错了全部公开。下面几条是其余一切规则的来由；具体做法见各专题文档，这里不重复。

## 1. 自由软件，自由视频

本仓库是自由软件，以 GNU 通用公共许可证第 3 版或（由使用者选择的）任何更新的版本（GPL-3.0-or-later）发布，全文见 [LICENSE](../LICENSE)。

我们把每一部成片看作它源码的目标形式，就像程序的可执行文件之于源代码。一部片子的「完整对应源码」就是它在 `videos/` 下的目录——文案、事实依据、实验回显、场景代码、配乐脚本、审稿记录——连同 `kit/` 里把它变成成片的工具链。因此，成片同样是自由的：

- **运行**：任何人都可以为任何目的观看、放映、使用这些视频。
- **研究**：每一帧都是 `f(t)`，每一句旁白都有出处，每一个数字都能回到实验里重算。
- **修改**：改一句文案、换一种配色、纠正一个事实，然后重新出片。
- **分发**：原样或修改后再发布。修改后的版本须以同一许可公开它的源码。

成片里由第三方取得的部分——在线服务合成的语音、字体、讲解对象的商标与引用材料——各自适用自己的条款，见 [第三方组件与许可](reference/third-party.md)。

## 2. 共产主义

知识是人类共同的财富，不是私产。本仓库按这个立场组织：

- **生产资料公有。** 工具、引擎、模板、方法、踩过的坑、失败的成片和它们的复盘，全部公开，任何人都可以拿去用。
- **各尽所能。** 人负责选题、判断与审定；不同的模型按各自的长处承担取证、写稿、设计与制作。分工按能力，不按身份。
- **成果回到公共。** 一部片子里摸索出的做法，要提炼回 `kit/` 与 `docs/`，成为下一部片子的起点，而不是留在某一部片子的目录里。
- **劳动如实署名。** 谁做了什么就写什么：人写真名，模型写真实的型号。不虚列、不漏列、不拔高。

## 3. 制作原则

1. **画面是时间的纯函数。** 整部片子是 t 的函数，任意一帧都能独立算出。这使并行渲染、逐帧检查与任何人的复现成为可能。
2. **事实有出处。** 画面与旁白里的每一项事实都记在该片的 `research/FACTS.md`，能回到原始来源或实验。模型的记忆与搜索摘要不是依据。
3. **人审定内容。** 文案经策划者明确确认之后才配音；成片的好坏由人看过、听过才算数。工具只检查能检查的部分。
4. **如实记录。** 没做的写没做，没看的写没看。不补造确认，不把「流程改了」写成「成片修好了」。
5. **每部片子是它自己。** 视觉与声音取自讲解对象本身，不沿用上一部的样子；片子之间不互相抄。共通的东西只经由 `kit/` 与 `docs/` 传递。
6. **反馈变成规则。** 每一条反馈都要落到一条通用的规则上，让下一部片子不再犯同样的错；见 [经验规则](lessons.md)。
7. **控制熵。** 每一类信息只有一个存放处，分仓库、系列、视频三级；派生的内容由工具生成。见 [文档地图](README.md) 的「信息归属」。
