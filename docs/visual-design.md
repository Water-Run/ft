# 视觉设计

先设计，后实现。本文规定一部片子的视觉系统由哪些部分组成、怎样定下来、封面怎么做。成片必须达到的审美标准见 [standards.md](standards.md) 第 2 节。

参考现成产品时，在本片 README 的「视觉系统」一节记录来源、借鉴方法与本片的设计选择。文案、分镜、构图和动效按本片内容独立设计，不以换色、换字复刻现有成品；原创边界见 [standards.md](standards.md) 第 2 节。

## 1. 画面的基本尺寸

| 项 | 值 |
|---|---|
| 舞台 | 1920×1080，左上角为原点 |
| 字幕条 | 画面底部约 112px（y ≥ 968）。画面内容不要伸进去 |
| 版心边距 | 左右 120px 是常用值；`project.json` 的 `check.margin` 是文字离左右边缘的最小距离，模板设为 60 |
| 帧率 | 60 帧/秒 |

## 2. 视觉系统

独立视频从头建立自己的视觉系统，不沿用上一部的配色与部件。系列里的一集沿用该系列的视觉系统（[series.md](series.md)）。一套视觉系统写在 `src/css/style.css` 里，包括：

**颜色**。写成 `:root` 里的变量，场景代码只引用变量。一个主色、一个强调色，其余为中性色。弱化用同色的透明度，强调用反白块或字重，尽量不引入第三种颜色。每一种「字色压在底色上」的搭配都要满足对比度：56px 以下的字 4.5:1，56px 及以上 3:1；强调色常常只够用于大字，定色时先算一遍。

**字体**。可用的字体在 `assets/fonts/`，结构样式 `base.css` 已声明前四种：

| 样式里的名字 | 字体 | 用途 |
|---|---|---|
| `"Sans SC"` | Noto Sans SC，字重 100–900 | 中文正文与标题 |
| `"Serif SC"` | Noto Serif SC，字重 200–900 | 中文衬线标题 |
| `"Inter"` | Inter，字重 100–900 | 拉丁文字、数字 |
| `"Mono"` | JetBrains Mono，字重 100–800 | 代码与终端（连字已全局关闭） |
| 自行声明 | VT323 | 像素点阵字。在 `style.css` 里加 `@font-face { font-family: "Pixel"; src: url("/fonts/VT323.ttf"); }` |

不用系统字体，也不在字体栈里写 `sans-serif` 这类通用族名作后备：不同机器的渲染结果会不同，缺字体时也不会被发现。用到的每种字体都要列进 `config.js` 的 `ENGINE.fonts`，引擎在构建场景之前等它们载入。

**字号阶梯**。四到六级，对比要强。参考值（1080p）：

| 级别 | 字号 | 用途 |
|---|---|---|
| 片名、章节编号 | 170–620px | 一屏只有一个 |
| 主陈述 | 96–150px | 一屏的结论 |
| 次级陈述 | 60px | |
| 正文 | 38px 起 | |
| 注解、出处 | 28px 起 | 全片最小的字 |
| 终端里的命令 | 40–56px；回显小一级并变淡 | |

`check.min_font` 是总闸门允许的最小字号（按镜头缩放之后的实际大小算），模板设为 22。镜头拉远时字会变小，定字号时要按最远的机位算。

**图形语言**。选定少数几种图形，并规定各自的含义，全片不破例。例：luainstaller 一片只有圆与直线——圆是文件、模块、可执行文件，空心表示「还没有」，实心表示「有」，外环表示目录包。

**部件**。终端、代码块、文件、表格、时间轴这些反复出现的东西，各定一种样式。终端不画窗框；命令比回显大一级；一屏只放一组命令。带样式的部件不在工具包里，每部片子按自己的视觉系统写，可参考已有视频的 `src/js/parts.js` 或 `components.js`。

**常驻元素**。章节卡、角标、进度条写在 `config.js` 的 `chrome()` 里，放在常驻层 `#hud`。右上角有常驻元素时，每一屏的右上角都要留出来；带慢推的屏还要按放大后的尺寸留。

**字幕**。样式在 `style.css` 的 `#caption span`；不同语言可分别设字号（`<html>` 上带有语言类名，例如 `.en #caption span`）。场景的底色有深有浅时，字幕颜色要跟着换（参考 luainstaller 一片 `config.js` 的 `after()`）。

## 3. 关键帧

动笔写场景之前，先做两到三个方向的关键帧，每个方向两到三张静帧：一张标题、一张信息最密的画面、一张图解。

- 关键帧可以是一个静态页面（放在 `src/design/` 下，用 `look.js --url` 看），也可以是先写出来的一两个场景。
- 按 [standards.md](standards.md) 逐条自评：单看这一帧是否是完成度高的平面作品；有没有「要避开的」那些特征；缩小一半后是否仍读得清。
- 选定之后在进度说明里给出选定的关键帧与理由；方向可以随时调整。
- 选定方向后做一段代表性动画，覆盖信息最密的画面、关键揭示与一次转场；核对运动中的构图、可读性、缓动、落点与接缝。静帧与动态都达到 [standards.md](standards.md) 第 2、3 节的要求，再铺开制作。
- 委托制作时，选定的关键帧与一段示范场景留在 `src/design/`，作为受托模型照着写的范例。

## 4. 检查版面

```bash
node kit/tools/look.js <视频> a3 c5              # 文字描述 + 截图（shots/）
node kit/tools/look.js <视频> a3:0.5 --brief     # a3 进行到一半；只列问题
node kit/tools/sheets.js <视频> at o5 a6 h4 --cols 3 --rows 1   # 拼成一张总览
node kit/tools/sheets.js <视频> every 4          # 沿全片每 4 秒一帧
node kit/tools/margin.js <视频>                  # 按像素量每句画面的外接范围，列出贴边的句子
```

`look.js` 的输出每行是一个此刻可见的元素：种类、位置与大小（已含镜头变换）、字号、颜色、文字、类名。不能看图时以它为准判断版面：两个元素的范围是否错开、主体是否在版心之内、最大的字是否是最小的字的四倍以上、强调色此刻用了几处。读法见 [tools.md](tools.md)。

风格规则可以交给总闸门查：`project.json` 的 `check.style` 里打开 `flat`（不用阴影、渐变、模糊）、`no_radius`（不用圆角）、`palette`（源码里只许出现这些颜色）、`fonts`（只许用这些字体）、`no_emoji`。写法见 [tools.md](tools.md)。

## 5. 封面

每种语言两版，由 `src/cover.html` 生成：

| 版式 | 页面尺寸 | 产物 |
|---|---|---|
| 16:9 | 1920×1080（`?r=169`） | `out/cover-<语言>-16x9.jpg` 与 3840×2160 的 PNG |
| 4:3 | 1600×1200（`?r=43`） | `out/cover-<语言>-4x3.jpg` 与 3200×2400 的 PNG |

- 封面单独设计，不用视频截帧。4:3 是重新排布，不是裁切。
- 缩到 360 像素宽仍要读得清主标题。主标题的字高约为画面高度的五分之一。
- 底部约 15% 不放文字：投稿平台会在那里叠时长与标题。
- 与正片用同一套颜色与字体；可以直接取正片标题画面的构图。
- 页面约定：`?lang=` 切换语言；字体载入完成后置 `document.body.dataset.ready = '1'`，工具等到这个标记才截图。
- 出图前先用 `look.js --url "/cover.html?r=169&lang=zh" --size 1920x1080` 查版面。

## 6. 版面上常见的问题

- 会转动、会长出标签的图（轨道上的卫星及其名字），按「转到最不利位置时」留边，不能只看某一帧。
- 整行反白时，用「负外边距抵掉内边距」的做法，否则被反白的那一行会比上下行多出一截缩进。
- 被补间的元素不要靠 CSS `transform` 定位或居中，补间会覆盖它；用 `left / top` 定位，需要居中就包一层 flex 容器。
- 放在画布右侧（一屏之外）的文字块可用宽度为负，会被挤成一字一行：`world` 里的文字默认不换行，要换行就显式写 `<br>` 或给块定宽。
- 推近到很大的倍数时，叠在上面的清晰层要盖住它淡入那一刻镜头能看到的全部范围，否则会露出一道边。

更多见 [pitfalls.md](pitfalls.md)。
