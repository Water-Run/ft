# 脚本与配音

旁白脚本是一部片子的时间骨架：每句旁白逐句合成，合成结果给出每句的时长与每个词被读到的时刻，画面上的所有动作都挂在这些时刻上。本文规定脚本的写法、多语言的做法、读法的处理与核对办法。

## 1. 脚本文件

脚本在 `src/js/script.js`，浏览器与工具共用同一份。结构：

```js
const RAW = [
  {
    id: 'open', chap: null, lead: 0.8, tail: 0.4,
    cues: [
      ['o1', { zh: '一个 Lua 脚本，写完了', en: 'A Lua script. Finished.' }, { gap: 0.55 }],
      ['o2', { zh: '要交给别人运行，对方得先装好 Lua', en: 'To run it, the other person needs Lua installed,' }, { gap: 0.3 }],
      ['oT', null, { pause: 3.0 }],
    ],
  },
  {
    id: 'what', chap: ['02', { zh: '它做什么', en: 'What it does' }], lead: 2.3, tail: 0.5,
    cues: [ … ],
  },
];
```

**场景**

| 字段 | 含义 |
|---|---|
| `id` | 场景号。场景文件里用 `scene('<id>', …)` 实现它 |
| `chap` | `[编号, 标题]`，有章节卡；`null` 表示没有 |
| `lead` | 场景开始到第一句旁白之间的时间，章节卡就放在这段时间里（常用 2.3 秒；没有章节卡时 0.8–1.0 秒） |
| `tail` | 最后一句旁白结束到场景结束之间的留白（缺省 0.6 秒） |

**cue**：`[句号, 字幕, 选项]`

| 部分 | 含义 |
|---|---|
| 句号 | 全片唯一。习惯上每个场景用一个字母作前缀：`o1`、`a3`、`h17` |
| 字幕 | 显示在画面底部的文本。`*词*` 表示强调。多语言时写成 `{ zh: '…', en: '…' }` |
| `tts` | 送去合成的文本。缺省时由字幕按读法表换算（见第 4 节）。也可写成 `{ zh, en }` |
| `gap` | 这句结束到下一句开始的停顿，缺省 0.3 秒。可写成 `{ zh, en }` |
| `pause` | 这一条不是旁白，而是纯画面的停顿（标题、转场），值为秒数；字幕写 `null` |

## 2. 写法

- 一句一件事。每句不超过一行字幕：中文不超过 26 个字宽（汉字算 1，拉丁字母与数字算 0.5），英文不超过 44 个字宽（约 88 个字符）。上限在 `project.json` 的 `check.caption_width` 里按语言设定；`scan.js` 另按渲染结果量字幕的实际宽度。
- 单句不超过 6 秒（`check.max_cue_seconds`）。更长的句子拆成两句。
- 语速：已成片的三部，中文各章的平均语速在每秒 4.3–4.9 字之间，没有超过每秒 6.3 字的句子；英文各章平均每秒 2.5–3.2 词。`node kit/tools/stats.js <视频>` 逐章给出语速、最快句、最长句，并列出过快的句子（中文超过每秒 6.3 字，英文超过每秒 3.6 词；阈值可在 `check.pace` 里按语言改）与过短的停顿。
- 停顿是节奏的一部分：结论句之后留 0.6 秒以上；一个场景里换话题的地方留 0.7–1.1 秒；镜头要移到下一站时，把上一句的 `gap` 留够镜头走完的时间。
- 开头 5 秒要有钩子：一个具体的现象、一个反差、一个问题。
- 语体见 [standards.md](standards.md) 第 5 节。

## 3. 多语言

除另有说明外，每部片子出中文与英文两个版本（`project.json` 的 `languages`）。

- 以中文为底本：先定稿中文，再按中文的语气与用词译成其他语言。译文写成该语言里自然、克制的句子，不逐字对译。新增第三种语言时同样从中文译，不从英文转译。
- 各语言的句号一一对应、数量相同；时长各不相同，时间轴各自排布。
- 语言的选择：浏览器取地址里的 `?lang=`，工具取 `--lang`；`script.js` 里的 `pick()` 把 `{ zh, en }` 取成当前语言的值。
- 画面里的文字用 `tr('中文', 'English')`；时间点用 `T('c5', { zh: '读', en: 'reads' })` 按语言取词。场景代码只有一套。
- 版面先按较长的那种语言排（通常是英文），再看另一种。
- 每种语言各有一份 `src/js/timing.<语言>.js`、`audio/<语言>/`、`out/<语言>/`，成片文件名带语言。
- 只做一种语言的片子把 `languages` 写成 `["zh"]`，脚本里的字幕直接写字符串。

## 4. 读法

字幕写产品的正式拼写；读法统一放在 `script.js` 的 `SAY` 表里，按语言各一组正则替换，长词写在前面：

```js
const SAY = {
  zh: [ [/luainstaller/g, 'lua installer'], [/月相/g, '月象'], [/SHA-256/g, 'S H A 二五六'] ],
  en: [ [/luainstaller/g, 'Lua installer'], [/\bluai\b/g, 'lua-eye'], [/\bELF\b/g, 'E L F'] ],
};
```

已知的规律：

- 连写的英文专名常被读错或被逐字母拼读。`luainstaller` 会被读成「low installer」，拆成 `lua installer` 才对；`MyISAM` 要写成 `My ISAM`。
- 多音字换成同音的单音字：数据「行」会被读成 xíng，合成文本里换成「航」（「执行」「进行」除外）；「月相」换成「月象」。
- 缩写要逐字母读的，字母之间加空格：`S R lua`、`L G P L`。
- 版本号、选项名写成读得出来的样子：`5.1 到 5.5` → `五点一到五点五`；`--file` → `file 选项`（英文 `dash dash file`）。

读法拿不准时先试再定：

```bash
node kit/tools/tts_probe.js <视频> --lang zh "luainstaller 是一个工具" "lua installer 是一个工具"
```

它把每种写法各合成一句，用语音识别回听，并列出词边界。音频留在 `audio/probe/`，可以直接试听。

## 5. 合成

```bash
node kit/tools/tts.js <视频>            # 全部语言
node kit/tools/tts.js <视频> --lang en  # 只做英文
```

- 用 edge-tts 逐句合成，取回每句的时长与词边界，写成 `src/js/timing.<语言>.js`（入库），并打印各场景的起止时刻与总长。需要联网。
- 音色与语速在 `project.json` 的 `voices`、`rates` 里按语言设定。缺省音色：中文 `zh-CN-YunyangNeural`，英文 `en-US-AndrewNeural`。语速写成 `"+5%"`、`"-4%"`。Yunyang 在 −4% 时约每秒 5.3 字（含标点的合成文本口径）。
- 以（音色、语速、文本）的哈希做缓存，放在 `audio/<语言>/`（不入库）。改了哪句只重新合成哪句；脚本里删掉的句子，音频一并清掉。
- 改了 `script.js` 的任何文本之后必须重新运行 `tts.js`，否则时间线用的是旧时长。
- 换一台没有缓存的机器时，`tts.js` 会重新合成全部句子。在线服务的输出可能随时间变化，时长随之略有不同；画面的时间点都由 `T()` 推出，会自动跟着走，但已渲染的画面与已混好的声音要重做。

## 6. 时间点：T()

```js
T('c5')              // c5 这句开始的时刻
T('c5', '读')        // c5 里「读」字被读到的时刻
T('c5', '读', -0.2)  // 同上，再提前 0.2 秒
T('c5', { zh: '读', en: 'reads' })   // 多语言
Tend('c5')           // c5 结束的时刻
```

- 词在**合成文本**里找（引擎先用 `SAY` 表把词换成读法再找），取首次出现的位置。同一句里一个词出现两次、想取第二个时，换一个只出现一次的相邻词。
- 查某句可用的词与各自的时刻：`node kit/tools/timeline.js <视频> c5`。
- 找不到词时页面日志里有 `word not in cue`，`scan.js` 把它报为 `PAGE` 错误。
- 时间点一律写成 `T(句号, 词)` 的形式，不写死秒数：旁白改了，画面才能自动跟着走。

## 7. 回听

混音之后：

```bash
node kit/tools/asr.js <视频>
```

用 Whisper 转写仅旁白的音轨，逐句并排打印「合成文本」与「听到的文本」。读法：

- 同音错字、英文大小写与拼写偏差属于识别误差，不算错。
- 要看的是：有没有漏词、有没有把英文单词逐字母拼读、数字读法是否正确、多音字是否读对。
- 读错了就改 `SAY` 表或该句的 `tts`，重新合成、重新混音、再回听。

## 8. 音色与响度

不同音色的峰值与均值之比差别很大（Yunyang 与 Andrew 相差约 7 dB）。混音按响度对齐旁白，不按峰值归一；成片增益按实测响度计算。两种语言的成片因此响度一致。
