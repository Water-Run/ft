## 本项目的第三方制作

接受本项目的委托、协作或投稿时，制作方应明确接受以下交付条件；费用、使用的人或模型、制作工具均不改变这些条件：

1. 对有权授权的交付源码、文档和作品采用 GPL-3.0-or-later；保留原作者、许可证和变更说明。
2. 同时交付**可编辑、可继续制作的材料**与成片。只提供 MP4、截图、压扁的图片或无法取得的私有工程不算完整交付。
3. 公开与该成片版本对应的源码及必要材料，给出直达链接、版本标识和制作步骤；原仓库主页链接不能代替第三方实际修改后的源码。
4. 加入外部字体、图片、音频、模型服务输出或引用材料时，列明来源、许可、使用与再分发依据。权利未解决时先取得许可、替换或移除，再交付。

这是本项目的协作与发布要求。分发受 GPL 覆盖的原作品或改编作品，还须依 GPL 第 4–6 节履行通知、许可和对应源码义务；不得再加禁止修改、禁止商业使用等与 GPL 冲突的限制。

## 对应源码与发布材料

源码是适合继续修改作品的形式。交付时在本片 README「交付」集中记录下列项目，避免另建重复台账：

| 项目 | 应提供或记录 |
|---|---|
| 本片可编辑内容 | 文案、场景、样式、原创图形与声音的源文件；外部编辑器的原始工程也要交付 |
| 制作与证据 | 对应版本的 `kit/`、依赖锁、数据与配乐生成脚本、必要的公开证据、构建步骤和环境版本 |
| 必要音画材料 | 复现该版所需且有权分发的原始素材、原配音与时序；不能只留下会变化或需付费重新合成的调用方式 |
| 对应版本 | 源码地址及提交号或发布标签；成片文件名与哈希；外置材料地址与校验和 |
| 权利与署名 | GPL 版本、真实贡献名单、第三方材料的许可证及授权依据；修改版标明改动 |

Git 忽略生成物是版本管理约定，不是省略必要交付材料的理由。大文件可放公开的发布附件或其他稳定下载位置，并在 README 给出对应关系。凭据、私人数据与无权再分发的第三方源码不进入公开包。清理本机生成物前，按[归档流程](../guides/release.md#6-归档校验后执行清理)保存并验证。

## GPL 的适用边界

GPL 可用于软件以外的作品；本项目明确许可自己的文案与视听内容。**仅运行 GPL 工具，不会自动使独立创作的全部输出成为 GPL 作品**；输出是否受覆盖取决于其内容和权利关系。私下修改也不等于必须向全世界发布；GPL 的分发义务面向所分发的受覆盖作品及其接收者。本项目选择公开发布源码，并将其作为上述协作条件。

依据：[GPL 第 1、2、5、6 节](https://www.gnu.org/licenses/gpl-3.0.html)、[GNU FAQ：工具输出](https://www.gnu.org/licenses/gpl-faq.en.html#WhatCaseIsOutputGPL)、[私人修改与公开源码](https://www.gnu.org/licenses/gpl-faq.en.html#GPLRequireSourcePostedPublic)。说明用于解释项目做法，不改写 LICENSE 或扩大其法律范围。

## 字体

清单与校验和在 `kit/assets.json`，由 `node kit/tools/assets.js --fetch` 从 Google Fonts 仓库的固定提交下载。五种字体都以 SIL Open Font License 1.1 发布：

| 字体 | 来源 |
|---|---|
| Noto Sans SC、Noto Serif SC | Google Fonts `ofl/notosanssc`、`ofl/notoserifsc` |
| Inter | Google Fonts `ofl/inter` |
| JetBrains Mono | Google Fonts `ofl/jetbrainsmono` |
| VT323 | Google Fonts `ofl/vt323` |

成片里嵌入的是字体渲染出的画面，不是字体文件。

## 在线语音服务

旁白由在线语音合成服务生成：edge-tts 调用的微软语音（`zh-CN-YunyangNeural`、`en-US-AndrewNeural` 等），或 MiniMax 的语音合成（`speech-2.8-hd`，按 `project.json` 的 `tts` 选用）。音色属于各自的服务。服务的可用性、输出与使用条款由服务方决定；发布含有这些语音的成片之前，应自行确认其使用条款是否允许相应的用途。

## 取证时引用的材料

各片使用的第三方源码、安装包和引用材料，在本片 `research/FACTS.md` 或 `research/MATERIALS.md` 记录版本、来源、许可与用途；大体积原件放在不入库的 `research/_src/`。公开证据或画面需要复制其中内容时，按实际材料的许可与适用权利核对。共享文档不再维护易过时的逐片材料清单。
