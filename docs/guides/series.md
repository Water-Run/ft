# 系列

系列是一组共享定位与少数约定的片子，例如「数据库引擎」「XX 秒速通」。系列只是归类，不是目录：每一集都在 `videos/<片>/`，和独立的片子同一级；属于哪个系列记在片单 `videos/catalog.json` 条目的 `series` 字段。

## 1. 系列共享什么，不共享什么

系列的识别性来自讲法与结构，不来自同一套配色和曲子。经验规则 F21：每部片子的视觉系统、配乐与讲法为它自己重新建立；系列只共享系列说明里**明确写下**的约定。

| 通常共享 | 通常不共享 |
|---|---|
| 标题的格式 | 配色、字体、部件、图形语言（取自本集的讲解对象，F16） |
| 时长规则（定长或区间） | 配乐的曲子、速度、动机（为本集写，F06） |
| 语言（例如数据库引擎只做中文） | 动作与换场方式 |
| 结构骨架、贯穿全系列的问题（每集仍独立可懂，F10） | 上一集的例子、术语表、事实记录 |
| 常驻元素的位置与做法（例如速通的秒尺与剩余秒数） | 上一集的取舍与踩坑记录（在那一集的 README 里） |

策划者要求某个系列统一视觉时，照录原话写进系列说明，那就是这个系列的约定。

## 2. 系列说明

每个系列一份 `series/<系列>.md`，只写这个系列的事：

- **定位**：讲什么、面向谁、怎么讲、每集多长（定长还是区间）、语言。
- **共同约定**：各集真正共享的东西，一项一行。
- **分集**：由 `catalog.js` 按片单生成，不手改。

不写某一集的设计决定、试过的方向、交付记录或问题——那些写在那一集的 README 里。要改约定，先改系列说明，再动下一集。

## 3. 片单里的系列字段

```json
{ "slug": "database-engines", "title": { "zh": "数据库引擎" }, "languages": ["zh"] }
{ "slug": "in-seconds", "title": { "zh": "XX 秒速通" }, "starter": "in-seconds" }
```

| 字段 | 含义 |
|---|---|
| `languages` | 本系列各集的缺省语言。不写则为中英双语。某一集要不同，写在那一集的条目上 |
| `starter` | 新建分集时盖在模板之上的起点代码，位于 `kit/starters/<名字>/` |
| `sections` | 建议的栏目（`id`、`zh`、`en`）。`new.js` 按它生成章节草稿；`check.js` 只提示缺了哪些、先后是否不同，不判不通过 |

语言的取法：条目自己的 `languages` ＞ 系列的 `languages` ＞ 中英双语。

## 4. 起点代码

`kit/starters/<名字>/` 放一个系列各集都要用的**机制**：例如速通系列的定长时间线（每场一个开始时刻，旁白超出定点即报错）、常驻的秒尺与剩余秒数、节拍网格。`new.js` 新建分集时把它盖在通用模板之上（只取 `src/`、`project.json`、`tools/`）。

- 起点是新建时拷入的一份，不是共享引用：之后改起点不影响已经做完的各集。
- 起点里的样式表、配乐脚本、部件只是能跑的占位。正式制作时按本集的对象重做；`check.js` 提示与起点完全相同的文件，新版目录交付前不通过。
- 起点只放机制，不放某一集的配置、校对、事实或生成物；`new.js` 会拒绝。
- 某一集做出了值得全系列沿用的机制，提炼回起点；只适合那一集的部件留在那一集。

## 5. 新建一集、新开一个系列

```bash
node kit/tools/new.js <片> --series <系列>                                    # 片单里已有的条目，标题取自片单
node kit/tools/new.js <首集> --series <新系列> --series-title "系列的中文名" --title "首集标题"
```

片单里没有这个系列时，`new.js` 会登记它，`catalog.js` 生成系列说明的骨架。首集制作中逐项确定定位与共同约定，写回系列说明。计划中的各集可以先在片单里登记标题（手改 `videos/catalog.json` 后运行 `node kit/tools/catalog.js`）。

## 6. 集与集之间

- 每集只靠它自己就能看懂（F10）：直接提出本章的问题，必要的背景在本片补齐，不用「上一期第几个问题」导航。
- 引用另一集时说出那一集的标题；跨集比较的数据在本集的 FACTS 里重新给出处，不依赖另一集的记录。
- 上一集被更正或收窄的说法，本集按更正后的说法讲，并在本集 README 写明。
- 开工前可以看前面几集的成片，弄清术语与度量口径；不要照抄它们的视觉、配乐与部件（F21）。
