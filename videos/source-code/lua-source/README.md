## 设计

**融合方案（2026-11-16，按策划者意见）。** 第 1 版比较过三种解释方法（A 手册：源码占主画面；B 机房：运行状态做成立体实物；C 三层对照：源码、指令、状态并排），策划者要求「有机融合」，于是不再三选一，按每段内容决定形式：A 的 Lua 形象管身份与源码（标志常驻、蓝色常规字重标题、❖、真实源码摘录用淡紫标出正在讲的行）；B 的立体管空间与状态（源码地图、栈格与调用帧、表的节点、字节布局、两份 lua_State）；C 的对照管对应关系（记号 → 编译器记下的 → 指令；指令 → 格子；代码行 → 节点）。每帧右上角一张小地图点亮本章涉及的文件，章节卡标出所属部分，帮助在长片里定位。对照表在 `src/design/fusion.json`，关键帧在 `src/design/fusion.html?f=1..7`。三个独立方向的页面已删除。

**视觉系统（取自讲解对象，F16）。** 颜色全部来自 lua.org 的 lua.css 与标志程序（FACTS P03、P04）：白底；标志与标题的蓝 #000080 表示 Lua 一侧（Lua 源码、值、函数、堆对象）；正文黑表示 C 一侧（C 源码、C 栈、宿主）；链接悬停的淡紫 #D0D0FF 只表示「此刻正在讲的那一处」；激活链接的红 #FF0000 只表示控制流（pc、跳转、抛出），只用于线条与 56px 以上的字。标题按 lua.org 用常规字重的蓝字，小节标记用官网 h2 前的 ❖。图形语言：方格是一个值格，圆（取标志的圆）是一个堆对象，蓝线是指针，标志环绕线那样的灰色虚线只表示「循环」（解释循环、回收的一轮）。字体用仓库已有的 Inter、Noto Sans SC、JetBrains Mono（关闭连字，源码照原样显示）。对比度：#707070 注解字压白底 4.95:1，蓝字压淡紫 10.8:1。

**3D 的用法。** 只在需要表达空间关系的地方用：源码分层的地图、栈格与堆对象的相对位置、数组的字节布局（5.4 与 5.5 对照）。行保持水平的斜二测，避免等距投影把长行斜出画面（关键帧第一版就出现过）。

**Lua 标志。** 策划者同意片中出现 Lua 标志（2026-11-15）。按 lua.org/images 的许可使用：不冒称原作、不改动（只许改环绕文字，本片不改）、等比缩放，注明设计者 Alexandre Nakonechnyj。`tools/gen_logo.py` 按官方 PostScript 程序的几何与颜色生成 `src/img/lua-logo.svg`，「Lua」字样用度量与 Helvetica 相同的 TeX Gyre Heros（GUST 字体许可）排出；与官方 128px GIF 叠合比对无重影。常驻于左上角，片尾注明设计者与许可。标志的权利属于 Lua.org，不随本仓库的 GPL 授出（docs/reference/third-party.md「商标」）。

**声音。** 音色先从第 2 版 5 男 5 女候选中点选 `Chinese (Mandarin)_Warm_Bestie`，同日策划者改定为 Harness 一期的 `Chinese (Mandarin)_Crisp_Girl`、语速 1.15（见「简报」）；下面关于 Warm_Bestie 音量的记录只作历史。策划者提醒「音量偏小」：试听段的整合响度 -32.4 LUFS，比其余候选的中位数（约 -23 LUFS）低约 9 dB。处理：混音按缺省的 `voice_norm: rms` 把整条旁白对齐到 -21 dB，试听段需要补 10.9 dB，补后峰值 0.54，不触发 0.7 的软限幅；全片合成后用 ebur128 再测一次，并在交付时核对成片响度（-16 LUFS ± 1.5）。读法上 pcall 写作「P call」，仍待人耳确认。配乐一首「月下」（`tools/music.py`）：按「月、简洁、巴西」的优先级，72 拍/分，D 大调 maj9、m11、maj7#11 和弦与暗长混响，钟片四音下行动机；只有铺底、尼龙弦式拨弦（Karplus–Strong）、低音、钟片四层，不用鼓；拨弦按波萨诺瓦的切分扫弦。制作方没有听过任何音频，只做了 Whisper 回听与数值检查（分段响度、频段占比、峰值因子、频谱图），听感由策划者判断。

**封面。** `src/cover.html`，16:9（1920×1080）与 4:3（1600×1200）两版，单独设计、不用视频截帧：左上官方标志与「Lua 5.5.1　34 个 C 文件　32202 行」，主标题「Lua源码全解析」用标志的蓝、500 字重（16:9 字号 228px，约为画面高度的五分之一），下方两层核心源码的斜二测方块（与片中源码地图同一画法，统一为蓝色）。底部 15% 留空。`look.js` 两版无问题，制作方看过截图与 360 像素宽的缩略图，主标题可读。正式出图用 `covers.js`，它与配音一样要等文案确认后才能运行。
