### intro · 01 认识 Lua

1993 年，里约热内卢天主教大学的 Tecgraf 组里 已经有人在用最早的 Lua 了 Lua 是葡萄牙语，意思是月亮 它不是哪几个词的缩写，就叫月亮 标志上，一颗行星，一颗绕着它的月亮 还有一圈虚线画成的轨道 在画这个标志的 PostScript 程序里 行星叫 planet，月亮叫 moon 连那圈虚线也有名字，叫 orbit Lua 自己没有「主程序」这回事 它总要住在别的程序里 那个程序把它当作 C 库链接进来 加载 Lua 脚本，调用其中的函数，再把结果取回去 手册把这样的程序叫作*宿主* 官网说，它常用在嵌入式系统和游戏里 发布包里自带一个宿主，命令行程序 lua 它的源码 lua.c 只有 794 行 另一个程序 luac，能把编译出的指令一条条列出来 整个发布包，压缩以后不到 400 KB 语言的全部实现、标准库和参考手册，都装在里面

### lex · 04 读入与记号

### code · 06 指令

那条 ADD 0 1 3，在内存里是一个 32 位整数 十六进制写作 03010022 这样编好的一条条指令，叫*字节码* 最低 7 位是操作码，说明做什么 其余 25 位，按不同的格式切成几个操作数 最常用的格式是 iABC A 占 8 位，接着是 1 位的标志 k，它的意思随指令而定 然后 B 和 C，各占 8 位 拆开 03010022 最低 7 位是十六进制 22，十进制 34 34 是 ADD 的操作码 往上 8 位是 A，等于 0 k 是 0，B 是 1，C 是 3 另一种格式 iABx，把 k、B、C 并成一个 17 位的操作数 用来放常量的编号 isJ 把 25 位全部留给跳转的距离 5.5.1 一共定义了 85 种操作码 A、B、C 多半直接是寄存器的编号 一条指令自己写明了读哪几格、结果写到哪一格 这样设计的虚拟机，叫*寄存器式虚拟机* Lua 并非生来如此 把 a = b + c 交给 Lua 4.0 的编译器 得到的是另一种指令 先把 b 和 c 依次压上栈顶 ADD 不带任何操作数 它弹出栈顶的两个值相加，再把结果压回去 最后弹出来，存进 a 操作数默认都在栈顶，这叫*栈式虚拟机* 5.0 以后，同一句只要一条带三个操作数的 ADD 指令少了，每条指令带的东西多了 到了 5.4，ADD 后面又跟上一条 MMBIN 两个数字相加，ADD 自己做完，跳过它 碰上不是数字的操作数，执行才落到 MMBIN 由它去查，加法有没有别的规定

### vm · 07 解释循环
