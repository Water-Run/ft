本片决定不讲的材料及理由：

- 缸径与冲程：只在官方培训资料 SSP 511／733 里给出，本轮未取得可复查的一手副本（镜像站不可用），按 `docs/guides/research.md` 标待核实，不进片中（`research/FACTS.md`「尚待核实」）。
- 「evo3」这一代号：全部一手材料里都没出现过（2020-12 官方写 `EA 211 TSI evo`，2022-07 写 `1.5 TSI evo2`，2025-08 仍是 evo2），不写（FACTS 02-3、尚待核实）。
- 可变气门升程：EA211 的一手资料里没有升程可变；厂家的可变气门技术是可变气门正时与 ACT／ACTplus 停缸。不把别的家族的用词套过来（FACTS 03-2、03-3）。
- 各品牌的逐个车型对照表：官方只给了「MQB 首个集团车型是第三代奥迪 A3」和「不同品牌同线生产」两句可查的话，本片不点具体品牌车型（FACTS 02-6、05-6）。
- 天然气 TGI 变体：属家族成员但本片名词预算不够，只留在事实表（FACTS 04-6）。
- EA211 累计产量：官方只有单厂年产与 MQB 累计产量，没有家族累计口径，不写（FACTS 05-7、05-8）。
- 变速箱、DSG、混动箱与具体动力总成匹配：属相邻「动力总成」系列（`series/powertrains.md/` 的《EA211 DJS+DQ200 经典动力总成》）的内容；本片讲家族，不讲一套具体总成，两集不互相照搬。
- 已知故障与口碑：属动力总成那一集的范围，本片不引。
