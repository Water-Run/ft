# 叙事主线

2026-10-11。这是面向主流观众的一条讲述顺序。依据在 `FACTS.md`。这里不规定秒数、画面、配乐或卡片。

2026-10-18 采用这条顺序写中文稿。重点是 harness 是什么、循环怎么走。历史和五家实现只支撑这两件事。Claude Code 的那一个差别，按 2026-10-18 的文档写成：程序的规则决定能不能执行；同一天的文档也允许改由分类器审查，不能说成总是询问使用者。

观众不需要知道模型怎么训练，也不需要认识仓库、协议或某一家的安装步骤。看完应能把一件事说清楚：聊天的是模型，真正去碰文件和命令的是它外面的程序。

## 顺序

1. **模型自己动不了手。** 没有外面的程序时，它只能把话说完。文件、命令和网页都在它够不着的地方。依据是 Claude Code 文档里「没有工具就只有文本」。

2. **外面有一层程序，负责做。** 模型提出要做什么。程序去执行，把结果送回来，再问一次，直到模型不再要工具。现在常把这一层叫做 harness。这个词在 2026 年的 Claude Code 文档和 Codex 的文章里都指这一层，不是某一种产品的专名。谁最先使用这个词，材料不够，不讲。

3. **这件事比这个名字早。** 2022 年的 ReAct 把过程写成想、做、看结果。2023 年 6 月 13 日，模型开始交出一份结构清楚的函数请求；公告没有写谁把结果送回去，但已经写明：工具带回的内容可能反过来指使模型，所以碰得到外界的动作要人确认。对观众，这一步只说明：先有「开口要工具」，后有一整层程序。

4. **同一圈，包法不同。** 不排名，不用一家代替所有人。每家只承担一个观众能看见的差别：
   - Claude Code：模型选择工具，程序决定这一下准不准做。规则写在程序里，写在提示里不算数。2026-10-18 的文档里，规则按拒绝、询问、允许取第一条；也可以改由分类器审查，而不是逐次询问。
   - Codex：程序执行命令，并且可以加沙箱。2025 年 4 月 16 日的说明和 2026 年的说明用的开关不一样，讲的时候要带着日期，不能说成从来如此。
   - OpenCode：同一个程序里有两种用法。`build` 是默认的、可以改东西的；`plan` 是用来看的，跑命令前会问。观众由此看到：差别可以是模式，不必是另一个软件。
   - Pi：它把自己写成一个可以改小、也可以加东西的 harness，默认不做子代理，也没有自己的许可墙。它以启动它的那个人的权限运行，并不在每次动手前询问。源码里的工具也不只是读、写、改、命令这四个。
   - DeepSeek Harness：这一层拆成可替换的插件。小的那一档只留 shell 和当前目录，没有文件编辑工具。观众由此看到：同一套程序可以只留最早的那一点能力。

5. **收在观众能用的一句上。** 换一个更会说话的模型，并不自动换掉那层程序。那层程序决定它碰得着什么、做之前问不问你、你能不能看见它做了什么。三家把「一轮」数得不一样，所以不要用某一个秒数或步数去比较它们谁转得更多。

## 不放进这条线的材料

训练方法，安装命令，基准分数，词是谁发明的，2021 年那个同名 Codex 模型，以及「Go 版 OpenCode 后来变成了 Crush」。这些要么超出这条线，要么 `FACTS.md` 标明不能用。

OpenCode 从 2025 年 4 月 30 日的 Go 程序，变成后来仓库里的另一套代码，这条可以作为「同一个名字下面的程序换过」的事实，但不是主线必须走完的历史。主线只用它今天 README 里的 build 和 plan。
