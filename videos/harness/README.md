## 开工反馈应用

反馈版本：`docs/lessons.json`，版本 2026-10-18，F01–F12。相关复盘：`docs/log/reviews/2026-10-09.md` 中 OpenClaw / Hermes、OpenClaw / OpenCode v2 的叙事问题，以及 `docs/log/feedback.md` 第 3 节。

目标观众已有的知识：知道对话模型会回答问题。不需要知道训练、仓库、协议或某一家的安装步骤。

看完应能回答的一个核心问题：模型自己只能把话说完。外面的程序提出工具、执行、把结果送回，直到模型不再要工具。这层程序就是 harness。

逐段怎样推进、最后回答什么：

| 场景 | 预估起点 | 推进 | 本段答案 |
|---|---|---|---|
| open | 0:00 | 先给现象，再给名字 | 没有外面的程序，模型够不着文件和命令。负责执行的那层叫 harness，不是某一家的专名 |
| loop | 0:20 | 按文档把同一个循环走完 | 送出记录，模型返回文字或工具请求，程序执行并把输出送回，直到不再要工具。问不问不属于这个循环 |
| past | 0:58.5 | 只留两笔能撑住先后的历史 | 循环早于这个词。2022 年 ReAct 里，想不改变外界，做才带来观察。2023-06-13 的公告只写到交出函数请求，并要求有后果的动作由人确认 |
| houses | 1:33.6 | 五家各一个差别 | 程序决定碰得着什么、问不问。各家的规则、沙箱、模式和最小工具集不同，不排名 |
