# 汽车平台

逐个讲解整车平台：它规定了什么、哪些可以变、基于它造出了哪些车，以及这种做法的得失。

## 定位

| | |
|---|---|
| 讲什么 | 各个汽车平台的历史、发展、架构与特性：它规定了什么、哪些可以变、造出了哪些车 |
| 面向谁 | 认得车、想理解平台这套做法的观众 |
| 怎么讲 | 详细的说明，架构图与代号逐项给出处；统一视觉风格与节奏 |
| 每集多长 | 5–15 分钟 |
| 语言 | 中文与英文（缺省） |

## 共同约定
各集真正共享的约定记在这里，一项一行。视觉与配乐默认每集取自本集的讲解对象（经验规则 F16、F21），除非下面写明了策划者的决定；某一集的设计决定写在那一集的 README。要改约定先改这里。写法见 [系列](../../docs/guides/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | `<厂商>——<平台或时代>` |
| 结构（建议） | 背景（上一代的问题）→ 平台的定义（固定的硬点与可变的尺寸）→ 模块与动力总成的搭配 → 代表车型 → 得失与后继 |
| 衔接 | 同一厂商的各集按时间衔接；尺寸与硬点用同一种侧视剖面画法，便于跨平台比较。与「动力总成」系列涉及同一批车型时互相引用 |
| 视觉与声音 | 按本页定位保持系列视觉风格与节奏；首集将实际共用的版式与节奏约定写回这里。各集的图形取自自身对象、配乐按内容设计，不把上一集的具体方案当作模板（F16、F21）。 |
