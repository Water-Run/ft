- **配乐**：WaterRun 2026-10-26：「配乐也是学术派的, 体现Pg的庞大严谨史诗」。本集重写为一首**赋格**：D 小调，庄重的慢主题，管风琴与弦乐的音色；第二声部在属音上回答，对题随后，一声部一声部按规矩进入——最讲规矩的作曲形式对应「学院派的正统」。和内容呼应：写新版本时多进一个声部、织体变厚，VACUUM 时声部依次退出回到干净的主题，WAL 是持续的低音踏板，崩溃时全体停一拍、重启后从主题重新进入；章节高潮全声部合奏，加低沉的重击；开场与片尾用完整的合唱式和声。和 MyISAM 的终端电子乐、InnoDB 的「两个事务」区分开。先做约一分钟的小样，和男声候选放在同一个试听页给 WaterRun。听过赋格小样后，WaterRun：「配乐更体现计算机 数据库海量数据的井井有条 复杂有序的计算机系统」——R2「数据的秩序」改为一层层精确的音型：D 小调，112 拍/分，十六分音符网格；拨弦琶音是一路数据流，木琴同一音型错开三个十六分音符跟进（卡农），低音八分音符脉冲像 WAL 的心跳；赋格主题留在弦乐上作学院派的线索；高潮全部合奏，崩溃停一拍后从一支声部重新建起，结尾各声部依次退出（像 VACUUM），落在 D 大调（`tools/music_sketch.py` 在提交 e3f8a3e 时的版本）。听过 R2，WaterRun：「BGM节奏太快 太吵杂 没有体现Pg的沉稳 节奏和前两期差不多」——R3「沉稳」慢下来、空下来：56 拍/分（前两集用过 66 与 76、84、100，R2 是 112），每小节一个和弦，同时最多四层；秩序靠一支从头到尾不变的八分音符音型（柔音钢琴），不再用十六分音符；音色去掉刺耳的高次泛音，不用钟、定音鼓和崩溃急停；赋格主题由大提琴低声奏出，时值放大一倍，最后落在 D 大调（`tools/music_sketch.py`）。WaterRun 2026-10-27：「可以」——配乐定为 R3，实现阶段按它写成随场景走的 `tools/music.py`。WaterRun 又要「BGM+配音的1.5分钟demo」：`tools/demo_mix.py` 用选定的男声读一段试听文字（只为试听，没有取证，不进成片），配乐按本片 audio 电平垫在下面，混法同 `kit/tools/mix.py`。
- **整片配乐**（`tools/music.py`，2026-10-27）：R3 的速度、音色与音型不变。每章从章节卡落下（thud）起重新数小节，章首一声低八度的钢琴；各章用自己的四和弦循环，讲机制的章节有那支八分音符音型，历史与取舍的前半只留铺底和钢片琴；赋格主题在开场、历史、页内、改、删、五个问题几章轮流由大提琴与小提琴奏出；崩溃不急停，讲到「强行停掉」时音型停下、只留一口气的长和弦，讲重放时回来；最后的问题停在 A 上，片尾落到 D 大调。混音实测：旁白 −21 dB，配乐在旁白之下约 −40 dB、无旁白处约 −32 dB。
