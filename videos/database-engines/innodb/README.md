## 设计

**选定**（WaterRun 2026-10-24 在试听页里选，原话见简报）：配音「成熟女性」（MiniMax `female-chengshu-jingpin`，语速 1.2；系列一集男一集女，本集女声）；视觉「手册架构图与泳道的有机结合」；配乐「两个事务」（`tools/music.py` 的 `commit`：A 小调到 C 大调，76 拍/分，两支拨弦一问一答，乐句收在主音上响一下铃，像一次提交）。

**视觉系统**（`src/css/style.css`、`src/js/parts.js`）：
- 底色、面板、页的青色取自 MySQL 9.7 手册的 InnoDB 架构图：内存（In-Memory）与磁盘（On-Disk）两大块，页是一个个小方块，粗箭头尾巴带两道竖杠。
- 人与事务按时间走在泳道上：每个人一条泳道，从左往右是时间，竖线是此刻。
- 颜色只表示三种状态：实心蓝（MySQL 标志的蓝）是已提交，砖红斜纹是未提交，砖红虚框是在等；挂锁是行锁。全片不换义。
- 左上角常驻「InnoDB · MySQL 9.7.4」身份标识。章节卡：暖灰底、深青章节号，下面一排页小方块随停留一格格填满。

**各章主画面**：

| 章 | 主画面 | 怎样随旁白推进 |

## 取证计划

环境：MySQL 9.7.4 LTS 官方 Windows 版，原生运行在临时数据目录（与 MyISAM 一集的补充实测同一版本），实验脚本放 `research/lab/`。旧版的 9.7.2 实验由「GPT-6（型号未记录）」完成，型号确认不了，新版不沿用其数据，只把 `research/r8/` 当线索与出处索引。

| 项 | 要得到什么 |
|---|---|
| 整棵树 | users（4096 行）与大表的主键树、姓名索引树：每层几页、页号、每页多少条记录、键的范围、页的填充（直接按页解析 `.ibd`） |
| 一行 | Alice 那一行在叶页里的字节：记录头、主键、事务号、回滚指针、各列 |
| 增 | 插入落在哪一页；页满分裂前后的页与层级（已做：`07_more.py`，FACTS G1–G4） |
| 查 | 主键查与姓名查的访问路径（回表）；缓冲池命中与读盘 |
| 改 | 原地改行、行头的事务号与回滚指针变化、undo 里的旧值 |
| 删 | 删除标记；有读视图挡着时记录仍在页里，提交后 purge 移除 |
| 事务 | 回滚；可重复读与读已提交下的快照读；锁定读 |
| 锁 | 记录锁、间隙锁挡住插入（幻影）、死锁检测与回滚 |
| 出错 | 强行结束进程后重启：已提交的在、未提交的回滚；redo、检查点与 doublewrite 的配置实查 |
| 史实 | Innobase、2005 年 Oracle 收购、2010 年 5.5.5 成为默认引擎等，沿 `research/r8/` 的出处重新核对 |
