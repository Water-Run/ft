## 读法

字幕写正式拼写，读法放在 `src/js/script.js` 的 `SAY` 表里。

| 写法 | 读法 | 原因 |
|---|---|---|
| InnoDB、MyISAM、MySQL、Innobase | Inno D B、My ISAM、My S Q L、Inno base | 连写时被吞音或读错 |
| ACID、MVCC、OLTP、LSN、SQL | 逐个字母 | 同上 |
| ARIES | Aries | 论文名按单词读 |
| `.ibd`、`.MYD`、`.MYI` | 点 I B D 等 | |
| 1196、1205、1213 | 一一九六、一二零五、一二一三 | 错误码逐位读 |
| 数据的「行」（一行、整行、行级锁） | 送去合成时换成同音的「航」；执行、进行、串行、银行不换 | 回听时「整行」「一行」「行级锁」被读成 xíng |
