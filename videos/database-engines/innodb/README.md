## 设计

**选定**（WaterRun 2026-10-24 在试听页里选，原话见简报）：配音「成熟女性」（MiniMax `female-chengshu-jingpin`，语速 1.2；系列一集男一集女，本集女声）；视觉「手册架构图与泳道的有机结合」；配乐「两个事务」（`tools/music.py` 的 `commit`：A 小调到 C 大调，76 拍/分，两支拨弦一问一答，乐句收在主音上响一下铃，像一次提交）。

**封面**（`src/cover.html`）：用正片自己的视觉——暖灰底、白框、手册架构图的磁盘分区，泳道上的砖红斜纹（未提交）与实心蓝（已提交）；不沿用 PART 1 那条立体字节线（那是 MyISAM「线性」的写照）。左边 PART 2 标签、问句、大标题「事务性与现代化 / InnoDB」和两种状态的图例；右边是一笔事务：START TRANSACTION、UPDATE 之后，Alice 这一行的 43 还没提交，只有两条路——COMMIT，43 生效，写进 redo 就不会丢；ROLLBACK，从 undo 取回 42。下面是磁盘上的 redo 日志与 undo。42、43、日志序号都是实测。

**视觉系统**（`src/css/style.css`、`src/js/parts.js`）：
- 底色、面板、页的青色取自 MySQL 9.7 手册的 InnoDB 架构图：内存（In-Memory）与磁盘（On-Disk）两大块，页是一个个小方块，粗箭头尾巴带两道竖杠。
- 人与事务按时间走在泳道上：每个人一条泳道，从左往右是时间，竖线是此刻。
- 颜色只表示三种状态：实心蓝（MySQL 标志的蓝）是已提交，砖红斜纹是未提交，砖红虚框是在等；挂锁是行锁。全片不换义。
- 左上角常驻「InnoDB · MySQL 9.7.4」身份标识。章节卡：暖灰底、深青章节号，下面一排页小方块随停留一格格填满。
