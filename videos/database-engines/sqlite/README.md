### 取舍

- 不进主讲：页内字节布局（Alice 这一行 10 字节的记录头与值，F01）、溢出页链（F02，画面可标出长文本续页）、删除与空闲页复用、VACUUM（D01、D02）。前两项属「直接深入到页内」，后者在 9 分钟里与主线关系较远。
- 不讲：逐条虚拟机指令、WAL 校验和、完整文件头、编译选项、WAL 下的崩溃恢复（未实测）。
- 页大小用 1024 字节是为让 4096 行长出三层；旁白在 b35–b36 用默认 4096 字节只需两层交代这一点。

## 交接

主实验显式用 **1024 字节页**；同批 users 与索引另做 **4096 字节页**对照。页号、层数、分裂阈值仅属于本样本，不是引擎常数。

原始 SQL 和完整回显为每组 out_*.txt，可用数据为 out_*.json。第三方源码、工具包在忽略的 research/_src/；二进制数据库在忽略的 out/lab/。

尚未做：函数调用轨迹、真实断电、设备持久性、吞吐与时延、操作系统冷缓存、WAL 模式的崩溃恢复、WITHOUT ROWID 等扩展。08 记录的是 SQLite 向操作系统发出的读请求，不观测系统缓存与设备。

## 复现

`python videos/database-engines/sqlite/research/lab/run_all.py` 重跑 01–08；`python videos/database-engines/sqlite/tools/gen_data.py` 从实测 JSON 生成 `src/js/data.js`，并核对关键数字。

Python 3.10 或更新；首次联网取得经 SHA3-256 核对的官方工具包与源码。其他系统可指定 FT_SQLITE 为同版本命令行程序；当前只在 Windows 实测。脚本不调用 Python 自带 SQLite。每次在本片 out/lab/ 新建目录，不覆盖、删除已有数据库。

公开证据不带个人路径、主机名或凭据。WAL 的盐值与回滚日志随机校验种子会变化，相关二进制哈希不承诺跨次相同；稳定的整树测绘数据可逐字节比较。
