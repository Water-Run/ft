## 设计

视觉与声音取自 MyISAM 与 MySQL 5.x 时代自身的材料（F16）；画面不逐句复述旁白：版本差异（如 8.0 起 `.frm` 变成 `.sdi`）、字节细节、出处可以只在画面上出现。旧版记下的问题（暗色面板、渐变与半透明圆角、二十多处静止、低频过重的铺底、依赖播放历史的画面）都不再出现。动画演示过程本身（F23）：表锁时间轴与播放头、空位链、页的分裂都是连续的过程，不做逐条出字的版面。

**封面**（[src/cover.html](src/cover.html)）：WaterRun（2026-10-24）：「封面要画的更立体高级, 体现MyISAM存储本质上是线性的特点.」画面是 `users.MYD` 的 128 个真实字节（5.5.62 快照，刚写入 8 行、尚未删除）排成一条立体的线：一格一个字节，一行十六格，alice 那一行用橙色，之后的行用两种蓝绿交替，一路伸向消失点；线的尽头立着橙色光标，标 `0080`，即下一行写入的位置。WaterRun 又要求「封面元素稍微再多点就行」「体现MyISAM质感」，于是加了 MyISAM 自己的东西：上方悬着 `users.MYI` 的主键页，8 个索引项（键 1–8，值是行号 0–7），每项一根线落到它指向的行首，即索引只存行的位置；左下角是一张表的三个文件与 5.5.62 实测大小（`users.frm` 8,614 B、`users.MYD` 128 B、`users.MYI` 3,072 B）；右下标「第 N 行 = N × 16」。透视由页面自己投影（相机与消失点分开控制），各面平涂，不用渐变与半透明。

MySQL 海豚标志与两种主色的出处见 [research/MATERIALS.md](research/MATERIALS.md)；标志只用来指明所讲的对象（D2 关键帧用过，D1 正片暂不用），权利属于所有者，不随 GPL 授出。

**正片的视觉系统**（[src/css/style.css](src/css/style.css)、[src/js/parts.js](src/js/parts.js)）：黑底、JetBrains Mono 与思源黑体；顶上一条实心的会话栏（`mysql> myisam_demo.users`，右边是三个文件，当前讲到的文件标橙），底下一条实心的字幕栏，镜头推近时画面从两条栏下面过去。颜色的含义全片不换：橙 = 正在讲的那一个（alice、焦点、光标）；蓝绿 = 结构与指针；红 = 删除与出错；灰 = 残留与次要；绿只用于年龄字段。章节卡是在终端里敲出的一行注释（`-- 03`）加标题。终端里整行输出瞬间出现，只有敲的命令用打字机。平涂，不用阴影、渐变、模糊与半透明。
