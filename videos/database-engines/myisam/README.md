# 一个数据库引擎是如何实现的？——从 MyISAM 说起

数据库引擎系列第一集的新版：给写过 SQL、没有读过引擎源码的观众，用 MyISAM 引入「数据库引擎」，沿 Alice 与几个同伴的同一段经历，讲清数据怎样落到文件、怎样被找到、怎样被改和删，以及没有事务时同时读写与中途出错会怎样。约 10 分钟，仅中文。[系列说明与全系列文案主线](../README.md)；技术事实唯一来源为 [research/FACTS.md](research/FACTS.md)。

### 第 1 稿为什么不行（复盘）

把「讲故事」理解成了修辞和数字：用比喻包装、塞进大量实测数字（4096、114744、360、155/3940），把全系列统一的人物与 4096 行数据硬套到开场一集，丢掉了旧版从 8 行小表起步、层层递进的结构，也丢掉了「5.5 之前」的时代感；还让每句旁白都点名画面上的字节，画面被台本绑死。教训写进了[全系列文案主线](../README.md#叙事原则)的「叙事原则」。

### 取证

文案的事实依据仍是旧版的 [FACTS](research/FACTS.md)：MySQL 5.5.62 上的实测快照与同版源码（`research/lab/`）。2026-10-24 在 MySQL 9.7.4 LTS 上做的九组补充实测在 [research/lab/v97/](research/lab/v97/FACTS_9.7.md)（`run_all.py` 可重跑），用于画面注解（`.sdi`、引擎列表）和制作参考。
