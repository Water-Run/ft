### 第 4 稿（2026-11-26）

起因：策划者 2026-11-26 会话原话「Redis的稿件感觉还是不好. MyISAM的开场很吸引人, 层层递进, Redis的结尾收场也应该如此, 有质感的升华. 大幅度对抗迭代」。

MyISAM 开场好在哪里（诘问的尺子）：h1 一个具体的瞬间；h2 「这一瞬间」接住 h1，提出问题；h3 把问题拆成两个具体的小问；h4 给回答它的部件起名；h5–h7 「足够简单」→「简单到每一个字节都可以摊开」，每一句接住上一句的最后一个词往前走，最后落在一样看得见的东西（字节）上。没有一句是总结，也没有一句是口号。

第 3 稿终章的毛病：先把七个引擎各点一句名（z4–z11），再讲「磁盘记得住但慢、内存快但会忘」（全片第四次说），再说「各自停在不同的地方」，再用系列片名问一遍、用五个动词答一遍（与 08 章重复），最后落在「这些事都已经在那一瞬间里发生过了」。一路是归纳与断言，没有一个观众能看见的东西在往前走；「升华」是被说出来的。

### 第 3 稿（2026-11-25）

起因：策划者 2026-11-25 会话原话「文案不好, 继续迭代优化, 消除AI味道. 主要是宏观的一个好的主线设计, 收尾升华, 自然.」

第 2 稿的毛病不在单句，在宏观：各章是按「增查改删」排下来的清单，章与章之间靠路标句和问句硬接；Redis 为什么要这样设计，没有一根线串起来。终章先逐引擎点名、再两轮对照，读起来像总结报告，「拿一样东西，换另一样」之类的话是格言腔。

第 3 稿的主线：**内存快，但会忘，也装不下太多；磁盘慢，但记得住。** 前六集把数据放在磁盘上、内存做缓存；Redis 反过来。全片每一章都是这一个选择的后果：

| 章 | 它从主线推出了什么 |
|---|---|
| 开场 | 五微秒没碰磁盘 → 内存快而会忘、磁盘慢而记得 → Redis 反过来 → 换来快，也欠下「会忘」「装不下」两笔账；从 Alice 这一个键说起 |
| 01 一张哈希表 | 不用迁就磁盘的页，按键找值可以更直接 |
| 02 增 | 内存贵，值挤成 27 个字节 |
| 03 查 | 直达很快；代价是只认键，怎么找得存的时候想好 |
| 04 改 | 原地改一个字节，不留旧版本 → Bob 正在读怎么办 |
| 05 事务与并发 | 一个线程一条条来（数据在内存里，几微秒一条，排队也来得及）→ 慢一条全都等 → 所以连哈希表长大也切成小步 → 一件事两条命令：MULTI/EXEC、WATCH、不回滚 |
| 06 出错怎么办 | 第一笔账「会忘」：快照、命令日志、两次 kill -9 → 兜了一圈还是回到磁盘，办法和前几集差不多 |
| 07 删 | 第二笔账「装不下」：删除、过期、上限 |
| 08 五个问题 | 系列约定 |
| 09 一瞬间 | 回到第一集的那一瞬间 → 七集七种回答（各一句，平铺）→ 页、树、缓存、日志大多在对付同一对难处：磁盘记得住但慢，内存快但会忘 → Redis 躲开了慢，为了记得住又回到磁盘 → 七个引擎各停在不同的地方 → Alice 的年龄只是一个字节，它在文件里、在树的叶子上、在一列数字里，这一次在内存的一个桶里 → 一个数据库引擎是如何实现的：就是这一个字节的五个问题 → 下一次一条查询在眨眼间返回，这些事都已经在那一瞬间里发生过了 |

消除「AI 味」的改法：
- 删掉路标句与自问自答的过渡（「原因在下一章」「答案很简单：一个一个来」「这叫……」后接定义的连串）；问句只留真会冒出来的那几个（c5、d8）。
- 删掉冒号揭示与对仗（「拿一样东西，换另一样」「同一个字节，七种改法」「改的那一刻，要是有人正在读」）；终章不再两轮逐引擎对照，只走一轮、各一句平铺。
- 数字只留观众要记住的：五微秒、27 个字节、42 → 43、两万、33287。0.24 微秒、16 万次、DEL 的内存数、保存点的六个数都只上画面或删去。
- 口语化、短句、主语清楚：「42 就这样被盖掉，没有留下旧的一版」「实验里 Alice 落空了一次，重读一遍，才得到 44」。
- 结尾不喊口号：落在一样具体的东西（Alice 年龄那一个字节）上，再回到第一集开场那一瞬间（仿 MyISAM 一集 h1–h2 与结尾 n10 的写法）。

顺手修掉的问题：开场的问题清单少了「删」（改为两笔账 + 从一个键说起，五个问题留到 08 章）；01「这些都可以不要」说过头（Redis 也有有序的结构，改为「按键找一个值，可以更直接」）；05「把要花时间的事都切成小块」说过头（改为「尽量不让哪一条命令做太久」）；06「快照和日志」与前几集「快照」（读快照）同词异义（改为「隔一阵子存一份全量，中间的改动记进日志」）；o8「内存只拿来做缓存」对 ClickHouse 一集没有依据（改「多半」，FACTS S08）。

预估：工具估算 12 分 18 秒（第 2 稿 14 分 3 秒）；按前两集实测语速折算约 11 分钟。字幕 169 条，字宽都不超过 26，单条估算都不超过 6 秒。新句逐句对过 FACTS（「第 3 稿新出现或改了说法的句子」一节，新增 S08）。
