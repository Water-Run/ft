本片用约 6 分 30 秒讲清汽车轻量化：重量到底影响车辆的哪些表现，减重怎么做到、代价是什么，以及电动化带来的新问题。中文与英文两个版本。内容只依据车企官方技术资料、美国 EPA / NHTSA / CARB 委托的研究及其同行评审；不引用厂商宣传口径而不写清条件。

制作流程与标准见仓库的 `docs/`；片中每一句陈述的出处见 `research/FACTS.md`。

目标观众已有的知识：普通驾驶者与汽车爱好者；知道马力、油耗、百公里加速、安全气囊这些日常词；不要求懂材料力学，也不要求知道任何一款轻量化车型的名字。

看完应能回答的一个核心问题：把车做轻，到底换来了什么、又要付出什么，为什么在电动车上这件事变复杂了？

逐章怎样推进问题、最后回答什么：

| 章 | 提出的问题 | 本章给出的答案 | 下一问 |
|---|---|---|---|
| 0 现象 | 减重这件事有多大分量？ | 是被法规与产业长期认真对待的方向：减重 10% 在同步缩小动力总成的前提下约换来 5–7% 的油耗下降；但只换材料（1–5%）远不如整车重做（5–10%） | 减重到底改变了车的什么？ |
| 1 物理链条 | 重量到底影响哪些表现？ | 分成两类：重量直接乘上去的（爬坡要的力与功率、加速、滚动阻力、动能）和不随质量变的（制动距离、风阻、轮胎能给出的力上限）；结论是减重买不到更短的刹车距离 | 那减重怎么做？ |
| 2 怎么做 | 减重怎么做？ | 密度阶梯：铁 7.87、铝 2.70、镁 1.74 g/cm³，碳纤维蒙皮约为同等钢蒙皮的 20%；结构上从 Model T 的钒钢，到奥迪 ASF 铝空间框架（A2 同属这条线，到 2010 年底约 55 万辆），再到大众 XL1 的碳纤维单体壳（795 kg、Cw 0.189） | 这么做的代价是什么？ |
| 3 代价 | 代价是什么？ | 三笔：安全上必须整车重做并逐项重做碰撞验证（EPA / NHTSA / CARB 的委托研究与同行评审流程）；钱上四项官方研究的结论是减重 18–32%，每车净省 0–419 美元不等，但每项研究本身花 100 万–200 万美元，且要年产 10 万辆才摊得开；工艺上要新的半成品与新工艺 | 电动化会不会把这件事推翻？ |
| 4 新问题 | 电动化会不会把这件事推翻？ | 不会推翻，但会加码：EPA 官方数据说纯电动车平均比同级车更重；不算 BEV 与 PHEV 的话 2024 车型年度新车平均重量要低 72 磅；连官方减重研究里都有一项是专门为电动车设计做的 | 所以轻量化的意义到底是什么？ |
| 5 结论 | 结论 | 轻量化不是把车做小，而是把重量从该花的地方挪走：同样的功率换更快、同样的电池换更远；代价是整车重做、碰撞重验与工艺升级 | 片尾名单 |

本片决定不讲的材料及理由：

- Model T 与 Audi A2 的整备质量：未取到一手来源（FACTS 待核实），写了就是编。
- 各品牌的减重营销案例（碳纤维版民用车型等）：与「重量影响什么」这条主线无关，属于车型清单（F01，参见 OpenClaw v2 的负面案例）。
- 混动与插混的完整能量流：会引入过多新名词（F02），XL1 的动力总成数据已经够用。
- 镁合金的压铸与防腐工艺细节：材料路线点到为止，展开需要另一个片子。
- 电池化学体系与快充：与重量链条关系弱，属于另一个题目。
- 欧洲 EuroNCAP 与中国法规的评级细节：本片的安全部分用 FMVSS / IIHS 与 EPA / NHTSA / CARB 的流程讲清「减重必须重验」这件事即可，不铺开各国评级差异（F03）。
- 媒体的「XX 款减重 XX 公斤、油耗降 XX%」类稿件：只用于定位官方材料，不作片中依据（F09）。

## 视觉系统

<!-- 颜色、字体、图形语言、转场；全片保持的约定（同一个图形只有一个含义）。 -->

- 图形约定（全片一个图形只有一个含义）：
  - 重量 = 一摞可数的砝码；
  - 力 = 箭头，长度对应大小；
