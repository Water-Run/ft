# 游戏物理学

每集讲一款游戏的物理模拟：它用什么方法逼近真实物理、换来了什么、放弃了什么。面向玩过这些游戏、想知道背后原理的观众。

## 连续性

同一系列的各集保持一致的做法记在这里：首集制作时定下来，后续各集遵守；要改就先改这里。各项的含义见 [docs/series.md](../../../docs/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | `<游戏名>物理学` |
| 结构 | 待首集确定 |
| 演示与取证 | 待首集确定；各集尽量用同一种可复现的实验（同一组碰撞、同一组初始条件），便于跨游戏对照 |
| 视觉 | 待首集确定；定下后写回这里，并把可复用的源码整理成系列基座 `_base/` |
| 声音 | 待首集确定 |
