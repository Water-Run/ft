# 一个数据库引擎是如何实现的？——事务性与现代化：InnoDB

数据库引擎系列第 2 集，一部 15 分 49 秒的科普片，仅中文。与第一集同一定位：讲一个存储引擎怎样实现。主线分三段：由上一集 MyISAM 的三条局限（没有事务、一把表锁、没有日志）引出事务性；讲清事务性是什么、难在哪里（事务与 ACID、锁与多版本、隔离级别、日志与预写，并在这里引出 OLTP）；再看 InnoDB 怎样把它做出来——沿上一集的四个问题「数据怎么放、怎么找、怎么并发、出错怎么办」逐章展开，每章对照 MyISAM 的做法；最后回到三条局限与代价。演示环境为 MySQL 9.7.2，只在第 01 章交代一次；InnoDB 自 2010 年 7 月的 MySQL 5.5.5 起成为默认存储引擎。

成片长度按策划者的要求约 15 分钟（`check.duration` 840–960 秒），高于系列一般的 10 分钟，例外已写入系列说明。本集只讲 InnoDB，不涉及其他数据库。片中每一句陈述的出处见 `research/FACTS.md`，章节与边界见 `research/MAP.md`，系列约定见 [`../README.md`](../README.md)，制作流程与标准见仓库的 `docs/`。

本片是重做后的第二版（中文稿 R8）。第一版（R7，14:35，纸色加钴蓝的版面）在预演后被策划者要求整片重做，意见原话见 `docs/feedback.md` 的 P6–P13，本文末节逐条对照。

## 视觉系统

本集的视觉取自 MySQL 与 InnoDB 自己的样子，不沿用第一集，也不沿用系列中其他影片的设计语言。

- **出处**：画法来自 MySQL 9.7 参考手册「InnoDB Architecture」一图（`innodb-architecture-8-0.png`）：浅灰底上的圆角面板与面板标题、青色深浅的圆角页块、文件与日志图标、虚线框表示示意的部分。强调色取自 MySQL 标志：蓝 `#00758F` 与橙 `#F29111`。
- **颜色**：底 `#EEF1F0`、面板 `#FAFBFA`、面板边线 `#CDC6BE`、墨 `#1E3742`、灰 `#5A6B72`；页块的青色由浅到深 `#E4EFEE`、`#BDDCD7`、`#84BDB5`、`#3F7D86`、`#22505C`，依次表示「空、普通、索引、正在用」。标志蓝给此刻讲到的东西：正在讲的行、选中的版本、提交的结果、标题与原文里的关键词；标志橙给锁、被锁的空隙、脏页与要当心的状态。平涂，不用阴影、渐变与模糊；斜线填充用一小块 SVG 平铺。对比度（WCAG）：墨/底 11.0:1，灰/面板 5.4:1，灰/底 4.9:1，标志蓝/面板 5.1:1，白字/标志蓝 5.3:1，白字/深青 8.9:1，墨/标志橙 5.3:1，墨/浅青 8.6:1。
- **图形的含义，全片不变**：圆角面板是一块存储或一个对象（文件、页、缓冲池、日志）；青色页块是页；圆角横条是记录；虚线框是旧版本或示意；橙色圆角块加锁梁是锁；橙色斜线是被锁的空隙、脏页与等待；折角的白纸是文件，`LOG` 标签的是日志。
- **字体**：拉丁文字与数字用 Open Sans（mysql.com 的正文字体，SIL Open Font License 1.1，可变字体文件随片放在 `src/type/`），中文用 Sans SC，SQL、记录与回显用 Mono。文献卡用标志蓝的大号年份、英文原题与作者出处；引文只取原文，不改写。
- **换章**：左侧出现章节标题（标志蓝的编号方块、章名、一排页块，其中一块是橙色），读完后收进左上角的章节标签；不用整屏擦除。
- **镜头**：每章是一块比画面大的画布，镜头只在站与站之间移动；停留时只做缓慢的单向推近（每秒 0.5%，最多 4%），换站时缩放回到起点，不往复、不摇晃（`src/js/parts.js` 的 `camTrack`）。
- **示意**：没有实测的过程（多层 B 树、缓冲池链表、双写缓冲、一次修改的六步）一律标「示意」。

**设计记录与原创。** 设计语言提案的关键帧在 `shots/kf-r8-1.png`–`kf-r8-4.png`（2026-10-10 经策划者确认）。版面按架构图的画法重新绘制，没有复刻任何现成的产品界面或视频；画面上的数据全部来自本片的实验：页、记录、字节、事务号、锁与恢复的回显都是 `src/js/data.js` 与 `research/lab/` 的原值。封面（`out/cover-zh-16x9.jpg`、`out/cover-zh-4x3.jpg`）用同一套视觉：一块缓冲池面板，标志蓝的一页正在用、标志橙的一页上了锁，旁边是一份日志文件。

## 读法

字幕写正式拼写，读法放在 `src/js/script.js` 的 `SAY` 表里。

| 写法 | 读法 | 原因 |
|---|---|---|
| InnoDB、MyISAM、MySQL、Innobase | Inno D B、My ISAM、My S Q L、Inno base | 连写时被吞音或读错 |
| ACID、MVCC、OLTP、LSN、SQL | 逐个字母 | 同上 |
| ARIES | Aries | 论文名按单词读 |
| `.ibd`、`.MYD`、`.MYI` | 点 I B D 等 | |
| 1196、1205、1213 | 一一九六、一二零五、一二一三 | 错误码逐位读 |
| 数据的「行」（一行、整行、行级锁） | 送去合成时换成同音的「航」；执行、进行、串行、银行不换 | 回听时「整行」「一行」「行级锁」被读成 xíng |
