# 05 镜头、动作、音效与配乐

通用规则见仓库 `docs/scenes.md` 与 `docs/sound.md`。本文件给的是**本片的要求**；具体怎么实现由你决定。

## 1. 镜头

- **连续的镜头运动贯穿全片。** 内容摆在一个比画面大的空间里，镜头在其中移动；场景之间用匹配剪辑、镜头穿越或图形化的转场衔接，不用整屏淡入淡出。
- **停留时不晃动。** 推进靠极慢的单向推近；停留时最多极慢地单向推近，不做往复平移或环绕（P6）。「任意 3 秒有可见变化」由跟着旁白出现的高亮、标注与图形变化满足，不靠镜头摆动凑数。
- **读数段落镜头停住。** 三个体积数字、页数分布、副本数、30/31 的读数出现时，镜头完全停住（不推不摇），留够阅读时间。
- 本片的画面里有几样东西会反复出现（库文件带、页阵、两块读数板、服务端进程剖面），**它们在几章之间的位置与大小要能被认出是同一个东西**。

## 2. 动作

- **一个动作说明一件事。** 不要把几个机制塞进一个动作。
- **入场动作要分得出差别。** 本片有多种机制在动（连接建立与断开、页按类型上色、副本出现、读数变化、版本链被回收、脏页落盘），每一种都该有自己的动作。不要所有元素同一种「淡入加上移」。
- **动作有预备、过冲、跟随。** 关键信息用一个明确的「揭示」动作交代。
- **退场交代去向。** 元素退场前要让人知道它去哪了，不在刚到达时直接消失（F19）。
- 文字不闪烁、不被错误遮挡；主体不意外跳位；边缘不穿帮。

## 3. 音效

- 只给**有语义的关键动作**配音效：连接建立与断开、页类型分布落定、副本出现、提交与读数变化、回收旧版本、脏页落盘、章节卡切换。
- **不要用默认气流声（`whoosh`）填满动作。** 慢移、阅读保持、镜头推移可以无声。
- 关键动作的音效要能被听出「这是同一类动作的同一类声音」——同一类动作用同一个 `sfx` 名字。
- 登记：`sfx('名字', 时刻, { g: 音量 })`。同一时刻不叠两个以上音效，相邻至少错开 0.06 秒。

## 4. 配乐

**策划者的要求：电子乐，富有节奏感。** 这一节把这句话落实成可核的要求。

### 4.1 形态

- 写成 `tools/music.py`，由 `mix.py` 调用（写法见 `docs/sound.md` 第 3.1 节与 `docs/tools.md`）。`project.json` 的 `audio.music` 已经指向这个文件。
- **要有节奏感**：明确的节拍与律动，不是稀疏的点缀。
- **要有存在感**（P27）：先有一层贯穿全片的低频或铺底，再加动机与节奏。旋律稀疏不等于克制——InnoDB 与 OpenCart 的配乐太弱，MyISAM 那种持续铺底才是参照。
- **与本系列前三集听得出来**（P3、F06）：2FA 是 120 拍/分的稀疏纪实（以秒针贯穿），PostgreSQL 是 72 拍/分的工业铺底，InnoDB 偏持续低频。本片是电子方向，节奏、音色与织体要与之明显不同。换 preset、换主奏音色不算差异化。
- **配乐服务于讲解。** 信息最密的段落要保证旁白清楚，不能机械地越讲越加层。
- 结论处（`z8`）抬起而不是提前用完；片尾（`credits`）收拢。
- 全片只用这一首曲子，不换曲。

### 4.2 分层

按场景推进加层还是别的办法，由你定。只要求两件事：

1. 听得出结构（哪一段紧、哪一段松、结论在哪里抬起）。
2. 全片任何时刻都有底噪级别的支撑，不出现「这一段没音乐」的空洞。

### 4.3 混音

- 仓库默认 `music_db -12`、`duck_db 7`、`sfx_db -9`；本片在 `project.json` 的 `audio` 段里已设好。
- 数字与读数出现时配乐要让位（真正的留白，不是把整首压低）。
- 响度与真峰值按 `finish.js` 在最终 MP4 上实测。

## 5. 试听片

另出一版配乐的试听片，让策划者挑：

```bash
node kit/tools/audio.js  videos/series/database-engines/firebird --lang zh music=<另一种> out=audio_b.wav
node kit/tools/finish.js videos/series/database-engines/firebird --lang zh --audio out/zh/audio_b.wav --name <名字>
node kit/tools/audio.js  videos/series/database-engines/firebird --lang zh   # 把正式混音恢复为默认
```

## 6. 配音

- 音色**待定**：`project.json` 的 `tts` 段是占位。按 F17，先试听候选音色与语速，确认语气不塌——句子有起伏、该强调处有重音、长句不被念平——再定。
- 试听要覆盖三组：`e6`–`e9`（三个数字的读法与重音）、`m2`–`m4`（外文专名与协议名）、`c3`–`c6`（长句不被念平）。
- 避开 `docs/script-and-voice.md` 第 9 节里标「停用」的音色。
- 读法与断句见 `brief/02-script.md`。
- 混音之后用 `asr.js` 逐句回听；ASR 只作筛查，最终由人耳确认，如实写明。
