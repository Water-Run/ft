## 连续性

| 项 | 约定 |
|---|---|
| 标题 | 待首集确定 |
| 结构 | 待首集确定 |
| 演示与取证 | 算法步骤以标准文本为准；画面上的数值由脚本实际计算得出 |
| 视觉与声音 | 待首集确定；定下后写回这里，并把可复用的源码整理成系列基座 `_base/` |
