# 编程思想

## 定位

| | |
|---|---|
| 讲什么 | 一门语言的设计哲学：这门语言的一条统一思想——它为什么长成这样、在什么地方取舍 |
| 面向谁 | 写过程序、想知道「为什么这样设计」的观众 |
| 怎么讲 | 讲思想从哪来、解决什么问题、代价是什么；每个论点配一段能运行的短代码，实测输出作为证据；严格事实核查，设计者的原话与实现细节回到原始文档与源码核对；统一视觉风格与节奏 |
| 每集多长 | 5–10 分钟 |

**收录的语言**（片单顺序）：Lua、Python、MiniScript、Rust、Zig、Nim、C#、TypeScript、OCaml、F#、Fish、PowerShell。只收有统一思想的语言；函数式、面向对象一类的编程范式不在本系列。

**与「编程语言」系列的分界**：同一门语言可以同时出现在两个系列里。`../programming-languages/` 讲的是解释器或编译器怎样把源码变成运行结果；本系列讲的是这门语言的设计哲学。取题时错开：实现与思想不混在一集里。

## 连续性

同一系列的各集保持一致的做法记在这里：首集制作时定下来，后续各集遵守；要改就先改这里。各项的含义见 [docs/series.md](../../../docs/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | `<语言> 语言的设计哲学：<一条思想>`，思想一句话点出该语言最值得讲的一点 |
| 结构 | 待首集确定 |
| 视觉与声音 | 待首集确定；定下后写回这里，并把可复用的源码整理成系列基座 `_base/` |
