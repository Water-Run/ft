# 动力总成

讲具体的发动机与变速器组合：结构、特性、演进与已知问题。

## 定位

| | |
|---|---|
| 讲什么 | 对汽车某一套特定的动力总成做详细解析：结构、匹配、特性、演进与已知问题 |
| 面向谁 | 对机械与汽车工程有兴趣的观众 |
| 怎么讲 | 一集只讲一套总成，讲透为止；参数、齿比、扭矩曲线等逐项给出处并注明数据来源与年份；全系列保持同一套数据口径 |
| 每集多长 | 3–7 分钟 |

## 连续性

同一系列的各集保持一致的做法记在这里：首集制作时定下来，后续各集遵守；要改就先改这里。各项的含义见 [docs/series.md](../../../docs/series.md)。标为「建议」的是起点，不是限制：每集按题目增删、合并、调整比重。

| 项 | 约定 |
|---|---|
| 标题 | 待首集确定 |
| 结构（建议） | 组合与搭载车型 → 发动机 → 变速器 → 两者的匹配与实际表现 → 演进与已知问题 |
| 演示与取证 | 结构与参数以厂商技术资料与维修手册为准；故障与口碑类的说法须有可查的出处，区分设计原因与个案 |
| 视觉与声音 | 待首集确定；定下后写回这里，并把可复用的源码整理成系列基座 `_base/` |
