# Shell 群观

按时间顺序看各种 Shell：从最早的命令解释器到今天的各类 Shell，各自的设计与取舍。

## 连续性

同一系列的各集保持一致的做法记在这里：首集制作时定下来，后续各集遵守；要改就先改这里。各项的含义见 [docs/series.md](../../../docs/series.md)。标为「建议」的是起点，不是限制：每集按题目增删、合并、调整比重。

| 项 | 约定 |
|---|---|
| 标题 | 待首集确定 |
| 结构（建议） | 年代与平台 → 代表性的 Shell 逐个演示 → 设计上的差异 → 留到今天的影响 |
| 演示与取证 | 各集用同一组小任务演示（列目录、管道、变量、循环、脚本），终端回显一律实测并注明版本。独立视频《古代来的 Shell：Windows 批处理（.bat）》题材相近，可互相引用 |
| 视觉与声音 | 待首集确定；定下后写回这里，并把可复用的源码整理成系列基座 `_base/` |
