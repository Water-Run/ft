# 时代

每集讲一个已经过去的技术时代：那个年代的技术面貌是什么、为什么是那样、又怎样被下一个时代取代。系列名里的「对应设计语言」是本系列的特别之处（见下）。

## 连续性

同一系列的各集保持一致的做法记在这里：首集制作时定下来，后续各集遵守；要改就先改这里。各项的含义见 [docs/series.md](../../../docs/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | `<主题>的时代` 或同等的时代命名 |
| 结构 | 待首集确定 |
| 视觉 | **特别约定：本系列不维持统一的系列视觉。** 每一集的视觉贴合那个年代实际的设计语言与观感——DOS 时代的字符界面、Win8 平板的方块磁贴、CRT 时代的辉光与扫描线，都以史料为据还原（示意画面按规定标「示意」）。连续性体现在结构与讲法上，而不是统一的配色与部件 |
| 声音 | 待首集确定 |
