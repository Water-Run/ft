# PowerPC 时代的麦金塔

本片讲 1994 年到 2006 年初那十二年的麦金塔：1991 年一家芯片公司结成三方联盟、1994 年整机换掉中央处理器、1998–2003 年用 G3/G4/G5 做出「肌肉感」、2005 年 Apple 宣布改用 Intel 的那一年究竟发生了什么。全片沿「结盟 → 换芯 → 三代 G → 转折 → 小结」推进，约 16 分钟，中英双语。

制作流程与标准见仓库的 `docs/`；片中每一句陈述的出处见 `research/FACTS.md`。

目标观众已有的知识：见过或用过 PowerPC 时代的 Mac，或者见过 Power Mac G4 / PowerBook G4 / iMac G3 的外形；知道「麦金塔」和「苹果电脑」是一回事；知道后来苹果改用了 Intel 的处理器；可能听过 G3、G4、G5 这些名字，但不知道它们是三颗不同的处理器、分别代表哪一年、解决什么问题；不知道 1991 年 Apple、IBM、Motorola 曾经结成过一个联盟；不知道 68k 与 PowerPC 两代 Mac 曾在同一时间并行卖过；不知道 AltiVec/Velocity Engine 是什么；不知道 2005–2006 年那次换芯是怎么决定的。

看完应能回答的一个核心问题：1994 到 2006 年这批麦金塔，为什么长成那个样子，又为什么在 2006 年被换掉？

逐章怎样推进问题、最后回答什么：现象（这批 Mac 的肌肉感从哪来，十二年后为什么被换掉）→ 三方结盟（1991-10-02，Apple/IBM/Motorola 为什么要一起造 PowerPC，第一代 Power Macintosh 用的是 PowerPC 601）→ 换芯（1994-03 三款 Power Macintosh 6100/60、7100/66、8100/80；同期 68k 的 Quadra 800、Performa 475、LC III 是怎么退场的）→ 三代 G（G3 的二级缓存、G4 的 Velocity Engine、G5 的 64 位与 1 GHz 前端总线；Mac OS X 10.0 在 2001-03-24 上市）→ 转折（2005-06-06 Apple 宣布一年内出 Intel 机型、2007 年底全换；2006-01-10 MacBook Pro 落地；当时给出的理由是路线图、能效与供货）→ 小结（这一代留下 64 位与片上 SIMD，带走的是一套自成一体的软硬件组合）。

## 与「电子发展史」系列的分工

「电子发展史」（`videos/series/silicon-history/`）按厂商与产品线梳理：每一代改了什么、为什么这样改、结果如何，指标口径全系列统一，配统一视觉。该系列的《苹果的芯片自研之路》讲的是苹果芯片**产品线本身**的演进。

本片在「时代」系列，讲的是同一个时代**在当时是什么样子**：1991–2006 这十二年里麦金塔的产品形态、竞争位置、行业文化，以及为什么在 2006 年被换掉。两边的分界：

| | 电子发展史 | 本片 |
|---|---|---|
| 讲什么 | 逐代产品的架构、工艺、关键指标 | 那批机器长什么样、当时的人怎么用它、它在产业里站在哪一边 |
| 依据 | 芯片手册、数据手册、官方规格 | Apple 官方新闻稿与历史材料、Apple 支持站技术规格、产品本体与界面语言 |
| 视觉 | 统一视觉风格 | 本系列特例：贴合 1990 年代末到 2000 年代初的麦金塔本体（半透明彩色外壳、铝制一体机、Aqua 界面） |

不互相照搬：本片不复述《苹果的芯片自研之路》里按型号排列的参数表，也不复用该系列的图表与时间线画法；「时代」系列讲体感、竞争格局与文化。

## 与系列内其他集的关系

本片是「时代」系列的第一集，按 `videos/series/eras/README.md` 的约定，系列的结构与声音基座由首集定下，后续各集遵守。要改系列约定先改系列说明。

《英特尔的酷睿年代》是另一条时间线上的片子（2006–2024 的 PC 侧），与本片的交点是 2006 年这一次换芯：Apple 从 PowerPC 换到 Intel 正是那一代 Intel 处理器的入局。两集各自独立可懂，不互相引用编号；本片讲「换掉的一方」，那一集讲「接上的一方」。
