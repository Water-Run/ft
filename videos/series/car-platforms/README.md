# 汽车平台

逐个讲解整车平台：它规定了什么、哪些可以变、基于它造出了哪些车，以及这种做法的得失。

## 定位

| | |
|---|---|
| 讲什么 | 各个汽车平台的历史、发展、架构与特性：它规定了什么、哪些可以变、造出了哪些车 |
| 面向谁 | 认得车、想理解平台这套做法的观众 |
| 怎么讲 | 详细的说明，架构图与代号逐项给出处；统一视觉风格与节奏 |
| 每集多长 | 5–15 分钟 |

## 连续性

同一系列的各集保持一致的做法记在这里：首集制作时定下来，后续各集遵守；要改就先改这里。各项的含义见 [docs/series.md](../../../docs/series.md)。标为「建议」的是起点，不是限制：每集按题目增删、合并、调整比重。

| 项 | 约定 |
|---|---|
| 标题 | `<厂商>——<平台或时代>` |
| 结构（建议） | 背景（上一代的问题）→ 平台的定义（固定的硬点与可变的尺寸）→ 模块与动力总成的搭配 → 代表车型 → 得失与后继 |
| 衔接 | 同一厂商的各集按时间衔接；尺寸与硬点用同一种侧视剖面画法，便于跨平台比较。与「动力总成」系列涉及同一批车型时互相引用 |
| 视觉与声音 | 待首集确定；定下后写回这里，并把可复用的源码整理成系列基座 `_base/` |
