# 汽车的系统工程

把汽车当作一个整体来讲：同样的零件，调校之后为什么表现不同；各个子系统之间怎样相互制约。面向对汽车感兴趣、没有工程背景的观众。

## 连续性

同一系列的各集保持一致的做法记在这里：首集制作时定下来，后续各集遵守；要改就先改这里。各项的含义见 [docs/series.md](../../../docs/series.md)。标为「建议」的是起点，不是限制：每集按题目增删、合并、调整比重。

| 项 | 约定 |
|---|---|
| 标题 | 待首集确定 |
| 结构（建议） | 一个可以感知的现象 → 涉及的部件与物理原理 → 各项指标之间的取舍 → 厂商的典型做法 → 小结 |
| 演示与取证 | 结构与参数以厂商技术资料、维修手册与公开的测试数据为准，逐项给出处；示意性质的图形在画面上标「示意」 |
| 视觉与声音 | 待首集确定；定下后写回这里，并把可复用的源码整理成系列基座 `_base/` |
