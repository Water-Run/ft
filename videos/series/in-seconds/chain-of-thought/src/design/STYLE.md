# 视觉系统：计时盘 × 思考轨

本片沿用「XX 秒速通」的系列视觉「计时盘」：墨色 `#0c0d0f`、纸色 `#f2efe8`、朱红 `#ff4a1c`，平涂、无圆角，数字与数据用 Mono，拉丁文字用 Inter，中文用 Sans SC。它不是视觉例外；只把右上角的「仪表」扩展成与 CoT 有关的「思考轨」，并把中间的推理步骤做成可数的刻度。

这份文件是设计方向，不是最终 `style.css`。系列基座的 `src/css/style.css` 已定义颜色、字号阶梯、字幕带与秒尺；实现时在此基础上加 CoT 专用部件，不改系列颜色与常驻元素的位置。

## 1. 一句话与设计命题

**一句话：** 把一次回答拆成一条可数的「思考轨」：问题在左，步骤一格一格往右走，答案在轨道的尽头亮起。

**设计命题：** CoT 的核心不是“模型在脑子里想了什么”，而是“它在给出答案前，把哪些中间结果写进了上下文”。画面只画可见的步骤、分支和投票，不画“大脑内部”；答案与步骤之间用一条轨道连接，但轨道不等于真相——结尾要能把它断开。

## 2. 色彩（沿用系列）

| Token | 色值 | 用途 | 约束 |
|---|---|---|---|
| `--ink` | `#0c0d0f` | 墨色底、字 | 系列主色 |
| `--paper` | `#f2efe8` | 纸色底、卡片 | 系列主色 |
| `--ac` | `#ff4a1c` | 朱红：此刻/结论 | **只给答案、当前步骤、走过的刻度**；一屏最多一处大面积 |
| `--dim` | `#8a8782` | 墨底次要文字 | 辅助信息 |
| `--dimp` | `#6b6964` | 纸底次要文字 | 辅助信息 |

规则：

- 不引入新颜色；CoT 的“分支/投票/失败”用纸色、墨色、灰色和线型表达，不靠新色。
- 朱红只给“答案”和“此刻正在走的步骤”；未选中的分支、被剪掉的路径用灰色/虚线，不用红色。
- 平涂；无阴影、渐变、圆角。圆只表示时间（秒表/表盘），方块表示数据/步骤。

## 3. 字体与字号（沿用系列）

| 层级 | 样式 | 用途 |
|---|---|---|
| 片名/大数字 | `.t-0` / `.t-1`（Mono 900） | 片名、`CoT`、192 |
| 主陈述 | `.t-2` / `.t-3` | 一句结论 |
| 问题/答案 | `.t-4` / `.t-b` | 题目、答案 |
| 步骤文字 | `.t-b` / `.t-n` | 中间步骤；一行一个动作 |
| 步骤编号 | `.num` | `01`、`02`、`03` |
| 注解/来源 | `.t-n` | 论文年份、数字口径 |

中文用 Sans SC；步骤编号、token 计数、年份用 Mono。不要用聊天字体或手写体。

## 4. 版面

- 世界仍是 1920×968；字幕带在 y≥968。
- 左侧 1/3 放问题（纸色卡片或墨色字），右侧 2/3 是「思考轨」；答案在轨道尽头，不居中。
- 思考轨是一条水平线/折线，每一步是一个小方块 + 编号 + 一行短文字；步骤间距一致，像尺子的刻度。
- 右上角 `HUD.right`（300×72）扩展为「思考轨仪表」：显示当前步骤数/总步数、分支数或投票计数；不要放聊天头像/大脑图标。
- 分支（self-consistency/ToT）从主线分叉，分叉角度固定 30°/45°；被剪掉的分支用灰色虚线，不要用红色叉号。
- 答案是一个朱红色块，块内字用墨色（系列已规定对比度）；答案块只出现一次。
- 不对称：问题偏左，轨道向右延伸；留白给“未走的分支”。

## 5. 图形语言（全片不破例）

| 图形 | 含义 | 画法 |
|---|---|---|
| 纸色卡片 | 问题/外部输入 | 矩形，无圆角；左上角可有一个小三角标“输入” |
| 小方块 + 编号 | 一个中间步骤 | 方块 24–32px；编号 Mono；一行短文字在方块右侧 |
| 水平/折线轨 | 步骤的顺序 | 2px 墨线；已走过的部分变朱红；未走的是灰色 |
| 分叉 | 多条推理路径 | 从主线分出 2–4 条；每条有独立的步骤块 |
| 票数/刻度 | self-consistency 的投票 | 短线 tally；多数答案上方出现朱红块 |
| 树枝/剪枝 | ToT 的搜索 | 分叉 + 灰色虚线剪枝；回溯用反向箭头 |
| 插座/箭头 | ReAct 的 action | 步骤块右侧接一个“插头”，箭头指向外部观察（纸色小块） |
| 朱红答案块 | 最终答案 | 只出现一次；块内墨色字；不要发光 |
| 断开的轨道 | 不忠实的解释 | 轨道在答案前断开/错位，用灰色虚线；不要用红色警告 |

不要画：聊天气泡、头像、大脑、齿轮、灯泡、魔法棒、思考 spinner。CoT 的视觉是“轨道/刻度/分叉”，不是“机器人脑袋”。

## 6. 动效

- **步骤落位**：每个步骤块按 0.5 秒一拍“盖章”落位（与系列 120 BPM、一秒两拍对齐）；不要平滑滑入。
- **轨道生长**：线从问题一侧向答案方向长出，已走过的部分变朱红；未走的部分是灰线。
- **答案亮起**：最后一步完成，答案块硬切出现；不要渐显/发光。
- **分叉**：主线在分叉点短暂停 1 拍，分出支线；支线各自落步骤；被剪掉的支线在 2 帧内变灰/虚线。
- **投票**：tally 线一根根出现；多数答案的朱红块最后落位。
- **回溯**：反向箭头沿轨道退回 1–2 步，再走另一条；不要抖屏。
- **镜头**：沿轨道慢推/平移；站与站之间移动；停留时不往复。
- **转场**：用轨道合拢/分叉、纸卡翻面、秒尺扫过；不用整屏淡入淡出。
- **12fps 步进**：步骤块/数字按 12fps 更新；镜头可连续。

## 7. 声音

- 节拍器/秒针（系列底）、铅笔划线、印章“啪”、继电器“咔”、纸卡翻动。
- 每个步骤一声轻“嗒”；答案块一声更实的“啪”；分叉用一声短促的机械分轨声。
- 不用 whoosh；不用“AI 提示音”。
- 配乐沿用系列 120 BPM 的脉冲与秒针；信息密集段加一层 click；结论处按系列 `lift_cue` 抬起。

## 8. 与系列的关系

这不是视觉例外。保留：

- 墨/纸/朱红三色与字号阶梯；
- 底部字幕带与秒尺、左上角剩余秒数、右上角仪表的位置；
- 120 BPM、一秒两拍、每秒一声秒针；
- 片尾名单格式。

只改：

- 右上角仪表的内容：从“验证码/表盘”换成“思考轨：步骤计数 + 分支/投票”；
- 中间画面的主图形：从“字节/验证码”换成“步骤块/轨道/分叉”。

## 9. 封面

- 16:9：左墨右纸；左侧 `CoT` 与 192 秒（朱红块），右侧一条思考轨从问题走到朱红答案块。
- 4:3：上方问题卡、下方轨道与标题；重新排，不裁切。
- 主标题字高约为画面高度的 1/5；底部 15% 不放字。
- 与系列其他封面并排看，应一眼认出是同一系列，但仪表不同。

## 10. 禁止

- 不要聊天界面、气泡、头像、输入框；这不是产品介绍片。
- 不要大脑/神经元/电路板/发光 AI 图标。
- 不要“思考中…”spinner 或三点动画。
- 不要用红色表示“错误/失败”；红色只给答案与当前步骤。
- 不要把所有步骤写成一大段代码/日志；一步一个动作，一行能读完。
- 不要把生成的 CoT 说成“模型真实想法”；画面与旁白都要保留这条边界。
- 不要用渐变、阴影、圆角卡片、霓虹。

## 12. 可直接给 AI 的描述

沿用「XX 秒速通」的计时盘视觉：墨色 `#0c0d0f`、纸色 `#f2efe8`、朱红 `#ff4a1c`，平涂、无圆角；数字与步骤编号用 Mono，中文用 Noto Sans SC，拉丁用 Inter。把 CoT 画成一条「思考轨」：左侧纸色问题卡，右侧水平/折线轨道，每一步是一个小方块 + 编号 + 一行短文字；轨道走过的部分变朱红，答案在尽头以唯一一个朱红色块出现。Self-consistency 画成多条分叉 + tally 投票；ToT 画成分叉、剪枝、回溯；ReAct 画成步骤块接插座/箭头到外部观察。右上角仪表显示步骤数与分支数，替代系列的验证码表盘。动效按 0.5 秒一拍盖章落位、轨道生长、答案硬切；不要平滑缓动、不要聊天 UI、不要大脑图标、不要 spinner、不要霓虹/渐变/阴影。结尾用一个断开的轨道提醒：写出来的步骤不等于模型真实的思考过程。
