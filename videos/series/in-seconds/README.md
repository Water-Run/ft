# XX 秒速通

每集在标题写明的秒数内讲清一个主题：一个概念、一项机制或一个工具。秒数是上限也是卖点：信息密度高、没有铺垫，开门见山。面向想快速搞懂的观众。

## 连续性

同一系列的各集保持一致的做法记在这里：首集制作时定下来，后续各集遵守；要改就先改这里。各项的含义见 [docs/series.md](../../../docs/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | `<秒数>秒…`，秒数即该集时长上限（`project.json` 的 `duration` 据此定） |
| 结构 | 待首集确定 |
| 视觉 | 待首集确定；定下后写回这里，并把可复用的源码整理成系列基座 `_base/` |
| 声音 | 待首集确定 |
