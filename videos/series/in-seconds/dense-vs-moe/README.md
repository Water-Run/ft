# 150 秒了解 LLM 的 Dense 和 MoE：稠密模型与混合专家模型

「XX 秒速通」系列的第 5 集，一部 150 秒的科普片。先建立 token、参数、计算量这几个基本概念，再并列讲两种架构：稠密模型（Dense）每个 token 用到全部参数；混合专家模型（MoE）把每层的前馈网络换成许多专家，由路由器为每个 token 打分、取前几名、把它们的输出按得分加权相加。随后交代两者的先后与今天的格局：MoE 的想法早在 1991 年就有，大模型起初多是稠密的，后来陆续用上 MoE，如今最大的开源模型大多是 MoE，以 Qwen3.8 的三个型号为例。最后用 Qwen3.8-Flash 与 27B 讲两者各自的长处：MoE 省计算、代价是内存，稠密在同样的参数量下更强，所以缺算力时选 MoE、缺内存时选稠密。中文与英文两个版本，时长相同。片长原为 96 秒，2026-10-09 先后改为 128 秒、150 秒，见 `research/FACTS.md` 的「文案审查」。

制作流程与标准见仓库的 `docs/`；片中每一句陈述的出处见 `research/FACTS.md`；系列的约定见 [`../README.md`](../README.md)。

## 视觉系统

本集按策划者的要求改用风格派（De Stijl）的新造型，系列的「计时盘」视觉在本集不用；常驻元素（字幕带与秒尺、剩余秒数、右上角的仪表）的位置与做法照系列约定。例外已写进系列说明。

- **颜色**：纸色 `#f2efe8`、墨色 `#0c0d0f`，三原色红 `#c8231b`、黄 `#f3c318`、蓝 `#1d4d9f`。平涂，不用阴影、渐变、圆角、斜线。对比度：纸色字压在红上 4.9:1、蓝上 7.0:1；墨色字压在黄上 11.7:1；红字压在纸色上 4.9:1。纸色压黄、墨色压蓝不够，这两种搭配不用。字幕里的强调用黄。
- **图形的含义，全片不变**：黑色粗线 = 结构的边界（层、块、专家之间）；白格 = 存着、这个 token 没用到的参数；红格 = 这个 token 用到的参数；黄块 = token；蓝块 = 必须装进内存的参数；灰色 = 量出来的分数或数量（路由器给专家的得分、27B 的成绩）。时间线上的方块、模型清单的条、三个型号的方块与结论页的色块都沿用这套含义：白底上的红段就是每个 token 激活的那一部分。
- **字体**：数字与数据用 Mono，拉丁文字用 Inter，中文用 Sans SC；大字用 900 字重，片名卡与结论页的主题词 200–250px。
- **右上角的仪表**：OLMoE-1B-7B 第 8 层的 64 个专家（4 行 × 16 列），每拍换一个 token，点亮路由器实际选中的 8 个；数据来自 `research/lab/03_route.py`，与第二场的大号路由图用同一个函数，两边同步。
- **换场**：一道黑色粗竖线由左向右扫过画面，新场景跟在它后面刷出，一拍（0.5 秒）扫完。每个场景自带纸色底。
- **镜头**：每场在一块比画面大的画布上移动：开场从 token 推近到权重原值、再拉远到格墙；第二场从塔飞进其中一层；第三场沿时间线平移到模型清单，再下移到 Qwen3.8，Flash 的方块就地长成参数墙、墙上一行就地展开成一层；第四场在上下两行的五站之间移动。

**参考与原创。** 参考的是风格派的造型原则：蒙德里安（Piet Mondrian）1920 年代起的「新造型」构图——只用水平与垂直的黑线、矩形的三原色面与大面积白，非对称的平衡；配乐取他晚年《百老汇布吉伍吉》（*Broadway Boogie Woogie*，1942–43）题名所指的布吉伍吉音乐。没有复刻任何一幅具体作品：本片的每一个构图都由数据决定——格墙的白格与红格是参数是否参与计算，塔的层数与块宽、方块的面积、清单与账本的条长都按参数个数画，专家格的点亮来自模型的实测路由。设计时做过两个方向的关键帧：A 经典新造型（黑粗线、色面、白格），B 百老汇布吉伍吉式的黄线网与小色块；B 的黄线压在纸色上只有 1.45:1、色块与数据互相抢眼，选定 A。

## 读法

字幕写正式拼写，读法放在 `script.js` 的 `SAY` 表里：

| 写法 | 中文读法 | 英文读法 | 原因 |
|---|---|---|---|
| Qwen3.8、Qwen3.8-27B | 千问三点八（二十七 B） | Qwen three point eight（, twenty-seven B,） | 中文直读成「Quinn」；用通义千问的中文名。型号里的连字符不读 |
| 2.4T、2.4T-A95B | 二点四 T（A 九十五 B） | two point four T（, A ninety-five B） | 逐段读出 |
| DeepSeek-V3 | DeepSeek V 三 | （直读） | 中文把「V3」连读得含混 |
| MoE、FFN | M O E、F F N | M O E、F F N | 连写的 MoE 在中文里整个被吞掉，英文被读成「MO」 |
| OLMoE | O L M O E | （直读） | 中文的 MoE 规则会把它拆成「OLM O E」，另写一条放在前面 |
| 27B | 二十七 B | twenty-seven B | |

不改含义的调整：中文字幕去掉句末句号、加强调标记；m2 一句拆成两条字幕（m2、m3），中文 m2 的读法写在 `tts` 字段里（句末用逗号，语调接着往下说）；中文第三、四部分的句间停顿比英文长，补足两种语言语速的差。
