# 96 秒读懂模型的模型卡

一部 96 秒的中英双语科普短片：决定用不用一个模型之前，应该先读它那份说明里的哪几栏。讲法是沿一张真实的模型卡（Hugging Face Hub 上的 `google-bert/bert-base-uncased`）从上往下走，每一栏先问「这一栏在回答什么问题」，再给卡里的原话或数字。成片时长必须恰好 96.00 秒。

制作流程与标准见仓库的 `docs/`；片中每一句陈述的出处见 `research/FACTS.md`。

逐章怎样推进问题、最后回答什么：

| 场 | 提出的问题 | 本场答案 | 下一问 |
|---|---|---|---|
| open 0.00–15.75 | 为什么同一个模型对两种人给出完全不同的答案？ | 答案写在它自己那份说明里，叫模型卡 | 这份说明是什么、什么时候该看 |
| what 15.75–26.25 | 模型卡是什么？ | 跟着模型一起发布的简短文档；2018 年论文提出，要求写清评测与使用场合 | 从上往下该怎么读 |
| read 26.25–64.75 | 该读哪几栏？ | 元数据 → 用途与限制 → 局限与偏见 → 评测结果，逐栏问它在回答什么 | 这张卡本身可信到什么程度 |
| edge 64.75–76.60 | 谁写的这张卡？ | 发 BERT 的团队没写，Hugging Face 团队代写 | 所以先读哪三栏 |
| close 76.60–88.00 | 先读哪三栏？ | 用途与限制、局限与偏见、评测结果 | ——（片尾静默） |

## 视觉系统

策划指定液态玻璃，完整规范见 [`research/STYLE.md`](research/STYLE.md)。要点：

- **保留不动**（系列约定）：字幕带与秒尺、左上角剩余秒数、120 拍/分与每秒一声秒针、定长时间线、语速。
- **只换视觉系统**：深墨到冷灰的底板配一条固定方向的宽光带；卡片本身是暖白的**纸**（`#f4f1ea`），玻璃感来自它的厚度边、折射亮边、背后模糊与 45° 高光——**玻璃是介质，不盖住卡上的字**。
- **四个栏目四种玻璃形态**，各只在本片这一处作栏目识别：YAML 头=薄玻璃片，用途与限制=厚玻璃块，局限与偏见=裂纹玻璃，评测结果=磨砂玻璃。
- **右上角仪表**（`hud-r` 容器）：一张缩小的模型卡轮廓，六栏竖排，读到哪栏亮哪栏，点亮用朱红 + 一次 0.3 秒高光扫过；最后 5 秒六栏全亮。镜头在「逐栏读」段纵向下移时与它同步。
- 全片一个连续空间，镜头始终能看到这张卡的边缘；`rT`、`oT`、`cT` 三处阅读停顿期间镜头完全停住。
- 参考与原创：不使用外部视觉参考作品，玻璃形态按模型卡这一对象自行设计；字体与朱红/纸色沿用系列基座，冷调底板与青色折射为本集新增。
