## 主问题

**拿到一个模型，在决定用不用之前，应该先读它那份说明里的哪几栏？**

答案：三栏 —— 用途与限制、局限与偏见、评测结果；外加一句「先看这张卡是谁写的」。

## 讲法

沿一张真实的模型卡（`google-bert/bert-base-uncased`）从上往下走，每一栏先问「这一栏在回答什么问题」，再给卡里的原话或数字。不用抽象定义开场，不堆术语。

开场直接给现象：两道填空题、两个答案（`o1`–`o2`），观众先看见结果，再知道这些答案写在什么地方（`o3`–`o4`）。

## 与第 16 集的分工

第 16 集《150 秒通过参数认识一个模型》讲从参数量认识一个模型；本集讲读一份文档判断该不该用。两集的对象同族（开源模型），方法完全不同。

据此，本片**不把参数量当作判断依据**，也不复述第 16 集。`bert-card` 的 `## Model variations` 表格（8 个变体、110M/340M）是本片查到的最诱人的材料，但采用它会把本片拉回参数话题，因此整栏舍弃，理由记在 `FACTS.md` 的「不能说的话」。

## 逐栏安排

| 顺序 | 卡的栏目（原文标题） | 讲什么 | 为什么是它 | 句号 |
|---|---|---|---|---|
| 1 | YAML 头 | 「最上面是机器读的元数据」——语言、许可、训练数据三项一眼可读 | 真实卡的第一样东西就是它；也是「模型卡 = 元数据 + 正文」这一结构的证据 | `r1` |
| — | （不逐栏讲）Model description / Model variations / Training data / Training procedure | 镜头快速经过，不停留、不点亮 | 见下「舍弃了什么」 | 画面约 2 秒一带 |
| 2 | Intended uses & limitations | 卡里写明这个模型主要拿整句做判断；要做文本生成应看 GPT2 | **直接回答「不该拿它做什么」**。这是全片最有用的单句证据 | `r2`–`r4` |
| 3 | Limitations and bias | 两个可复现的填空例子与分数；卡里明写这个偏见会传染给所有微调版 | **唯一有具体数字、且卡自己下了结论的一栏**。也是 F04 的核心画面 | `r5`–`r8` |
| 4 | Evaluation results | GLUE 语言理解测试，微调后平均 79.6 | 回答「它在别人的考卷上得几分」。只报数字，不评价好坏 | `r9` |

开头（`o1`–`o4`）与结论（`c1`–`c3`）复用的都是第 3 栏的那两个填空，不引入第二个例子 —— 系列约定要求一条线索贯穿，`check.js` 的静止检测也按单一演示对象排。

## 舍弃了什么

| 舍弃的 | 理由 |
|---|---|
| 论文作者 9 人的完整名单 | 96 秒放不下，且对「怎么看模型卡」没有帮助。只在画面角标给论文标题与 2018 年 |
| 论文的两个实例卡（微笑人脸、有毒评论） | 本片已有一张真卡作主线，再引入两个会分散；见 `FACTS.md` |
| 论文的价值判断（走向负责任地普及 AI） | 价值判断，不是判断该不该用的依据 |
| BERT 的 MLM / NSP 两个预训练目标的完整解释 | `r7` 只需要观众看懂「填空」这个玩法即可；完整解释会挤掉重头段落。MLM 的 15% 掩码规则因此也不讲 |
| `## Model variations` 的 8 个变体与参数量 | 与第 16 集重叠，见上「与第 16 集的分工」 |
| `## Training data`（BookCorpus 11,038 本书 + 维基百科） | 对「该不该用」是背景，不是判断条件 |
| `## Training procedure`（WordPiece、词表 30,000、`[CLS]`/`[SEP]`、80/10/10 掩码规则） | 同上 |
| GLUE 表里的 8 个分项（MNLI、QQP 等） | 只用平均值 79.6；分项表留给画面，不进旁白 |
| GLUE 各任务的全称与含义 | 一句话定义足够（`FACTS.md` 已核），逐项解释放不进 96 秒 |
| 「模型卡已成为行业标准」之类的趋势判断 | 无可复查依据，见 `FACTS.md`「不能说的话」 |
| Hugging Face 官方模板的 14 个一级栏目 | 会变成第二份清单，与本片主线（一张真卡）冲突。只在 `FACTS.md` 里作交叉印证 |
| Apache-2.0 许可的口头解释 | YAML 头里显示即可，不念 |

## 需要 WaterRun 拍板的取舍

见 `review/NOTES.md` 的「拿不准的地方」。主要是三个：卡里「training data 可以称为相当中性」这句要不要进旁白；MLM 解释压到一句是否够；第 3 栏的分数只念两位小数是否可接受。
