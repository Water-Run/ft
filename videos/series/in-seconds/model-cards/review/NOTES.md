### 拿不准、需要 WaterRun 拍板的取舍

**① 「training data 可以称为相当中性」这句要不要进旁白？**
卡里在两个例子之前有这句限定：`Even if the training data used for this model could be characterized as fairly neutral, this model can have biased predictions`。我的判断是：不进。它会挤掉 `r7` 的两个分数，而分数才是这一栏的证据。但少了这句，观众可能以为模型就是在训练数据里「学到」了偏见——卡里特意做了这个区分。**要不要用半句补上（例如在 `r7` 前加「卡里先说了训练数据本身不算有偏见」）？**

**② MLM 压到一句够不够？**
`r6` 只说「卡里直接给了两个可以复现的例子」，没解释填空的来历。观众看到 `[MASK]` 与 15% 的关系可能要自己脑补。**加一句「掩住词让模型猜」是否值得从别处挪 2 秒？** 现在 read 场有 0.69 秒余量，加不下一整句。

**③ 只念两位小数可接受吗？**
`r7` 念「0.097」「0.220」，卡里的原值是 `0.09747550636529922` 与 `0.21981462836265564`。理由：96 秒念不下 17 位小数，且位数不影响结论。**画面上要不要同时给出完整原值？**（现在打算只给四位小数 `0.0975` / `0.2198`，完整值留在 `FACTS.md`。）

**④ 免责声明这一段该不该更靠前？**
目前它在 `edge`（64.75–76.60），是全片最后一个「边界」。另一种排法是紧跟 `o4`（片名卡之后）就点明「这张卡是代写的」，让整片读卡过程都带着这个前提。**但那样 `read` 段的重头会被打断，且片名卡之后立刻泼冷水，观感上更冷。** 我选了现在这个位置。

**⑤ 第 3 栏要不要英文原句与中文并排？**
`r7` 的两个分数，卡里原文是英文句子 + 一段 Python 输出。**画面上给英文原句加中文转述，还是只给中文转述 + 原分数？** F11 要求外文有中文释义，但 `o1`/`o2` 已经用中文说过一遍，第三栏再并排可能重复。
