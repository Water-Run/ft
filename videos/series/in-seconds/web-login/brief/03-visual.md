# 03 视觉系统

完整规范：`src/design/STYLE.md`；实现：`src/css/style.css`；关键帧：`src/design/kf.html`（`?f=1` 标题、`?f=2` 哈希、`?f=3` 会话票、`?f=4` 因子/WebAuthn）。

## 1. 颜色与搭配

| Token | 色值 | 含义 | 允许的搭配 |
|---|---|---|---|
| `--ink` | `#111111` | 验证者/系统/黑框 | 米白底、黄底、红底（大字） |
| `--paper` | `#F1ECE1` | 米白底 | 黑字、红/蓝/黄块 |
| `--ac` / `--bh-red` | `#E2412C` | 秘密/凭证（口令、私钥、令牌） | 米白底上的块；黑底上的大字 |
| `--bh-yellow` | `#F2C230` | 用户/声明 | 黑字压在黄上 |
| `--bh-blue` | `#2F57B0` | 会话/令牌/通道（TLS、cookie、session、JWT） | 米白字压在蓝上 |
| `--dim` / `--dimp` | `#6E6A61` / `#8A857A` | 次要文字 | 只在对应底色上 |

一屏最多三块大色 + 黑 + 米白；红/黄/蓝是概念标签，不是装饰。所有平涂；不用阴影、渐变、毛玻璃、圆角卡片。圆只表示“知道/时间”，方表示“拥有/数据”，三角表示“本身”。

## 2. 字号

沿用 `style.css` 的 `.t-0`…`.t-n`；标题 120–400px、正文 38px、注解 28px。最小字号 24px（`check.min_font`）。一屏只有一个最大字；最大字至少是最小字的 4 倍。中文字体 `Sans SC`，拉丁 `Inter`，编号/协议名 `Mono`；只用 400/700/800。

## 3. 版面

- 1920×968 世界；字幕带 y≥968；左右边距 120px。
- 12 栏网格定位，但不对称：标题偏左/偏右，形状可出血、切半、旋转 15°/30°/90°。
- 三四个大形状撑起一屏，字很少；不要居中堆叠。
- 一屏只讲一件事；需要更多信息时用形状/标签，不加深色面板。

## 4. 图形语言（不破例）

| 图形 | 含义 |
|---|---|
| 红圆 | 你知道的东西（口令/秘密） |
| 蓝方 | 你拥有的东西（设备/会话） |
| 黄三角 | 你本身（生物特征） |
| 三块拼合 | 一个完整的“你”/多因素 |
| 黑框 | 验证者/系统；形状不合就进不去 |
| 单向压模 | 口令哈希：进去一个形状，出来另一个；不可逆 |
| 带缺口的钥匙 | WebAuthn：私钥在方内，公钥在方外 |
| 盖戳的票 | cookie session：票根=session ID，票面=用户 |
| 带签名缺口的蓝色条 | JWT/token：签名可验，内容可读；谁拿着谁用 |
| 两个黑框互交一张票 | 联合登录：IdP 认证，RP 收 assertion；SAML/OIDC 都是这种结构 |
| 从画外伸进的斜块 | CSRF/会话劫持：借浏览器的手 |
| 错位的假框 | 钓鱼：同形但 origin 不对 |

## 5. 封面

16:9 左形状拼合体、右标题；4:3 上形状、下标题；主标题字高约画面 1/5；底部 15% 不放字；与正片同色同字体；缩到 360px 宽仍可读。

## 6. 禁止

聊天 UI/气泡/头像/输入框；大脑/神经元/电路板/发光 AI 图标；spinner/“思考中”；红色当错误色；渐变/阴影/毛玻璃/圆角卡片；霓虹；直接复刻现成海报/产品界面。
