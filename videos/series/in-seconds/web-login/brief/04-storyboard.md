# 04 分镜要求

逐句时间以 `timing.<语言>.js` 为准；下面用句号定位。每个场景至少一次连续镜头运动；形状动作按 12fps 步进。具体构图可调整，但图形语义与 `expect.*.json` 的文字不能破。

## open（0:00–0:18）

- o1–o2：米白底，一条蓝色票根从右侧滑入，上面是 `SID=...`；红色圆在左侧，标注 `YOU`。o1 只出现 SID，o2 出现 `YOU` 与 SID 的连接线。
- o3–o4：切到片名卡。黑字 `200` 极大；红圆、蓝方、黄三角在左侧拼成一块，右侧标题“了解 Web 登录 / 怎么验证你是你”。o4 出现 `SESSION ID` 标签。
- o5：黑框从上方落下，把“YOU”框住；框外出现一个问号形状。镜头轻推。
- 片名卡停留从 o3 到 o4 结束，保证读完；不要用“刷一下”。

## password（0:18–0:49）

- p1：左侧一个抽象登录表单（两条黑线 + 一个红圆），右侧空白；镜头从表单推向服务器一侧。
- p2：蓝色方 = TLS 通道；红圆（口令）沿通道移动。
- p4–p6：红圆进入黑框压模，出来蓝方（哈希）；黄色小方块 = salt 贴在蓝方边缘。p4 出现 `SALT + HASH`；p6 出现 `SLOW HASH`。
- p7：服务器一侧用同一压模再算一次；两个蓝方对齐。
- p8：蓝方堆叠，红圆不在堆里；标签 `HASH`。
- p9：红圆单独发光（不是发光特效，用红色块放大），标签 `KNOW`。
- p10：cookie 票根从服务器滑向浏览器；红圆留在服务器外，标签 `NO PASSWORD`。
- 镜头从表单平滑移到服务器压模，再移到 cookie；不要来回摇。

## session（0:49–1:25）

- s1：服务器一侧出现一个空的票夹；标签 `REMEMBER`。
- s2：票夹里生成一张票，票根是蓝色；标签 `SESSION ID`。
- s3：票根被装进 `Set-Cookie` 的黑框信封，滑向浏览器。
- s4：浏览器每次请求带票根；蓝色票根沿一条黑线往返。
- s5：服务器一侧出现会话表网格（纸色格），票根落在其中一格；标签 `SESSION STORE`。
- s6：票根被一只手（黑色斜块，不画具体手）拿起；标签 `BEARER`。谁拿着票根，谁就是 `YOU`。
- s7：票面旁出现三块小方：`Secure`（蓝）、`HttpOnly`（黑）、`SameSite`（黄），标签用 expect 的字符串。
- s8：旧票根被剪掉/换新，注销时票根变灰；标签 `ROTATE`。

## attacks（1:25–1:53）

- a1：票根伸出三条黑线，分别通向三个黑框；标签 `THEFT`。
- a2：第一条线进入一个“页面里的脚本”黑框，脚本形状（黑色小方块）从票根上读走蓝色；标签 `XSS`。
- a3：第二条线不读票根；浏览器形状（蓝色方）被画外的黑色斜块推着，带着票根发出请求；标签 `CSRF`。
- a4：第三条线先塞给用户一张旧票根；标签 `FIXATION`。
- a5：用户用旧票根登录，旧票根与攻击者的黑框连上；标签 `TAKEOVER`。
- 三条路径的构图要区分：读、借、换。不要用同一种箭头。

## factors（1:53–2:25）

- f1：红圆（口令）被一条鱼钩形黑线拉走；标签 `PHISHING`。
- f2：红圆、蓝方、黄三角排开；标签 `KNOW / HAVE / ARE`。镜头横移。
- f3：黄三角（短信码）被一条从画外伸进的线实时复制；标签 `SMS`。
- f4：黄三角被假框接住；标签 `OTP`。假框与真框错位。
- f5：两块不同形状拼合，黑框只接受两块；标签 `AAL2`。
- f6：蓝方里生成一把带缺口的钥匙；标签 `WEBAUTHN`。
- f7：钥匙的缺口与服务器给的 challenge 形状对上；公钥留在服务器一侧；标签 `PUBLIC KEY`。
- f8：真框与错位假框并排；钥匙只在真框里能转；标签 `ORIGIN`。

## federated（2:25–2:57）

- g1：本站（红圆/蓝方）之外出现第三个大形状（黑框/授权服务器）；标签 `SSO`。
- g2：用户从本站走到第三方；第三方出现 `GOOGLE` 标签（通用示意，不画真实品牌 UI）。
- g3：黑框把一枚“授权”钥匙交给本站，但不交“身份”；标签 `OAUTH`。
- g4：一张短命的 code 票从黑框滑回本站，票上写一次性；标签 `CODE`。
- g5：本站出示 verifier 形状，code 票才能换成 token；标签 `PKCE`。
- g6：token 票上有签名缺口；标签 `JWT`。明确“签名不等于加密”。
- g7：第三方的身份层（黄三角）叠到 OAuth 上；标签 `OIDC`。

## close（2:57–3:12）

- c1：红圆 + 蓝方票根 + 黄三角排成一条链；标签 `PASSWORD + COOKIE`。
- c2：黄三角与蓝方拼合；标签 `MFA`。
- c3：链条中间出现一个灰色虚线缺口；标签 `WEAKEST LINK`。
- c4：缺口合上，三个形状拼成一个整体；标签 `VERIFY YOU`。

## outro（3:12–3:20）
