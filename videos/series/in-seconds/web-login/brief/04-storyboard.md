# 04 分镜要求

逐句时间以 `timing.<语言>.js` 为准；下面用句号定位。每个场景至少一次连续镜头运动；形状动作按 12fps 步进。构图可调整，但图形语义与 `expect.*.json` 的文字不能破。

## open（0:00–0:19）

- o1：米白底，四个抽象登录碎片同时出现——红圆（口令）、黄小方（验证码）、黄三角（指纹）、蓝方（Google 登录）；黑字问句压在左上。标签 `LOGIN`。
- o2：四个碎片排成一行/扇形，每块下面只给一个词：`PASSWORD`、`OTP`、`PASSKEY`、`GOOGLE`；镜头轻推。
- o3：四块收成三栏：`WHO` / `PROOF` / `MEMORY`；黑框把三栏框住。这是全片骨架，停留要够读。
- o4：一张蓝色票根从右侧滑入，票面 `SID=...`；标签 `SESSION ID`。片名卡在这时出现：`200` 极大，标题“了解 Web 登录 / 怎么验证你是你”。
- o5：黑框合拢，把票根夹住；框外一个问号形状。镜头推近票根。

## credentials（0:19–1:06）

- c1：黄三角（用户）落在黑框前，标注 `ACCOUNT`；一条黑线把它和“声明”连起来。
- c2：红圆（口令）进入一个抽象输入框；标签 `PASSWORD`。
- c3：红圆外面套一层蓝色通道，通道两端是浏览器/服务器；标签 `TLS`。
- c4：红圆进入黑框压模，出来蓝方（哈希）；黄色小方块 = 盐贴在蓝方边缘；标签 `SALT + HASH`。
- c5：两个相同的红圆分别加不同黄块，压出两个不同蓝方；标签 `SALT`。
- c6：只留红圆，黑框不给通过；标签 `KNOW`。旁白“只证明此刻你知道”。
- c7：三块小黄方从短信/邮件/验证器三个方向落下；标签 `OTP`。
- c8：一条斜线从画外伸进，把其中一块黄方实时复制走；标签 `RELAY`。
- c9：蓝方里长出一把带缺口的钥匙；标签 `PASSKEY`；旁边小字 `WebAuthn`。
- c10：钥匙的缺口与黑框里的随机挑战对上；公钥留在服务器一侧，私钥在蓝方内；标签 `PUBLIC KEY`；背景给一个错位的假框，标注 `ORIGIN`。

## session（1:06–1:47）

- s1：三栏骨架再次出现，`MEMORY` 一栏被红框选中；标签 `REMEMBER`。
- s2：一条请求线从浏览器到服务器，线上没有记忆/历史；标签 `STATELESS`。旁白“HTTP 不记得上一次请求”。
- s3：服务器生成蓝色票根，装进 `Set-Cookie` 黑框信封，滑向浏览器；标签 `COOKIE`。
- s4：票根随每次请求返回；服务器一侧出现会话表网格，票根落格；标签 `SESSION STORE`。
- s5：另一条路：服务器把身份签进一条蓝色长条 token，不建表；标签 `JWT`。
- s6：token 上出现签名缺口/波纹；标签 `SIGNED`。强调“签名可验”。
- s7：token 被“打开”，内容可见；黑框外画一只眼睛，标签 `NOT SECRET`；不要画锁。
- s8：一只手（黑色斜块）拿着票根或 token；标签 `BEARER`；旁白“认票不认人”。
- s9：token 上切掉一截（短命），旧票根被剪断/换新；标签 `SHORT / ROTATE`；注销时票根变灰。

## federation（1:47–2:20）

- f1：本站黑框外出现第三个大黑框（IdP），两者之间有一条信任线；标签 `FEDERATION`。
- f2：用户从本站走到第三方；第三方框上写 `GOOGLE`（通用示意，不画真实品牌 UI）。
- f3：第三方把一枚“授权”钥匙交给本站，但不交“身份”黄三角；标签 `OAUTH = AUTHZ`。
- f4：第三方再加一层身份，黄三角与 `ID Token` 蓝条一起返回；标签 `OIDC / ID TOKEN`。
- f5：一张短命 code 票 + 一个只有 client 知道的 verifier 形状；两者对上才换 token；标签 `CODE + PKCE`。
- f6：两个黑框互交一张 assertion 票；标签 `SAML / SSO`；旁白“一次登录，多个系统”。
- f7：信任线从本站延伸到第三方，但线上有一个未合的缺口；标签 `TRUST`；旁白“只是转移信任”。

## attacks（2:20–2:52）

- a1：三栏骨架裂开三条黑线；标签 `RISKS`。
- a2：错位的假框套住真框，红圆/黄方被吸走；标签 `PHISHING`。
- a3：一叠“别处泄露的口令”纸片被倒进登录框；标签 `STUFFING`。
- a4：页面脚本黑块伸手读蓝色票根；一只 `HttpOnly` 黑盾挡住；标签 `XSS / HTTPONLY`。
- a5：画外斜块推着浏览器，自动带着 cookie 发请求；`SameSite` 黑栏挡住；标签 `CSRF / SAMESITE`。
- a6：攻击者先把一张旧票根塞进浏览器；用户登录后旧票根与攻击者黑框连上；标签 `FIXATION`。
- a7：token 蓝条被抽走；旁边一个 expiry 切口在倒计时；标签 `JWT THEFT`。

## close（2:52–3:12）

- e1：三栏骨架收拢成一块；标签 `NOT JUST A PASSWORD`。
- e2：三块形状（声明/证明/记住）拼成一个整体；标签 `CLAIM / PROOF / MEMORY`。
- e3：整体链上出现一个灰色虚线缺口；标签 `ASSUMPTIONS`。
- e4：缺口合上，黑框给出通过；标签 `VERIFY YOU`。
- e5：最终构图：红圆 + 蓝票/蓝条 + 黄三角拼成一组；标签 `CREDENTIALS`；片名小字收尾。
