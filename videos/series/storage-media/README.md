# 存储介质

从磁带到闪存，逐类讲解存储介质：一位数据在物理上是怎样被记下、又怎样被读出的。

## 定位

| | |
|---|---|
| 讲什么 | 各种存储介质的特点、历史沿革与物理底层：一位数据怎样被记下、又怎样被读出 |
| 面向谁 | 用过存储介质、想知道底下是什么的观众 |
| 怎么讲 | 深入讲解物理原理与沿革；务必严格事实核查，容量、密度、寿命等参数逐项给出处并注明口径与日期；统一视觉风格与节奏 |
| 每集多长 | 第 1、3 集约 15 分钟，第 2 集约 9 分钟 |

## 连续性

同一系列的各集保持一致的做法记在这里：首集制作时定下来，后续各集遵守；要改就先改这里。各项的含义见 [docs/series.md](../../../docs/series.md)。标为「建议」的是起点，不是限制：每集按题目增删、合并、调整比重。

| 项 | 约定 |
|---|---|
| 标题 | 待首集确定 |
| 结构（建议） | 物理原理 → 一位数据的写入与读出 → 寻址与读写机构 → 容量与速度的演进 → 局限，以及它被什么取代 |
| 衔接 | 各集按年代先后排列，结尾引出下一种介质；容量、密度、速度用同一套单位与同一种比例图，便于跨集比较 |
| 视觉与声音 | 待首集确定；定下后写回这里，并把可复用的源码整理成系列基座 `_base/`。首集方向见下 |

**首集视觉方向（2026-10-18，待关键帧确认）。** 第 1 集 [`magnetic`](magnetic/) 拟用 NASA 朋克：浅灰/米白测试台、面板接缝/铆钉、黑白功能图案、全大写小号标签、四色复古彩条（`#4C5A68`、`#7A7F4E`、`#D2A85E`、`#A8432F`）、圆形任务徽章、一处红色强调（`#D63A2C`）、轻微使用痕迹。磁带/硬盘/软盘画成可拆硬件；容量用同一套对数标尺跨集比较。完整规范见 `magnetic/src/design/STYLE.md`。关键帧选定后再把上表的「视觉与声音」改成正式约定，并把可复用部件整理成 `_base/`。
