# 存储介质

从磁带到闪存，逐类讲解存储介质：一位数据在物理上是怎样被记下、又怎样被读出的。

## 连续性

同一系列的各集保持一致的做法记在这里：首集制作时定下来，后续各集遵守；要改就先改这里。各项的含义见 [docs/series.md](../../../docs/series.md)。标为「建议」的是起点，不是限制：每集按题目增删、合并、调整比重。

| 项 | 约定 |
|---|---|
| 标题 | 待首集确定 |
| 结构（建议） | 物理原理 → 一位数据的写入与读出 → 寻址与读写机构 → 容量与速度的演进 → 局限，以及它被什么取代 |
| 衔接 | 各集按年代先后排列，结尾引出下一种介质；容量、密度、速度用同一套单位与同一种比例图，便于跨集比较 |
| 视觉与声音 | 待首集确定；定下后写回这里，并把可复用的源码整理成系列基座 `_base/` |
