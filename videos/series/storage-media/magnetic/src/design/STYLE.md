# 视觉系统：NASA 朋克（NASA-punk）

本片把三种磁介质画成一台 1970 年代航天级存储测试台：白色/浅灰的硬件、接缝、铆钉、功能图案、全大写小号标签、一道复古彩条、一枚任务徽章，再加一点使用痕迹。风格是**NASA 朋克**：七十年代航天的功能美学，加上复古彩条、磨损和标签。

这份文件是设计方向，不是最终 `style.css`。实现时按本文件写 `src/css/style.css`，并把 `project.json` 的 `check.style.palette/fonts` 改成这里的值。

## 1. 一句话与设计命题

**一句话：** 把磁带、硬盘、软盘摆在一张航天测试台上，用飞行手册的方式拆开：每一位数据写在哪、磁头怎么找到它、容量为什么能长大。

**设计命题：** 磁存储是“机械 + 材料 + 伺服”的工程。画面要像工程师的工作台/测试架：面板可以拆，接缝可见，标签是给机器和人看的；每个数字都有单位、口径和来源。不是复古电脑，不是霓虹科幻。

## 2. 色彩

| Token | 色值 | 用途 | 约束 |
|---|---|---|---|
| `--np-paper` | `#ECE5D6` | 主底色（浅灰米白） | 大面积；像真实设备外壳 |
| `--np-white` | `#F7F3E8` | 面板高光/纸张 | 少量 |
| `--np-ink` | `#1C1E1B` | 字、线、编号 | 主色 |
| `--np-gray` | `#4C5A68` | 彩条第一色、结构线 | 中性 |
| `--np-olive` | `#7A7F4E` | 彩条第二色、军绿标签 | 中性 |
| `--np-sand` | `#D2A85E` | 彩条第三色、警示前提示 | 中性 |
| `--np-rust` | `#A8432F` | 彩条第四色、旧漆/锈迹 | 只做小面积 |
| `--np-red` | `#D63A2C` | 唯一鲜艳强调色 | 只给最重要的按钮/标记 |
| `--np-steel` | `#8C8F86` | 螺丝、金属边 | 小面积 |
| `--np-black` | `#111111` | 黑白斜纹/方块 | 功能图案 |

规则：

- 底色是白/浅灰，不是黑；这是与卡带未来主义最明显的区别。
- 四色彩条 `#4C5A68 → #7A7F4E → #D2A85E → #A8432F` 是身份元素，出现在面板边缘/封面/章节卡；不要把它变成彩虹渐变。
- 整张图只留**一种**鲜艳强调色：红 `#D63A2C`；只给最重要的按钮、记录灯或“不要擦除”标记。四色条纹是低饱和的，不算第二种强调色。
- 功能图案用黑白：斜纹、方块、箭头、同心圆；每个图案都要有功能含义，不是装饰。
- 平涂；可以用 1px 硬边高光/暗边表示面板厚度，但不要柔和渐变/大投影。

## 3. 字体与字号

可用字体：`Inter`（瑞士风格无衬线，替代 Helvetica/Univers）、`Sans SC`（Noto Sans SC）、`Mono`（JetBrains Mono，标签/编号）。

| 层级 | 字体 | 字号（1080p） | 用法 |
|---|---|---|---|
| 片名/大编号 | `Inter` 800 / `Sans SC` 900 | 160–300px | 片名、`MAGNETIC`、年份 |
| 主陈述 | `Sans SC` 700 / `Inter` 700 | 84–120px | 一句结论 |
| 面板标题 | `Inter` 700 + 全大写 + 字距 0.06em | 32–40px | `TAPE PATH`、`HEAD STACK` |
| 功能标签 | `Mono` 700 + 全大写 | 22–28px | `STOW 84S`、`THIS SIDE UP`、`DO NOT ERASE` |
| 正文 | `Sans SC` 400 / `Inter` 400 | 32–38px | 解释 |
| 数字/单位 | `Mono` 500 | 28–44px | 容量、转速、年份 |

标签小、全大写、靠左，贴在控件/部件旁边；不要把所有标签做成同一种胶囊。中文用 Sans SC；拉丁/数字用 Inter 或 Mono。

## 4. 版面

- 12 栏面板网格；每个面板有 1–2px 接缝，接缝里露出更暗的底；面板四角可有铆钉/螺丝。
- 面板可以像真实设备一样“拆开”：上半是总览，下半是剖面；左右不对称，留出测试台的空白。
- 细线（1px 黑/灰）画结构、尺寸线、箭头；粗线（3–4px 黑）只给主分隔。
- 标签贴在部件旁边，带引线/箭头；编号用 `01`、`02` 或 `A-12`。
- 一屏最多一个“最大字”；容量数字可以大，但不要和片名抢。
- 字幕条仍在 y≥968；面板内容不要伸进去。

## 5. 图形语言（全片不破例）

| 图形 | 含义 | 画法 |
|---|---|---|
| 四色彩条 | 本系列的身份 | 四条等宽横条，贴在面板边缘/封面；不渐变 |
| 圆形任务徽章 | 本集/系列标记 | 同心圆 + 简化的磁带/盘片轮廓 + 年份；不要写太多字 |
| 磁带路径 | 磁带怎样走 | 两个卷轴、导轮、磁头、压带轮；箭头标方向；标签 `THREAD`、`STOW` |
| 盘片/磁头堆 | 硬盘结构 | 剖面：主轴、盘片、磁头臂、音圈；尺寸线标间隙 |
| 软盘剖面 | 软盘结构 | 方形外壳、快门、轮毂、写保护缺口；标签 `WRITE PROTECT` |
| 容量标尺 | 容量比较 | 对数刻度/条形读数；单位写清 MB/GB/TB；同一套比例跨集使用 |
| 黑白斜纹 | 禁止/擦除/危险 | 只给 write-protect、erase、no-go 区域 |
| 黑白方块 | 对齐/校验 | 只给磁道/扇区/校准标记 |
| 红色按钮/灯 | 最重要的动作 | 一屏最多一处；例如 `REC`、`ERASE`、`DO NOT POWER OFF` |
| 手写便签 | 使用痕迹 | 小纸片/胶带，写 `DON'T ERASE`、日期；不要遮挡关键读数 |
| 划痕/掉漆 | 使用痕迹 | 细线/小色块，轻微；不要脏到看不清 |

不要用霓虹、全息、发光蓝线、圆角玻璃面板；这不是“未来飞船 UI”，是“1970 年代 NASA 测试台”。

## 6. 动效

- **面板装配**：面板从边缘滑入/翻下，硬停；接缝在最后一帧对齐。
- **磁带穿带**：带子沿路径“穿”过导轮/磁头，卷轴开始转；路径上的箭头依次亮起。
- **盘片/磁头**：盘片匀速转；磁头臂按磁道步进，硬停；寻道有 1–2 帧过冲。
- **容量标尺**：条形/刻度逐格跳，数字跟着跳；不要平滑增长。
- **剖面展开**：外壳像手册插图一样“掀开”，内部结构线先出现，再填部件。
- **镜头**：沿测试台做 dolly/推近；站与站之间移动，停留时不往复。
- **转场**：面板合拢/翻开、纸带刷过、四色彩条扫过；不用整屏淡入淡出。
- 仪表/数字 12fps 步进；卷轴/盘片可以连续转。

## 7. 声音

- 继电器“咔”、电机启动/停止、磁带穿带的机械声、盘片主轴的低频、磁头寻道的短促“哒”、纸张翻动。
- 关键动作（记录、擦除、寻道、穿带）各有不同声音；不要用 whoosh 代替机械声。
- 配乐：低频脉冲 + 金属打击 + 短波电台式的稀疏音符；节奏稳定，信息密集段加一层 tick；不要大混响 pad。
- 旁白出现时音乐让位；音效不盖过旁白。

## 8. 与系列的关系

这是「存储介质」系列第一集。系列说明的「视觉与声音」原本写“待首集确定”；本集把它定为 NASA 朋克，并把可复用的部分整理成系列约定：

- 容量、密度、速度用同一套单位与同一种比例图；后续光盘、闪存集沿用同一标尺。
- 四色彩条与圆形任务徽章作为系列身份；每集可以换徽章内的图形，但不换彩条顺序。
- 面板/接缝/功能标签的语法沿用；不要下一集换成卡带未来主义。
- 结尾引出下一种介质（光盘），但不提前讲完。

## 9. 封面

- 16:9：浅灰测试台，左侧三种介质（磁带/盘片/软盘）像硬件一样排开，右侧黑色标题与四色彩条；红色只给一个记录灯。
- 4:3：上方测试台、下方标题；重新排，不裁切。
- 主标题字高约为画面高度的 1/5；缩到 360px 宽仍读得清。
- 底部 15% 不放字；任务徽章放角落，不抢标题。

## 10. 禁止

- 不要霓虹发光、全息投影、大面积渐变、深色星空背景。
- 不要圆角半透明面板、毛玻璃、胶囊标签。
- 不要卡带未来主义的米色塑料 + 绿字 CRT 当主视觉（那是另一集）。
- 不要把所有东西装进同一种“白卡片”；面板要有接缝、铆钉、功能分区。
- 不要为了“复古”而伪造不存在的型号/编号；画面上的编号要么是真实型号，要么明确标“示意”。
- 不要把手写便签/划痕做成满屏噪声，遮住读数。

## 11. 验收清单

- [ ] 底色是白/浅灰，不是黑；与卡带未来主义并排看能一眼区分。
- [ ] 四色彩条顺序正确，且没有变成渐变。
- [ ] 整张图只有一处红色强调；红色不用于普通装饰。
- [ ] 每个功能图案（斜纹/方块/箭头）都有含义，不是贴纸。
- [ ] 标签全大写、小号、贴部件；中文正文可读。
- [ ] 容量数字有单位、口径、来源；同一套比例图跨集可复用。
- [ ] 磨损/手写痕迹轻微，不遮挡关键读数。
- [ ] 缩到一半，标题、容量、标签仍可读。

## 12. 可直接给 AI 的描述

用 NASA 朋克（NASA-punk）风格设计，参考 70 年代 NASA 的规范手册和《星空》的界面。底色用白色或浅灰 `#ECE5D6`，像一台真的航天设备；画面用细线分成面板，留出接缝和铆钉。加入功能性的图案和标签：黑白警示斜纹、全大写的小号编号与方向标注（如 `STOW 84S`、`THIS SIDE UP`），用等宽字体或加宽的无衬线字体（Inter / Noto Sans SC）。身份元素用一道四色复古彩条（`#4C5A68`、`#7A7F4E`、`#D2A85E`、`#A8432F`）或一枚圆形任务徽章。整张图只留一种鲜艳的强调色（红 `#D63A2C`），只用在最重要的按钮或标记上。最后加一点使用痕迹：轻微划痕、贴纸、手写的提醒，但不要脏到看不清。把磁带、硬盘、软盘画成可拆的硬件：卷轴/导轮/磁头、盘片/磁头臂、快门/轮毂/写保护缺口；容量用同一套对数标尺。不要霓虹发光、不要全息投影、不要大面积渐变、不要卡带未来主义的绿字 CRT。
