# 编程语言

每集讲一门编程语言：它为什么出现、长什么样、有哪些与众不同的设计，以及解释器或编译器怎样把源码变成运行结果。实现部分是每集的重心。面向会写程序、没有读过语言实现的观众。

## 连续性

同一系列的各集保持一致的做法记在这里：首集制作时定下来，后续各集遵守；要改就先改这里。各项的含义见 [docs/series.md](../../../docs/series.md)。标为「建议」的是起点，不是限制：每集按题目增删、合并、调整比重。

| 项 | 约定 |
|---|---|
| 标题 | `编程语言——<副题>`，副题点出这门语言最值得讲的一点 |
| 结构（建议） | 简介 → 历史 → 快速上手 → 特性 → 实现 → 你知道吗。各栏的做法见下文；栏目可以增删、合并或调整比重，保留的栏目沿用同样的名称与先后顺序 |
| 演示与取证 | 各集用同一道小题的不同语言版本做演示（首集确定），便于横向比较；实现部分以该语言真实实现的源码与实测数据为准，注明版本 |
| 视觉与声音 | 待首集确定；定下后写回这里，并把可复用的源码整理成系列基座 `_base/` |

## 各栏的做法

| 栏目 | 做法 |
|---|---|
| 简介 | 一个能体现这门语言特点的小程序和它的运行结果，先给出具体印象，再说它用在哪里 |
| 历史 | 只讲与设计取舍有关的节点：为解决什么问题而生，哪几个版本改变了语言的面貌。不做编年 |
| 快速上手 | 从安装到运行第一个程序，全程实测 |
| 特性 | 挑两到四个最能代表设计思想的特性，每个配一段可以运行的代码 |
| 实现 | 一段源码从文本到执行结果的全过程：词法与语法分析、中间表示或字节码、执行、内存管理。全集的重心，时长占比最大 |
| 你知道吗 | 两三条有出处的冷知识，放在收尾之前 |

栏目随题目调整的例子：C 一集的「实现」讲的是编译、链接与运行时；PHP 一集要多出「一次请求的生命周期」；历史很短或与实现密不可分的语言，可以把「历史」并入「简介」或「实现」。

片单里记有这组栏目（`videos/catalog.json` 的 `sections`）：新建分集时 `new.js` 据此生成章节草稿，`check.js` 在栏目缺失或顺序不同时给出提示，但不据此判定不通过。
