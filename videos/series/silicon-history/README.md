# 电子发展史

按厂商与产品线梳理处理器和显卡的发展：每一代改了什么、为什么这样改、结果如何。

## 连续性

同一系列的各集保持一致的做法记在这里：首集制作时定下来，后续各集遵守；要改就先改这里。各项的含义见 [docs/series.md](../../../docs/series.md)。标为「建议」的是起点，不是限制：每集按题目增删、合并、调整比重。

| 项 | 约定 |
|---|---|
| 标题 | `<厂商>——<产品线或时代>` |
| 结构（建议） | 时代背景与对手 → 逐代产品（架构、工艺、关键指标）→ 转折点 → 小结，引出下一段 |
| 衔接 | 同一厂商的各集按时间衔接；指标口径全系列统一（工艺、核心数、频率、功耗、发布时间），数据逐项给出处；时间线全系列共用一种画法 |
| 视觉与声音 | 待首集确定；定下后写回这里，并把可复用的源码整理成系列基座 `_base/` |
