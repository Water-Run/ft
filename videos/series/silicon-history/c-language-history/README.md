目标观众已有的知识：写过至少一种语言（不必是 C），知道变量、函数、指针的大致含义；知道 C 是一种系统语言、历史上与 UNIX 绑在一起。不需要读过标准文本，不要求知道任何版本号或标准编号。

看完应能回答的一个核心问题：C 语言这几十年的每一次版本更替，是为了解决什么具体问题？换句话说，今天写 C 时遇到的那些「C 的老毛病」，各自是从哪一次更替里来的、又是被哪一次更替治好的？

逐章怎样推进问题、最后回答什么：
- open —— 交代对象与年代：1968 年 Bell Labs 有一台只有 8K 个 18 位字内存的 DEC PDP-7，UNIX 就写在这上面；C 是为它而生的系统语言。给出本片路线。
- ch1 从 B 到 C —— 回答「C 从哪来」：BCPL → B → NB → C；类型系统、指针与结构体；1973 年夏用 C 重写 UNIX 内核。
- ch2 K&R 与事实标准 —— 回答「C 靠什么传遍世界」：1978 年的第一版《The C Programming Language》成了事实标准，但没跟上实际用法。
- ch3 为什么需要 ANSI C —— 回答「标准化是为了什么」：1983 年 X3J11 成立；1989 年底产出 ANSI X3.159-1989；唯一的真正语言改动是函数原型。
- ch4 C99 —— 回答「1990 年代要修什么」：移除隐式函数声明、加 `//` 注释、可变长数组、`long long`、`_Bool`、复合字面量与指定初始化器。
- ch5 C11 —— 回答「多线程时代要补什么」：并发与内存序、原子、`_Generic`、`_Static_assert`、`_Alignof`、匿名结构体、移除 `gets`。
- ch6 C17 —— 回答「为什么有一版几乎没有新东西」：只有缺陷修正与澄清，`__STDC_VERSION__` 是 201710L。
- ch7 C23 —— 回答「二十年没动之后改了什么」：`nullptr`、`constexpr`、`typeof`、`auto` 类型推断、二进制字面量、`_BitInt`、`#embed`、属性、关键字化。
- ch8 C2y：进行中 —— 回答「标准现在走到哪」：第六版，`__STDC_VERSION__` 还是 202ymmL 占位；草案 N3886 已收进具名循环、case 范围、`_Countof` 等改动，尚未出版。
- ch9 标准是怎么定出来的 —— 回答「这些改动是谁怎么定的」：WG14、N 编号论文、澄清请求与变更请求、会议、认领人、ISO 的阶段码。
- outro —— 回到核心问题：每次更替都是对上一版不足的定点修补，标准因此是加法而不是重写。

本片决定不讲的材料及理由：
- C++ 的历史 —— 属于「编程语言哲学」系列与本系列其它各集的范围；本片只在函数原型与 outro 两处用一句带过「语法借自 C++」并说明本片不展开。
- 具体编译器与实现的内部（pcc、lint 的算法、gcc 的实现）—— 属于实现机制，不服务于「每次更替为了什么」这条主线；lint 只在解释「K&R 描述不够精确」时用一句带过。
- UNIX 自身的历史分支（System V、BSD）与 UNIX 战争 —— 与 C 的标准演进无直接因果，删去以免打断时间线。
- C 标准库的逐个函数 —— 只在标准自身认为「库与语言同等重要」这一点上提一句，不做清单。
- 逐条讲解 C99/C11/C23 的全部新增特性 —— 每版只讲三到五项有明确理由的改动，其余以清单形式留在画面上供查阅，旁白不念。

## 视觉系统

<!-- 颜色、字体、图形语言、转场；全片保持的约定（同一个图形只有一个含义）。 -->
<!-- 使用的参考作品、来源、借鉴方法与本片的设计选择；未使用外部参考则写明。不得直接抄袭现成产品。 -->

- **取材**：视觉语汇一律取自本片真正讲的对象自己的材料。配色与版式取 ISO/IEC 目录条目页（标准编号、状态、阶段码的排布）；表格与年表取 WG14 官方项目页（版本、出版、对应草案三列，以及里程碑年表）；条款体例取 C 标准草案封面的 `ISO/IEC 9899:202y (en) — Nxxxx working draft` 与 `§` 编号标题；变更清单取标准附录 M 的 Change History 排版。
- **颜色**：中性纸白作底，深墨作正文色，只用一种强调色标出「这一版改了什么」；强调色在两版之间保持不变，避免每章换色造成同质化的刷屏感。
- **字体**：中文用系统无衬线；版本号、条款号、草案编号与代码用等宽，保证 `X3.159-1989`、`__STDC_VERSION__` 一类串不错位。
- **图形语言**：一个图形只有一个含义——**时间轴**永远画成同一条横轴，版本节点用同一种方块；**标准文档**永远画成同一册带编号的书；**一次编译期判定**永远画成同一条竖线加一个钩子。
- **转场**：章节之间用镜头沿时间轴推进完成，不整屏擦除；换章允许一次淡入。
