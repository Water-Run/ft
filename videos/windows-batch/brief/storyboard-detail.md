# 分镜细化（制作者用）

依据 `brief/04-storyboard.md`；坐标是 world 坐标（镜头在 `x=960, y=484, z=1` 时 world 坐标 = 画面坐标）。
内容区 1920×968（`y ≥ 968` 是字幕条）。左文件、右屏幕；当年 = Pixel 字，今天 = Mono 字。
时间点一律写 `T(句号, 词)`；本文件里的秒数只是 `node tools/timeline.js` 的当前值，供估算用。

新增的样式类（写在 `style.css` 末尾的「场景自用」之后）：

| 类 | 用途 |
|---|---|
| `.hl` | 行内琥珀底（文件里的 `%n%`、引文里的 `NOT being removed`） |
| `.mini` | 小一号的纸（「读入后的样子」），无行号 |
| `.y-pixel` / `.y-grot` | 时间轴的年份刻度（Pixel 84px / Grot 900 84px）；片尾两个年份用行内 font-size 放大 |
| `.mono-note` | 引一行源码用的 Mono 30px 说明 |
| `.floppy` 与子元素 | 5.25 英寸软盘图形（墨色盘身 + 纸色圆孔 + 读写槽），`data-name="软盘"` |
| `.wrap` | 插入代码行用的可增长包裹层（`overflow: hidden`，高度由补间控制） |
