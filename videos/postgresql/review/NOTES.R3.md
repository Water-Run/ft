## 优势与统计各自能支持什么

57.9% 是 Stack Overflow 当年数据库题全部答题者的开发使用比例，题目可多选；不是全球数据库市场份额，也不是逐个用户从 MySQL 迁移的数量。

“默认选择”在稿中表述为**新项目有理由优先评估的候选**。技术能力、工具和采用案例给出工程解释；调查只证明该样本中的广泛使用，没有提供各项优势对使用率的因果权重。对照章没有宣称所有这些功能均为 Pg 独有，也没有声称 MySQL 所有现有应用应迁移。

比较分两层：b2–b5 是存储与维护机制；b6 开始比较整套数据库的组合与采用路径。MySQL 本身也支持 JSON 和空间数据；InnoDB 只是它的存储组件，不能遗漏 MySQL 上层能力后制造优势。
