## 0. 与系列约定的关系

保留不动（系列说明「连续性」表的常驻元素）：字幕带与秒尺在底部，秒尺按全片 96 秒刻度且走过的变朱红；左上角剩余秒数，最后 5 秒逐秒跳；120 拍/分与每秒一声秒针；定长时间线；语速。

**只换视觉系统**：底色、玻璃卡、参数类别的图形语言、本片的右上角仪表。

## 1. 核心比喻与它的落点

讲解对象本身是**一份参数表**——模型仓库里那份真实的配置文件与模型页上那张参数表。玻璃是这份参数表所处的介质：一张压在玻璃底板上的纸，玻璃有厚度、有折射，纸上的墨在玻璃下面被微微拉长。

因此全片只有一个玻璃底板，参数表是压在它上面的一张真实排版的纸。镜头始终能看到这张纸的边缘 —— 随便截一帧，画面里都有一张**看起来像参数表的文档**（YAML 键值、字段名、等宽数字、表格），这就是 F16 要的身份标识。

**玻璃不能盖住内容**。玻璃是介质，不是滤镜：表上的字始终是深色、实心、高对比，不允许被模糊、折射或半透明面板压住。液态玻璃的表现集中在卡的**边缘、厚度、投影和它下面的底板**。

## 2. 底色与光

| 项 | 取值 | 说明 |
|---|---|---|
| 底板 | 深墨到冷灰的垂直渐变 `#0b0f14` → `#151b23` | 不是纯黑；有冷调，玻璃的折射才有东西可折 |
| 环境光 | 一条从画面左上斜下的宽光带，落在玻璃底板上 | 全片位置固定，只有强度随场景微调（范围 ±8%，不许乱跳） |
| 卡片纸面 | 暖白 `#f4f1ea` | 卡片是纸，不是玻璃。玻璃感全部来自它的周边 |
| 强调色 | 朱红 `#ff4a1c` | 沿用系列朱红，只给「此刻读到的那一行」和结论。整屏朱红仍只用于片名卡与结论卡 |
| 次强调 | 玻璃的青色折射 `#5cc8d8`，低饱和 | 只出现在玻璃边缘与高光，不进文字 |

## 3. 液态玻璃卡片怎么做

一张玻璃卡由四层构成，从下到上：

1. **厚度**：卡片下方的偏移体，比卡片本身大 6–10px，模拟玻璃的厚度边，边缘做亮/暗双线（受光侧亮、背光侧暗）。
2. **模糊**：卡片**背后**的内容被高斯模糊（模拟隔着玻璃看）。卡片本身的正面不模糊。
3. **折射边缘**：卡片四边内缩 3px 的一圈亮边，亮边随环境光方向固定（左上亮、右下暗），不做旋转扫光。
4. **高光**：一条斜 45° 的柔和高光带，斜切过卡片，位置由环境光决定，全片不逐卡乱动。

**动效**：玻璃卡入场时是一滴液体落到位置上摊平 —— 摊平时有轻微过冲（overshoot ≈ 6%），表面张力回弹一次后稳定。退场时反向收拢。摊平过程 0.45 秒，缓动 `power2.out`，落到 0.25 秒节拍格上（`config.js` 的 `Q()`）。

**禁止**：卡片整体半透明到看不清底下；外发光；hover/浮动式的循环微动；所有卡用同一种入场（有的从下方滴落，有的从侧面滑入，方向与该行在表上的位置一致）。

## 4. 参数类别与「玻璃」的对应

图形语言：一个图形在全片只有一个含义，用到底。

| 参数类别 | 对应的玻璃形态 | 为什么 |
|---|---|---|
| 参数量（总参数 / 激活参数） | **薄玻璃片**，几乎透明，贴着纸面上方 | 一个数，贴在标牌上的一层薄标签 |
| 结构参数（层数、隐藏维度、注意力头数） | **厚玻璃块**，实心、有明显厚度边 | 模型的骨架，有分量 |
| 上下文长度 | **裂纹玻璃**：厚，但表面有一道斜向裂痕，裂痕末端是一点朱红 | 它是硬边界，超出即截断；裂痕只在这一类出现，不复用 |
| 词表与 token | **磨砂玻璃**：模糊最强，数字浮在磨砂后面 | 你写的字与模型数的 token 隔着看，换算关系本身是模糊的 |

四个形态**只在全片这一处**用作参数类别识别。正文里再出现这四类时（`r1`、`c2`），用同一组形态的缩略图标，不换新图形。

参数的口径陷阱（总参数 ≠ 激活参数、参数量 ≠ 能力）属正文的边界章：用对应形态的缩略图标加一句正文点明，**不新增第五种形态**，也不给它单独的玻璃卡。

## 5. 右上角仪表

系列约定要求右上角放一个「与题目有关、全片都在走的读数」。本集用：

**一张缩小的参数表轮廓，四行从上到下竖排，读到哪一行哪一行就点亮。**

- 位置与尺寸沿用基座 `config.js` 的 `hud-r` 容器（右缘离画面 60px）。
- 表格轮廓本身始终在，不消失；只有当前行的点亮状态在变 —— 与正文的推进是同一个状态，不另设动画。
- 当前行点亮用朱红 + 一次玻璃高光扫过（0.3 秒），点过的行留一层 30% 不透明的亮，其余为暗玻璃。
- 全片 96 秒里它一直可读，观众随时知道「读到哪了、还剩几行」。它不用来数秒 —— 数秒由左上角的剩余秒数负责。
- 最后 5 秒时，四行全部点亮。

## 6. 字体与字号

沿用系列阶梯：拉丁文字 Inter、数字与数据用 Mono、中文用 Sans SC。文档版面（YAML、字段名、表格、代码）里的英文一律 Mono，与正文区分。

正文 1080p 下不小于 38px，注解不小于 28px，卡片内的英文原文按终端规则 40–56px。先看缩小一半的总览图。

## 7. 本片镜头

- 全片一个连续空间：镜头在**一张**参数表上方与内部移动，不换面板、不换屏。
- 「逐行读」这一段，镜头的纵向推进与右上角仪表的点亮同步 —— 镜头往下走一行，仪表亮一行。
- `rT` 停顿（两个数字后的 1.9 秒）期间镜头**完全停住**，不推不摇。这是 F04 的硬要求：这 1.9 秒里画面上只有两个数字和它们的原文。
- `oT` 片名卡（2.6 秒）与 `cT` 结论停顿（1.2 秒）同样静止。
- 停留时不做往复平移（P6）。

## 8. 禁用

- 深色渐变 + 光斑 + 点阵 + 暗角 + 噪点这类「模板化科技感」的堆叠（[docs/standards.md](../../series/docs/standards.md) 第 2 节）。本片的渐变是有方向的环境光，不是背景装饰。
- 半透明圆角面板把所有东西装进卡片里。玻璃卡只用于**参数表本身**与参数类别标识，不用于字幕带、常驻元素、说明文字。
- 胶囊标签、小菱形图标、全大写宽字距的英文注脚。
- 撞色高亮 + 外发光。
- 居中对称、四平八稳的布局。
- 「刷一下」的擦入擦出与换面板。逐行推进靠镜头下移 + 仪表点亮，不是靠整屏刷。
- 所有元素同一种「淡入加上移」。
- **任何说明性小字**（F15）：不加「示意」「按原文重建」「代写」这类标注。表上的免责声明就是它本来的样子，来源一行署名即可。

## 9. 参考与原创

本片不使用外部视觉参考作品。玻璃、裂痕、磨砂这几种形态是按模型参数表这一对象自己设计的，不照搬任何现成产品的设计系统、图标或动效。字体与配色沿用本仓库系列的「计时盘」基座（朱红 `#ff4a1c`、纸色 `#f2efe8`、墨色 `#0c0d0f`），冷调玻璃底板与青色折射是本集新增的部分。

## 10. 本片的闸门配置与理由

策划者 2026-10-19 就《96 秒速通模型卡》拍板：**本集关掉 `check.style.flat`，真做折射玻璃**；2026-10-20 改题重规划时确认**继续沿用**。这是 XX 秒速通系列里第一集破例——此前六集（含 dense-vs-moe、harness、web-login、pistol-shooting 等视觉例外）都保留了 `flat: true`，只扩调色板、必要时去掉 `no_radius`。

因此 `project.json` 的 `check.style` 是这样定的，受托模型照此执行：

| 项 | 取值 | 说明 |
|---|---|---|
| `flat` | `false` | 本集允许 `gradient(`、`blur()` / `backdrop-filter`、`box-shadow` / `drop-shadow`。液态玻璃的底板渐变（第 2 节）、卡片背后的高斯模糊与磨砂（第 3、4 节）、投影（第 1 节）三者都要用 |
| `no_radius` | `false` | 玻璃卡是圆角矩形。`border-radius: 50%` 本来就在豁免之列，但圆角矩形不是 50%，所以整条放开 |
| `palette` | 在系列五色外补 `#0B0F14`、`#151B23`、`#F4F1EA`、`#5CC8D8` | 前两个是底板渐变的起止色，`F4F1EA` 是卡片纸面，`5CC8D8` 是玻璃折射的青色。**画面上不得出现调色板以外的任何十六进制色值**，闸门按字面比对 |

**仍然生效的硬规则**（这几条不受本次破例影响）：

- **颜色只能用 CSS 变量里的调色板值，不得写 `rgb()` / `rgba()` / `hsl()`。** 第 5 节说的「点过的行留一层 30% 不透明的亮」请用 `opacity` 属性或一个调色板内的实色实现，**不要用 `rgba(..., 0.3)`**——闸门按正则禁掉这三个函数。
- 不得用 emoji 与装饰符号。
- 字体只用 `Sans SC` / `Inter` / `Mono`；文档版面里的英文按第 6 节用 Mono。
- 画面仍必须只由时间决定：不得用 CSS `transition` / `animation` / `@keyframes`、定时器、系统时间、时间线回调或未固定种子的随机数。玻璃的摊平、回弹、高光扫过一律用引擎的补间写成时间的纯函数。
- 第 8 节的禁用项照旧，其中「深色渐变 + 光斑 + 点阵 + 暗角 + 噪点」仍禁——本片只允许第 2 节那条**有方向的**环境光渐变。
