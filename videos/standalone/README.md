# 独立片

独立片是一组高质量的特别片子：每部都是独立的、精良制作的高质量成片，不属于任何系列，也不靠系列撑场面。各片在 `videos/standalone/<片>/`；片单与阶段见[片单](../README.md)。

策划者原话（2026-11-07）：

> 独立视频是精良制作的高质量, 吸引人的视频, 参考垃圾回收的艺术

> 富有质感和升华

> 落盘文档, 之后的独立片除非特别说明, 都是3D. 独立片是高质量的特别系列哈, 每个视频都是独立的高质量成片

> 配色, 画面之类的不够冷静严谨, 过于花哨, AI味太重.
> 再次深度打磨一下视觉, 形式服从内容, 服从叙事的基础. 不要故意为炫技而炫技, 而是有质感的在背后承托(这个精神也要落盘文档)

## 定位

- **讲什么**：一个值得单独成片的题目，讲透一件事，并让人愿意看完。
- **时长与语言**：每部各自在片单条目与本片 README「简报」里定；缺省只做中文。
- **标准**：在仓库[质量标准](../../docs/standards.md)之上，内容、文案、画面、声音都按「独立的高质量成片」要求，不以「能讲清楚」为止。

## 共同约定

1. **缺省 3D，但 3D 是承托。** 画面以立体的场景、物体与镜头运动为主，不做纯平面排版；策划者对某一部特别说明时从其说明。立体用在本身有空间含义的东西上（摊开比较的几样东西、堆叠的层次、随数据变高的量），镜头平稳，冷静严谨；不为炫技加光晕、彩色玻璃、发光线条与无意义的旋转（[宗旨](../../docs/principles.md)「内容大于形式」）。3D 用 CSS 3D（`perspective`、`transform-style: preserve-3d`）或 WebGL（先 `node kit/tools/glprobe.js <视频>` 探测，渲染加 `--gpu 1`），状态仍只由 t 决定（[场景与动态](../../docs/guides/scenes.md)）。质感需要的投影、渐变与景深是本片的风格选择：`new.js` 新建独立片时 `check.style.flat` 为 `false`，不要再改回平涂。
2. **吸引人，有质感，有升华。** 叙事是核心：开场给出具体的现象和贯穿全片的问题；章与章之间由上一章留下的问题推动；措辞口语、有画面感，但每句都能在本片 `research/FACTS.md` 找到出处；结尾回到开头的问题作答，再往上走一层，落在人能带走的东西上。修辞服务于结构，不拿成语、对仗与金句堆「文学性」（[经验规则](../../docs/lessons.md) F01、F28）。
3. **参照片。** 策划者点名的参照是[《垃圾回收的艺术》](garbage-collection/)：读它的文案与成片，学讲法，不照搬句子、画面与配乐。
4. **每部从头设计。** 视觉系统、配乐与讲法为本片的对象重新建立（F21）；不沿用上一部独立片的配色、部件或曲子。
