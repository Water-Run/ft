# 怎么打手枪？

一部中文、英文双语独立片，以高级 3D 画面详细介绍手枪射击。片长为几分钟，不再沿用速通系列的 150 秒定长约束。

制作流程与标准见仓库的 `docs/`；片中每一句陈述的出处见 `research/FACTS.md`。

## 简报

2026-11-04，策划者 WaterRun 的原话：

> 怎么打手枪? 抽离为独立片, 3D, 高级, 几分钟, 详细的介绍手枪射击.

据此从「XX 秒速通」抽离为独立片。核心问题是：从射击前的准备与握持，到瞄准、扳机控制、击发、后坐和复位，一次完整的手枪射击应当怎样完成，各步为什么这样做。内容应详细、完整，不再按速通片压缩；具体时长在文案与审片阶段确定。

看完应能回答的一个核心问题：一次完整的手枪射击应当怎样完成，准备、握持、瞄准、扳机控制、击发、后坐与复位各起什么作用。

逐段怎样推进、最后回答什么：以一次完整射击为主线，从射击前准备进入动作细节，再解释击发瞬间与击发后的控制，结尾回到安全、稳定、可重复地完成一次射击。章节还没有写。

## 视觉系统

已定方向为高级 3D，尚未画进场景。体积、透视、景深与镜头运动要参与解释握持、瞄准、击发、后坐和复位，而不只是装饰。保留此前确定的强节奏与冲击方向；旁白保持客观语体。

此前参考《赛博朋克：边缘行者》的高饱和、强对比、广角、低角度与逐帧错色，只作为表现方向的记录，不照搬角色、夜之城或片中图形。具体 3D 美术与技术方案在关键帧阶段确定。

当前场景仍是旧计时盘基座，三维还没做。用 WebGL 画三维时，状态只由时间决定：先跑 `node kit/tools/glprobe.js`，渲染加 `--gpu 1`（见 `docs/guides/scenes.md`）。

目录里的颜色仍是旧基座的墨色 `#0C0D0F`、纸色 `#F2EFE8`、朱红 `#FF4A1C`。实现时替换调色板、画面、配乐与常驻元素；速通系列的定长时间线、语速、秒尺、剩余秒数和 120 拍均不再是本片的约定。
