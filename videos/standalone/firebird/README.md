## 设计

三个方向（立体手册 / 层叠纸剧场 / 海报手册）与三张封面的探索稿见审片页，源文件 `src/design/kf.html`，取材见 `research/MATERIALS.md`。

策划者选定（2026-11-09）：视觉「AB有机融合 内容偏A 封面偏B」；封面「如上」，即偏 B；配音 `Arrogant_Miss`（嚣张小姐），MiniMax speech-2.8-hd，语速 1.2（试听语速，全片再按实测调）；配乐 C（Motorik 电子摇滚）。

配乐小样 `tools/music_sketch.py`：共同动机取自名字，FIREBIRD 中可作音名的字母为 F、E、B、D。

重置版（2026-11-10，按上面的意见整片重做，r8 起）：

| 项 | 做法 |
|---|---|
| 运动 | 去掉全片踩拍的整层左右错动。动作只有三种来路：跟着旁白从逻辑上的方向入场；换段、换章时整页往上滚，顺着读文档的方向；镜头只在推进二楼窗户这类需要强调时动 |
| 插画 | 全部换成等距视角（2.5D）的 SVG 插画，`src/js/art.js`：人物、猫、蓝瓷砖浴室、两层小楼、客房与家具、M1 坦克、电话、钱包、硬币、沙漏、钟面、服务器等 |
| Logo 与图注 | MySQL、PostgreSQL、SQLite、Firefox、Mozilla、DEC、Ashton-Tate、Borland、SourceForge、Windows、Linux、macOS 用正式标志，名字为辅；观众多半忘了的公司加一行手册式图注（FACTS G01–G08），出处见 `research/MATERIALS.md` |
| 数据库 | 白色圆柱上印彩色 Firebird 标志，取代橙红渐变圆柱上的同色标志 |
| 读写 | 写的人在上方、橙色、铅笔，箭头流向新版本；读的人在下方、蓝色、眼睛，箭头从旧版本流出；两股同时流动 |
| 读法 | PostgreSQL 的读法由 `Postgre S Q L` 改为 `Postgres Q L`（只改 SAY 表，不改文案），重合成 o5、a5、f3、g6 四句 |

## 复盘

本机 Python 没有 scipy，配乐工具用 numpy 自写了滤波与拨弦；`look.js --url` 要求页面根元素 id 为 `stage`，Git Bash 下传 `/design/…` 路径要加 `MSYS_NO_PATHCONV=1`。

预览的静止检测（freezedetect −48 dB）按整帧的帧间差算：小图标出现、细线描出、终端里多一行字、慢慢移动的小物件都算「没动」。重置版里每 2.5 秒内至少安排一次面积够大、动作够快的变化，并且都对应旁白里的一件事（屏幕整屏变红、当前行高亮跳动、日历翻页、卡片调回等）。scan.js 读的是承载文字的元素自己的字号，写在 SVG 里或嵌在外层容器里的字会被误报成小字，重置版把这类字改成直接写在带样式的元素上。
