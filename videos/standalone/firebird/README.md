## 简报

策划者要求（2026-10-26 会话原话）：

> 既能做服务又能嵌入式, 数据库小众的第三选择: Firebird

### 制作中


本机 Python 没有 scipy，配乐工具用 numpy 自写了滤波与拨弦；`look.js --url` 要求页面根元素 id 为 `stage`，Git Bash 下传 `/design/…` 路径要加 `MSYS_NO_PATHCONV=1`。

预览的静止检测（freezedetect −48 dB）按整帧的帧间差算：小图标出现、细线描出、终端里多一行字、慢慢移动的小物件都算「没动」。重置版里每 2.5 秒内至少安排一次面积够大、动作够快的变化，并且都对应旁白里的一件事（屏幕整屏变红、当前行高亮跳动、日历翻页、卡片调回等）。scan.js 读的是承载文字的元素自己的字号，写在 SVG 里或嵌在外层容器里的字会被误报成小字，重置版把这类字改成直接写在带样式的元素上。
