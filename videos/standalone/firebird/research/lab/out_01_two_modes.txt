## 嵌入式：没有服务进程，直接建库、建表、写一行
$ isql -q
create database 'demo/shop.fdb' user 'SYSDBA';
create table t (id int, name varchar(20));
insert into t values (1, 'phoenix');
commit;
select * from t;
quit;
--- out
SQL> SQL> SQL> SQL> SQL> 
          ID NAME                 
============ ==================== 
           1 phoenix              

SQL>
