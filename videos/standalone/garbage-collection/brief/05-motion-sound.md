# 05 镜头、动作、音效与配乐

通用规则见仓库 `docs/scenes.md` 与 `docs/sound.md`。本片另外规定这些。

## 1. 镜头

- **一张纸的空间。** 全片是一张连续的纸，镜头在纸上移动与推近，不换屏、不换面板。每章之间用「镜头移到下一处」而不是整屏刷。
- **推进靠镜头，不靠刷屏。** 一段里镜头应当始终在动：极慢的推近（`z` 从 1 到 1.03–1.05）就够，但必须连续。停留时不做往复平移。
- **读数段落镜头停住。** 数字、原文、规矩这类要读的内容出现时，镜头完全停住（不推不摇），留够阅读时间。
- **网格的空间感要一致。** 同一批方格在几章之间出现时，位置与大小要能被认出是同一张纸。

## 2. 动作

- **一个动作说明一件事。** 方格落位＝对象被造出；红色竖线刷过＝清扫；指针线出现＝引用建立；颜色改变＝三色标记的推进。不要把几个机制塞进一个动作。
- **红色是稀缺资源。** 一屏最多一处红色大面积。红色出现＝收集器正在做事。其余时间是黑、米白与灰。
- **入场动作要分得出差别。** 本片可用：方格「盖章」式落位、指针线生长、颜色铺开、数字滚动、章节卡整屏换。**不要所有元素同一种「淡入加上移」。**
- **退场交代去向。** 元素退场前要让人知道它去哪了，不要一到就消失。
- **方块落位有轻微过冲**（约 6%），表面张力回弹一次后稳定；硬停，不要弹簧。

## 3. 音效

- 只给**有语义的关键动作**配音效：对象落位、指针建立、红色清扫开始、涂灰拦截、计数归零释放、拆环器出手、章节卡切换。
- **不要用默认气流声填满动作。** 慢移、阅读保持、镜头推移可以无声。
- 关键动作的音效要能被听出「这是同一类动作的同一类声音」——比如所有归零释放用同一种短促的落位声。
- 音效登记：`sfx('名字', 时刻, { g: 音量 })`。名字自取，但同一类动作用同一个名字。

## 4. 配乐

- 基座的 `tools/music.py` 可用：120 拍/分，一秒两拍，全片每秒一声「秒针」。它按场景加层，最后一个正片场景转半拍，结论处抬起。
- **配乐要有存在感。** 先有一层贯穿的低频铺底，再加动机与节奏；旋律稀疏不等于克制。段落推进靠加层，不要靠换曲子。
- 本片是「纸上讲机制」，配乐不要科幻化：不用合成器长音、不要电影预告式的鼓点、不要和画面抢注意力。基调可以是克制的机械感。
- 结论句（`h1`–`h7`）是全片的收束，配乐要在这里抬起而不是提前用完。
- 另出一版试听片（`brief/05` 的第 13 步），用另一套配乐，让策划者挑。

## 5. 混音

- 仓库默认：`music_db -12`、`duck_db 7`、`sfx_db -9`。
- 本片旁白的信息密度高，**阅读段落要真的留白**——数字、原文、规矩出现时，配乐要让位。
- 响度与真峰值按 `project.json` 的 `check` 段；`finish.js` 会在最终 MP4 上实测。
