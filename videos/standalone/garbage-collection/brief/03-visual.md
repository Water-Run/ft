# 03 视觉系统与版式规则

**你在一个定好的系统里构图，不要另起一套。** 规则来自 `research/STYLE.md`（策划者已批），实现是 `src/css/style.css`。闸门按字面比对：色板外的颜色、`rgb()/rgba()/hsl()`、渐变、阴影、圆角、emoji、系统字体名都过不去。

## 1. 颜色

| 变量 | 值 | 用途 | 约束 |
|---|---|---|---|
| `--sw-black` | `#111111` | 字、活对象、粗线 | 主色 |
| `--sw-paper` | `#F4F1EA` | 底色 | 米白，不是纯白 |
| `--sw-red` | `#DA291C` | 收集器做出决定的那一刻 | **唯一强调色**，一屏最多一处大面积 |
| `--sw-gray` | `#8A8A8A` | 已扫描、中性信息 | 中性 |
| `--sw-light` | `#D9D5CC` | 网格线、分隔 | 细线 |
| `--sw-white` | `#FFFFFF` | 反白块、死对象内部 | 少量 |

规则：只用这 6 个值。红色**只表达「收集器正在判断/移动/回收」**，不表示错误或警告——一屏没有收集动作就不出现红。全部平涂，无阴影、无渐变、无纹理、无圆角。

## 2. 字号阶梯

| 层级 | 类 | 字号 | 用法 |
|---|---|---|---|
| 巨型标题 | `.sw-display` | 320px | 片名、章节的大数字 |
| 标题 | `.sw-title` | 180px | 一句话结论 |
| 主陈述 | `.sw-stmt` | 120px | 一句结论 |
| 次级 | `.sw-sub` | 60px | 解释 |
| 正文 | `.sw-body` | 38px | 正文 |
| 注解 | `.sw-cap` | 28px | 图注、来源 |
| 小字 | `.sw-micro` | 22px | 编号、图注 |
| 等宽 | `.sw-mono` | — | 数字、地址、代码、指针值 |

只使用 Regular 与 Bold 两种字重（`.sw-display`/`.sw-title` 的 900 属 Bold 档）。标题极大、正文很小，一屏只允许一个「最大字」，最大字至少是最小字的四倍。

字体：拉丁字用 Inter，中文用 Sans SC，数字与代码用 Mono。不要写系统字体名（`sans-serif`、`monospace` 等会被闸门拦下）。

## 3. 版式

- 12 栏网格，左右边距 120px，栏间距 24px（`.sw-grid` 与 `.sw-col*`）。
- 文字一律左对齐、右边不齐。不要居中，不要两端对齐。
- 不对称构图：大标题偏左，图解偏右，留出一整块空白。
- 用 1px 细线分隔区块（`.sw-rule`），大区块之间用空白，**不要用卡片**。粗线 2px（`.sw-rule-bold`）只给主分隔。
- 编号 `01`–`05` 放在章节左上；年份用小字放在标题下方或图注。
- 字幕带在 y≥968 之下，正文不要压到字幕上。

## 4. 部件的类名与用法

| 类 | 画的是什么 | 怎么用 |
|---|---|---|
| `.sw-cell` | 一个对象 | 黑方块＝活 |
| `.sw-cell-dead` | 死对象／未标记 | 白底黑框 |
| `.sw-cell-scan` | 已扫描但未定 | 灰 |
| `.sw-cell-red` | 收集器正在处理的对象 | 红，一屏最多一处 |
| `.sw-ptr` + `.sw-ptr-head` | 指针／引用 | 2px 黑线 + 小而尖的箭头；不用曲线 |
| `.sw-sweep` / `.sw-sweep-h` | 收集器的清扫动作 | 4px 红色竖线／横线，速度恒定 |
| `.sw-gen-0/1/2` | 分代色带 | 浅／灰／黑，不用彩色 |
| `.sw-idx` | 编号 | 小号等宽 |
| `.sw-year` | 年份 | 大号数字 |
| `.sw-rule` / `.sw-rule-bold` / `.sw-vrule` | 分隔线 | 1px 细、2px 粗、1px 竖 |
| `.sw-red` / `.sw-gray` / `.sw-paper-t` / `.sw-white-t` | 文字颜色 | 直接加在文字类后面 |
| `.chapter` | 章节卡 | 整屏墨色、字为米白、编号为红（红压墨色对比度约 4:1，只用于 56px 以上的大字） |

细网格（堆的地址空间）用 SVG 的 `<line>` 画，颜色取 `var(--sw-light)`——本片禁用渐变，不能用 `linear-gradient` 铺。

## 5. 图形语言

一个图形在全片只有一个含义，用到底：方格＝对象，线＝指针，红色＝收集动作，灰＝已扫描，色带＝分代。

**不要用**卡通垃圾桶、扫帚、机器人这类插画。GC 的图形必须是可数的格子、线、箭头。

## 6. 禁用的做法

- 深色渐变 + 光斑 + 点阵 + 暗角 + 噪点这类「模板化科技感」的堆叠。本片只有一条**有方向的**环境光渐变都不允许。
- 半透明圆角面板把所有东西装进卡片。玻璃感不在这套系统里。
- 胶囊标签、菱形图标、全大写宽字距的英文注脚。
- 撞色高亮 + 外发光。
- 居中对称、四平八稳的布局。
- 「刷一下」的擦入擦出与换面板。推进靠镜头下移与仪表点亮。
- 所有元素同一种「淡入加上移」。
- **任何说明性小字**（F15）：不加「示意」「按原文重建」「代写」这类标注。

## 7. 字幕

`#caption span` 40px、墨色字压米白底；强调用红色（`#caption em`）。字幕由引擎画进画面，宽度上限 26 字宽（本片正文每句已按 24 字宽断好句）。

## 8. 片尾

`gCredit` 是静默 cue（`pause: 14`、`credits: true`、无 `tts`、无字幕）。名单按 `research/FACTS.md` 的「制作署名」，展示「开源视频」与完整可读的 `github.com/Water-Run/ft`。
