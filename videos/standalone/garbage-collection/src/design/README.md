# 本目录：受托模型放关键帧与示范场景

**这里原本由准备方放参考关键帧与一段示范场景。2026-10-20 策划者决定：关键帧、分镜构图与场景实现全部由受托模型（Opus 5.5）自己做，准备方不预置任何版面样张。**

理由：关键帧是审美判断。准备方预置版面等于替受托模型把构图定死，既压缩他的发挥，也可能把一次不成熟的审美当成规格。准备方交的是**约束**，不是成品。

## 你要在这里交什么

| 文件 | 内容 | 什么时候做 |
|---|---|---|
| `keyframes.html` | 三到四张静态版面：片名版面、信息最密的一屏、图解、章节卡。用本片真实的 `src/css/style.css` 排，不另起一套。 | 第 1 步之后、铺开场景之前 |
| `scene-demo.js` | 一段十来秒的示范场景：信息最密的一小段，用到镜头移动、两三种入场动作、打字机或逐字显示、音效登记。写到 `src/js/scenes/` 后可直接被 `index.html` 加载。 | 同上 |

## 你必须遵守的约束

- 视觉系统：`src/css/style.css`（色板、字号阶梯、12 栏网格、部件类名）与 `research/STYLE.md`（规则与禁用项）。
- 闸门：`project.json` 的 `check` 段。色板外的颜色、`rgb()/rgba()/hsl()`、渐变、阴影、圆角、emoji、系统字体名都被脚本挡住。
- 事实：画面上的数字、代码、原文只能来自 `research/FACTS.md`，逐条编号在 `src/js/script.js` 的 `facts` 字段。
- 逐句对应：`expect.zh.json` 写明每句说完时画面上必须出现的文字。那是**要出现什么**，不是**怎么摆**；摆法由你定。
- 冲击点：`research/STYLE.md` 第 13 节是策划者「震撼、艺术、冲击感」要求的落点清单（准备方的提案）。每一章要有一个说得出名字的主画面；具体怎么演由你决定，改动在 `DELIVERY.md` 里说明。
