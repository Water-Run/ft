# 视觉系统：瑞士风格（Swiss Style / International Typographic Style）

本片把内存画成一张可以逐格检查的表格：对象是格子，指针是线，GC 是编辑手上的红笔。风格是**瑞士国际主义**：看不见的网格、中性的无衬线字、左对齐右不齐、大片留白、黑/米白加一个高饱和红。

这份文件是设计方向，不是最终 `style.css`。实现时按本文件写 `src/css/style.css`，并把 `project.json` 的 `check.style.palette/fonts` 改成这里的值。

## 1. 一句话与设计命题

**一句话：** 用一张严格的网格和一支红笔，把“哪些对象还活着、哪些可以被收回”讲成一件可数、可核对的事。

**设计命题：** GC 的难点不是“删除”，而是“判断”。画面要让人看到判断的依据：roots、指针、可达性、标记位、代际、写屏障。所有判断都落在网格上，红色只在“收集器做出决定/移动对象”的那一刻出现。

## 2. 色彩

| Token | 色值 | 用途 | 约束 |
|---|---|---|---|
| `--sw-black` | `#111111` | 字、活对象、粗线 | 主色 |
| `--sw-paper` | `#F4F1EA` | 底色 | 米白，不是纯白 |
| `--sw-red` | `#DA291C` | 收集器的动作/决定 | **唯一强调色**；一屏最多一处大面积 |
| `--sw-gray` | `#8A8A8A` | 已扫描/中性信息 | 中性色 |
| `--sw-light` | `#D9D5CC` | 网格线、分隔 | 细线/淡块 |
| `--sw-white` | `#FFFFFF` | 反白块、死对象内部 | 只在需要时 |

规则：

- 只用黑、米白、灰、红；不要第二种彩色。
- 红色只表达“收集器正在判断/移动/回收”，不表达“错误”或“重要”。如果一屏没有收集动作，就不出现红。
- 全部平涂；无阴影、无渐变、无纹理、无圆角。
- 网格线用 1px `--sw-light`；重要分隔用 2px 黑线。
- 大面积留白是构图的一部分，不是“没做完”。

## 3. 字体与字号

可用字体：`Inter`（新怪诞无衬线，替代 Helvetica/Neue Haas Grotesk）、`Sans SC`（Noto Sans SC）、`Mono`（JetBrains Mono，用于地址/代码/数字）。

| 层级 | 字体 | 字号（1080p） | 用法 |
|---|---|---|---|
| 巨型标题/年份 | `Inter` 700 / `Sans SC` 700 | 180–420px | 片名、`1960`、`01` |
| 主陈述 | `Inter` 700 / `Sans SC` 700 | 96–140px | 一句结论 |
| 次级陈述 | `Inter` 400 / `Sans SC` 400 | 56–64px | 解释 |
| 正文 | `Inter` 400 / `Sans SC` 400 | 34–38px | 正文、注解 |
| 小字/编号 | `Inter` 500 / `Mono` 500 | 22–28px | 年份、地点、图注、来源 |
| 代码/地址 | `Mono` 400 | 32–44px | 指针地址、字段、日志 |

只使用 Regular 和 Bold 两种字重；不要 Light/Black 混用。标题极大、正文很小，形成强烈对比。拉丁字用 Inter，中文用 Sans SC；数字可用 Inter 或 Mono。

## 4. 版面

- 12 栏网格，左右边距 120px；所有元素边缘对齐网格线。
- 文字一律左对齐、右边不齐；不要居中，不要两端对齐。
- 不对称构图：大标题偏左，图像/图表偏右或反；留出一整块空白。
- 用 1px 细线分隔区块；大区块之间用空白，不用卡片。
- 编号 `01`–`07` 放在章节左上；年份/地点用小号字放在标题下方或图注。
- 一屏只有一个“最大字”；最大字至少是最小字的 4 倍。
- 字幕条仍在 y≥968；不要把正文压到字幕上。

## 5. 图形语言（全片不破例）

| 图形 | 含义 | 画法 |
|---|---|---|
| 方格 | 一个对象/一块内存 | 黑方块=活；白底黑框=死/未标记；灰=已扫描但未定 |
| 细线 + 箭头 | 指针/引用 | 黑色 2px 线；箭头小而尖；不要曲线 |
| 红色竖线/红块 | 收集器的动作 | 标记、清扫、搬动的那一刻；一屏最多一处 |
| 红色数字 `0` | 引用计数归零 | 只在引用计数章节；表示“可以收回” |
| 横向色带 | 分代 | 01 年轻 / 02 中年 / 03 老；用灰阶区分，不用彩色 |
| 两列方格 | copying / semispace | 左 from、右 to；红色箭头只在搬动时出现 |
| 大年份 | 历史 | 1960、1970、1978、1983；小字写事件 |
| 细网格 | 堆的地址空间 | 只在需要定位时出现；不要当背景装饰 |

不要用“卡通垃圾桶”“扫帚”“机器人”这类插画；GC 的图形必须是可数的格子、线、箭头。

## 6. 动效

- **网格先出现**：细线从左到右画出，然后方块“盖章”落位；不要淡入。
- **方块落位**：1–2 帧过冲，硬停；不要弹簧。
- **红色标记**：像盖章/划线，一次到位；不要发光。
- **清扫**：红色竖线从左扫到右，经过的未标记方块变成白底黑框；速度恒定。
- **复制**：方块沿直线搬到另一列，原位置留一个细虚线框（forwarding pointer）；不要飞曲线。
- **分代**：色带从下往上堆，老代在上；切换代时硬切，不要滑动。
- **镜头**：在网格上平移/推近，站与站之间移动；停留时不往复。
- **转场**：用网格线合拢/拉开、红色块刷过、纸张翻页；不用整屏淡入淡出。

## 7. 声音

- 节拍器/秒针、纸张翻动、印章“啪”、铅笔划线、短促的机械咔哒。
- 红色动作配“盖章”声；清扫配连续的纸带/划线声；复制配一声短促的滑动。
- 配乐：极简的脉冲 + 低频钢琴/马林巴，节奏稳定；信息密集段加一层高频 click；不要用大混响 pad。
- 旁白出现时音乐让位；音效不盖过旁白。

## 8. 与系列/体量的关系

这是独立片，没有系列视觉约束。体量按“数分钟、循序渐进”定；视觉系统本身要能支撑 5–8 分钟，不靠不断换版式。网格、字号阶梯、红色语义在全片保持一致。

## 9. 封面

- 16:9：米白底，左侧巨大黑色标题（两行），右侧一张由黑/灰/白方块组成的堆图；红色只给一个“被划掉”的方块。
- 4:3：上方标题、下方堆图；重新排，不裁切。
- 主标题字高约为画面高度的 1/5；缩到 360px 宽仍读得清。
- 底部 15% 不放字；用细线和小号年份/副标题点缀。

## 10. 禁止

- 不要渐变、阴影、噪点、纸张纹理、圆角卡片。
- 不要居中、不要两端对齐、不要四平八稳的对称。
- 不要装饰插画、图标堆叠、彩色高亮。
- 不要第二种强调色；不要把红色当“错误/警告”用。
- 不要“深色科技背景 + 发光方块”；本片是纸上的黑与红。
- 不要把所有内容装进卡片；用网格和留白组织。

- [ ] 一屏只有一个最大字，且至少是最小字的 4 倍。

## 13. 震撼、艺术与冲击感（2026-10-19，按策划者要求补）

策划者要求全片“震撼、艺术、有冲击感”，配音“俏皮、妩媚、有艺术感，赛博活泼”（MiniMax 傲娇御姐音色）。冲击不靠换风格，靠把这套系统推到极端：更大的字、更硬的切、更少的东西、更准的时刻。每章只允许一个“冲击点”，其余画面安静，给它让路。

| 章 | 冲击点 | 做法 | 声音 |
|---|---|---|---|
| 开场 | `67,000,000` | 数字从 0 以可见速度滚到六千七百万，占满整屏宽；格子纸在它身后以同样速度被填黑 | 计数 tick 加速成一片噪声，到数后骤停 |
| 开场 | 内存耗尽 | 格子纸全黑的一瞬，整屏切成一行等宽字 `System.OutOfMemoryException`，再并排压出 PHP、Java、Node 的报错原文（四行，各一色阶的灰） | 一声硬停（无混响）；之后半秒静音 |
| 开场 | 136 次 | 同一张格子纸，这次红色竖线以每秒 136 次的节奏刷过，纸始终只有一小块是黑的 | 刷纸声连成嗡鸣，旁白“程序一个字都没管”时音乐留白 |
| 01 | `1 → 2 → 3 → 2 → 1 → 0` | 对象的前 8 字节放大到整屏，只改那一位数字；归零时数字变红，方块当场变白 | 每次变化一声 tick，归零一声印章 |
| 02 | 28 → 14 MB | 一条内存曲线横跨整屏，一次断崖式下落；曲线下方是 Lua 的真实回显（b9） | 下落时一声长划线 |
| 03 | 三代 | 三条色带从下往上堆，一个黑方块逐级跳上去：`0 → 1 → 2`，第三次不动（d4 后留 0.7 s） | 两声“咔哒”，第三次静默 |
| 04 | 黑指白 | 整屏只有两个方块和一条线：黑方块伸出一条线指向白方块，红笔把线划断、把白方块涂灰——这是全片唯一一次“红线被改灰”（e7a–e8，e8 后留 1.0 s） | 划线声；规矩句 e8 出现时全部停 |
| 04（铺垫，不是冲击点） | 419 步 | 02 章那条曲线补上步数轴：前 300 步纹丝不动，之后断崖（e13–e14） | 标记段只有节拍器 |
| 04（章尾重音） | 11 字节 | `.NET` 的四条指令以巨型等宽字竖排：`lea` / `call CORINFO_HELP_ASSIGN_REF` / `nop` / `ret`（e16–e17）；紧接的 e20“程序员一行都没写”时它们全部变红 | 四声短促咔哒 |
| 05 | 账单 | 黑底反白：一张只有三行的账单——计数、追踪、所有权 / 手动——各在哪里付钱；这是全片唯一一次黑底 | 低频铺底升到最高，然后落回 |
| 收束 | 脚注 | 麦卡锡脚注的英文原文以打字机节奏出现，中文译文在下方跟进；h5–h6 连读，h6 之后停满 2.5 s | 只有打字声，无配乐 |

规则：

- 冲击点之间的画面要“空”：一句旁白配一个元素，留白占屏幕一半以上。震撼来自对比，不来自密度。
- 大数字与报错原文都用真实回显的原文，不美化、不改字体；冲击感来自“这是真的”。
- 旁白的俏皮在声音里，不在画面里：画面不加表情符号、感叹号、手绘箭头。
- 可选的“赛博”变体：把整套色彩反转——`#111111` 底、`#F4F1EA` 字、红不变——其余规则不动，仍无发光、无渐变。是否采用由策划者定（见 `review/NOTES.md` 取舍）。
- 配乐按 F06 的新要求有存在感：一层贯穿的低频铺底（以 MyISAM 一集为参照），冲击点前半秒抽走、冲击点上砸回。

## 12. 可直接给 AI 的描述

用瑞士国际主义风格（Swiss Style / International Typographic Style）设计。12 栏模块化网格，所有元素边缘对齐网格线。字体用新怪诞无衬线体（Inter 或 Noto Sans SC），只用 Regular 和 Bold 两种字重；标题极大、正文很小，形成强烈的大小对比。文字一律左对齐、右边不齐，不要居中，不要两端对齐。不对称构图，留出大面积空白。配色只用黑 `#111111`、米白 `#F4F1EA` 和一个强调红 `#DA291C`，全部平涂，不要阴影、渐变、纹理和装饰插画。把内存画成方格：黑方块是活对象、白底黑框是死对象、灰是已扫描；红色只表示收集器的标记/清扫/搬动。用细线分隔区块，用 01、02 这样的编号和小号年份点缀。不要卡片、圆角、发光、第二种彩色。
