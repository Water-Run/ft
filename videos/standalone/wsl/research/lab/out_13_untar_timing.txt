# wslc 各子命令的用法（供 14 使用）
PS> wslc import --help
导入 tarball 的内容以创建文件系统映像。可以选择使用存储库和标记名称标记映像。
使用情况: wslc import [选项] <file> [<image>]
别名:
  wslc image import, wslc import
参数:
  file   文件或 - 从 stdin 读取
  image  图像名称
选项:
      --no-trunc  不截断输出
  -?  --help      显示选定命令的帮助信息
'wslc' 的全局选项:
      --session   指定要使用的会话

PS> wslc run --help
运行容器。默认情况下，容器在前台启动；使用 --detach 在后台运行。
使用情况: wslc run [选项] <image> [<command>] [<arguments>...]
别名:
  wslc container run, wslc run
参数:
  image      图像名称
  command    要运行的命令
  arguments  要传递到容器初始化进程的参数
选项:
      --cidfile              将容器 ID 写入提供的路径
      --cpus                 CPU 数(例如 0.5、1、2.5)
  -d  --detach               在分离模式下运行容器
      --dns                  resolv.conf 中 DNS 名称服务器的 IP 地址
      --dns-option           设置 DNS 选项
      --dns-search           设置 DNS 搜索域
      --domainname           容器域名
      --entrypoint           指定容器初始化进程可执行文件
  -e  --env                  环境变量的 Key=Value 对
      --env-file             包含环境变量 key=value 对的文件
      --gpus                 Add GPU devices to the container ('all' to pass all GPUs)
      --health-cmd           检查容器运行状况的命令
      --health-interval      运行状况检查的运行间隔时间(例如 30s, 1m30s)
      --health-retries       报告容器运行不正常所需的连续失败
      --health-start-period  容器在运行状况检查倒计时之前初始化的开始时间段(例如 30s, 1m30s)
      --health-timeout       允许一次运行状况检查运行的最长时间(例如 30s, 1m30s)
  -h  --hostname             容器主机名
  -i  --interactive          附加到 Stdin 并保持其打开状态
      --ip                   在网络上为容器分配一个 IPv4 地址
  -l  --label                在对象上设置元数据
  -m  --memory               内存限制(例如 512M、1G)
      --mount                将文件系统挂载附加到容器
      --name                 容器的名称
      --network              将容器连接到网络
      --network-alias        为容器添加网络范围的别名
      --no-healthcheck       禁用任何容器指定的运行状况检查
  -p  --publish              将端口从容器发布到主机
  -P  --publish-all          将所有已公开的端口发布到随机主机端口
      --pull                 映像拉取策略(always|missing|never) (默认: missing)
      --rm                   在容器停止后将其移除
      --shm-size             /dev/shm 的大小(例如 64M、1G)
      --stop-signal          停止容器的信号
      --stop-timeout         在终止容器前停止容器的超时时间(以秒为单位)(-1 表示无超时)
      --tmpfs                将 tmpfs 装载到给定路径处的容器
  -t  --tty                  使用容器进程打开 TTY。
      --ulimit               Ulimit 选项 (格式： <name>=<soft>[:<hard>]，使用 -1 无限制)
  -u  --user                 进程的用户 ID (name|uid|uid:gid)
  -v  --volume               将装载卷绑定到容器
  -w  --workdir              容器内的工作目录
  -?  --help                 显示选定命令的帮助信息
'wslc' 的全局选项:
      --session              指定要使用的会话

PS> wslc system session --help
管理 WSL 容器会话，包括列出活动会话和启动交互式 shell。
使用情况: wslc system session [<命令>] [选项]
命令:
  enter      输入临时会话。
  list       列出会话。
  run        在会话中运行命令。
  shell      附加到会话。
  terminate  终止会话。
有关特定命令的更多详细信息，请向其传递 help 选项。 [-?]
选项:
  -?  --help     显示选定命令的帮助信息
'wslc' 的全局选项:
      --session  指定要使用的会话
