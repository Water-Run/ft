# 道交法中的路权

**2026-10-09：已建立中文项目，取证与 Opus 开工资料已准备；进入文案阶段，尚未审稿、配音或制作成片。** 原排期 10 月 11 日，按 WaterRun 本日要求提前到今天；其余选题不替换。周计划见 [TODO](../../../docs/todo.md)。

面向中国大陆普通机动车驾驶员。核心问题：**出现通行冲突时，依据现场控制和交通关系，怎样判断该让谁、何时停止或通行？** 仅中文，无英文配音、字幕或交付版。独立片初始预算 8–10 分钟、上限 600 秒，供写稿取舍，不靠填充达到下限。

## 接续入口与材料

- Opus 从 [AGENTS](AGENTS.md) 开始，接续取证、写中文稿与分镜方案，再依既有流程交审、制作。
- [FACTS](research/FACTS.md)：事实边界、逐条条件、证据状态、常见错误与未决事项。
- [来源登记](research/sources.json) 与 [采集清单](research/lab/source_snapshot_manifest.json)：官方直达链接、版本、读取范围、原文 SHA-256 与真实失败记录。
- [法条摘录](research/lab/statutory-excerpts.json)：从法规正文快照提取，供离线核对；原始网页在不入库的 `research/_src/`。
- [场景测绘](research/SCENARIOS.md) 与 [案例数据](research/lab/cases.json)：来向去向、适用条件、让行主体、反例，均为教学示意。
- `brief/01–06`：主线、文案、视觉、分镜、声音、验收任务书。

本片处于取证阶段交接，`src/` 保留明确标记的模板。资料齐全不能记为成片已经讲清；实际接手模型先登记再署名。

## 开工反馈应用

采用 [反馈总账](../../../docs/feedback.md) **2026-10-09** 版及当日八片复盘。正面对照是 MyISAM 的过程推导、2FA 的同例贯穿、luainstaller 的明确场景；这是既有复盘归纳，不替用户编造评分理由。Codex 在预研时建立此表，Opus 接手复查，收尾逐项回应。

| 编号 | 适用性与本片计划 | 正面对照与验证办法 |
|---|---|---|
| F01 叙事偏题 | 适用。每章回答一次驾驶决策，法规史、罚款表、事故猎奇不进主线 | 学 MyISAM 围绕过程取材；审稿逐章写答案，成片标出问题与回答时间 |
| F02 缺少推理步骤 | 适用。同一 A/B 场景按条件、冲突、义务、结果展开；至少一组只变一个条件的对照 | 学 2FA 保持对象一致；正常速度能复述为何让行，记录条件与结果可读区间 |
| F03 边界太晚 | 适用。开篇说明中国大陆、普通机动车、示意；“让右”同时展示无控制条件和驾驶方向 | 学 luainstaller 先交代使用场景；交叉核对字幕、信号、车头、FACTS |
| F04 卡片刷过 | 适用。短标题稳定至少 2 秒起，内容卡 3–5 秒起，复杂条件加长，进退场另计 | 保留高分片对象连续性，不沿用其短卡缺陷；逐卡记文字全到位至退场的起止并连续播放 |
| F05 动作同质 | 适用。轨迹、冲突区和条件变化负责解释；保留道路与对象，不逐条刷走整屏 | 对照近期两部开头、换章、解释段；说明动作带来的信息，不以换色计改进 |
| F06 声音同质 | 适用。阅读、等待和缓慢镜移不默认加 whoosh；独立写动机、速度、音色与编排 | 学 2FA 内容与节奏相连；与近期两部、本片无配乐版连续试听，预设名和 LUFS 不能判通过 |
| F07 隐私与取证画面 | 适用。自绘 A/B 示意；不公开新闻车牌、当事人姓名和本机路径 | 保留真实取证，只公开必要法条与来源；查 JSON、字幕、封面、说明、最终 MP4 |
| F08 输出与记录不符 | 适用。目标中文 1080p/60 fps，交付以实际 FFprobe、音轨和哈希为准 | 保留规范记录、修正旧片记录缺陷；同一最终文件与 README、片单逐项核对 |
| F09 意见冒充事实 | 适用。官方科普也回查完整条款，地方口径不扩成全国规则 | 保留原评分；FACTS 写出处、日期、条件和未决项；发布后以实际链接读反馈 |

## 复现预研检查

在仓库根目录执行，不配音、不渲染：

```sh
python videos/standalone/traffic-law-right-of-way/tools/gen_data.py
python videos/standalone/traffic-law-right-of-way/tools/check_research.py
node kit/tools/catalog.js --check
```

公开网页采集用 `research/lab/collect_sources.py`，可用 `--only L02 G01` 指定来源。法条摘录由 `research/lab/extract_statutes.py` 从原文生成；新机器先采集或复制忽略的原文并核对哈希。实际检查见 [preparation-check.txt](research/lab/preparation-check.txt)，环境摘要见 FACTS。自动检查只验证结构、引用与数据一致，不判断法律结论、叙事或视听质量。
