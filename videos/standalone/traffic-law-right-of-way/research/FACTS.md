# 道交法中的路权：事实与证据

取证日期：**2026-10-09，UTC+8**。对象：中国大陆全国性道路通行规则，面向普通机动车驾驶员，仅中文。该范围是用户指定的创作边界；不把港澳台或其他法域规则混入，也不凭本片判断个案责任。

本文件是事实主账。来源、摘录、案例是证据及制作输入，不另立相互矛盾的事实版本。尚无成片文案，R 编号先对应研究陈述；Opus 写稿后补 `cue → R 编号`，字幕、标题、图形与封面同样映射。

## 1. 证据口径与环境

规范原文决定规则；公安机关的具体应用、解释及法院案例用来核对实际含义。**同一法条被两个网站转载不算独立印证**，执法清单单纯抄引条文也不能自动算第二个独立解释。新闻中省略的限制须回到完整条款补齐，不能用科普短句覆盖法规。

状态：**已交叉核查**表示正文与独立适用材料相符，可按本表边界起草；**归纳**表示由已核规则推导的教学表述，不冒充法定原话；**待补证**表示原文已读但独立适用依据不足，不能进入定稿；**版本待核**或**图样待核**只完成注明范围。所有陈述交审前和成片后仍须复核。

法律资料通过官方公开 HTML 原文读取，另以 Python urllib 保存原始字节与提取文本，无登录、无浏览器凭据。登记 27 个来源，当前 HTTP 原文归档成功 22 个；L01、L03V、G03、G04、G08 在网页阅读工具中可读，本地 HTTP 采集失败，**不是无内容，也不记为已归档**。完整时间、方法、失败、相对路径、SHA-256 见 [清单](lab/source_snapshot_manifest.json)。L01V 已归档法律全文，L02 已归档行政法规全文，断链时仍可离线核对。

原网页在 `research/_src/official/2026-10-09/`，不入库；法条公开文本的选段由 `lab/extract_statutes.py` 生成 [statutory-excerpts.json](lab/statutory-excerpts.json)，含原文文件哈希与条号。案例 JSON 是自拟教学示意，无真实驾驶人、车牌或精确道路测量。网页原文中的新闻个人信息不摘入公开记录。

制作环境于 2026-10-09 跑过仓库 doctor：Windows、Node 24.21.0、Python 3.14.3、Puppeteer 25.12.0、GSAP 3.13.0、Chrome 154；FFmpeg 可用，字体校验通过，约 35 GB 可用空间。未合成任何本片 TTS，音频与 cue 时长为空属当前阶段正常。其他制作任务的浏览器配置未清理。这里保存脱敏摘要，未提交含本机个人路径的原始 doctor 输出；来源采集脚本运行于 Linux Python 环境，公开记录无内网连接信息。
