# CoT：先思考，再回答

独立视频，仅中文，目标片长 **6–7 分钟**。讲大模型的思维链：为什么让模型先写出思考再给答案，它就能答对；写下的思考又是什么。

本片的阶段、署名、发布与评分记在 `project.json`，事实依据在 `research/FACTS.md`，文案只在 `src/js/script.js`。流程与规则见仓库的 `docs/`。

策划者清理要求（2026-10-23 会话）：

> 清理这些视频, 除了我人工要求落盘的, 其它清理干净, 避免干扰继续.

- **目标观众已有的知识**：用过或听说过聊天式的大模型；不需要知道 Transformer、token、强化学习，这些在片中第一次出现时讲清。
- **看完能回答的一个核心问题**：为什么让模型「先思考，再回答」，它就能答对？它写下的「思考」又是什么？
- **贯穿的例子**：一道真实的乘法 25992 × 92138（本片实验 L1 的 `n5-03`），同一个模型三种问法：只许说答案（错在中间两位）、先写过程再答（对）、先写答案再写过程（错，最后一步加成了第一行的错数）。开场三种都演出来；第 02 章、第 03 章、第 04 章与结尾回到这道题。
- **逐章推进与答案**（第 2 稿）：
  - 开场：同一个模型、同一道题，三种问法三种结果；起名 CoT；抛出全片的大问题：写出来为什么就能算对？对一台一个字接一个字往下写的机器，「思考」究竟是什么？
  - 01 一句话：这个做法从哪来（2022 年谷歌的示范题；几个月后的「Let's think step by step」）。模型没变，只多了几行字。留下问题：几行字凭什么管用？
  - 02 草稿纸：模型一次写一小块（token），每块只有固定层数的计算；只许说答案等于用四块字的工夫算完整道题，所以错在最难的中间；写下的中间结果就是草稿纸。光多写没用（S1 消融），有用的是内容；本片 100 题的数据。
  - 03 学会思考（第 4 稿起在「顺序」之前）：思维链从一句提示变成训练出来的习惯（o1、R1-Zero 与「顿悟时刻」）；本片实验：思考模式算对开头那道题并自己验算，位数越多想得越久。
  - 04 顺序：回到开头的第三次；答案先写下，过程往往去凑它（S1 消融与本片复现）；这样的过程更像事后补的解释，直接引出第 05 章。
  - 05 说出来的理由：写在前面的思考也不一定是真正的原因（S9，测的正是上一章那类模型）；人也一样（S10 丝袜实验）。
  - 结尾（第 4 稿）：再看开头那三次回答——四块字算不完、草稿让它算对、答案先定过程后补；先思考再回答能让它算得更对；它写下的思考可以是草稿，也可能像第三次那样和真正起作用的对不上，就像那条提示；所以不能全当成理由来读。
- **决定不讲的材料与理由**：自一致投票、涌现规模（约 100B）、MultiArith 等数据与主线无关或会增加名词；o1 的 AIME 数字没有读到一手原文；思维链监控与安全的讨论不展开。第 2 稿为片长与节奏再删去：S8 的「答案都排在 A」实验（第 05 章留一例模型、一例人）、S5–S7 的理论证明（只作第 02 章的依据）、R1-Zero 的竞赛题正确率；都留在 FACTS。
- **时长上限与语言**：6–7 分钟；仅中文（`["zh"]`）。
- **新名词**（第 3 稿起 3 个）：思维链（o12）、token（c1）、层（c4–c6）。「强化学习」第 3 稿不再点名，只说「答对了，就给奖励」。

审片页里的候选（2026-11-03，留作记录）：

- **视觉方向**（白底，`src/design/keyframes.html?d=A|B|C&f=1|2|3`，各三张：片名、信息最密的一屏、图解）。三者比较的是解释方法，不只是配色：
  - A「生成」：画面就是模型正在写的那一页，跟着一次生成走；思考与回答用颜色分开。
  - B「草稿纸」：同一道题的三种问法并排摊开比较，错位用荧光笔标出。
  - C「剖面」：剖开模型看一个 token 怎样算出来，层的堆叠与往回读的连线。
- **配乐**（`tools/music.py` 的三个小样，各 60 秒）：A「落字」毡音钢琴 76 拍/分；B「运算」拨弦脉冲 104 拍/分；C「长句」弦乐与钢片琴 66 拍/分。都不用鼓、铜管和合唱，也不用 kit 预设与速通系列的节拍。
- **配音**：5 个近期未用的 MiniMax 音色，语速 1.2（`tools/audition.py`）。

看听范围：9 张关键帧看过两轮（总览图与改动后的四张），修掉 B3 算式重叠、C2 标签压线、C3 token 进字幕区、A1 标题下细线戳到逗号、B2 数字拥挤；`look.js` 的版面检查无报错。配乐与配音没有亲耳听过（本会话不能听音频），只核对了数值：配乐每 5 秒的响度走向呈「引子—推进—最高处—收束」，峰值约 −1 dBFS 以内；配音的时长与语速见审片页。

**实现中的约定**（2026-11-07 起）：每场先建画布与引擎镜头（`makeCamera`，保持不动），桌面与纸张用 `src/js/parts.js` 的 `makeDesk`（`rig.track` 控制位置、倾角与远近，写法同 `cam.track`，每段自动在下一段开始前走完）、`sheet`、`tile`、`barRows`；各章是一条向右的桌面，镜头一站一站移过去，换站 1–1.4 秒，停留时只极慢横移；颜色只有墨、灰与表示「错」的朱红；纸上的标题与旁白一致；画面只放旁白讲到的内容。封面 `src/cover.html`：冷灰白底、细衬线「CoT」与「先思考，再回答」，右侧一张写着先写过程那一次草稿的纸。
