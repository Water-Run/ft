# CoT：先思考，再回答

独立视频，仅中文，目标片长 **6–7 分钟**。讲大模型的思维链：为什么让模型先写出思考再给答案，它就能答对；写下的思考又是什么。

策划者清理要求（2026-10-23 会话）：

> 清理这些视频, 除了我人工要求落盘的, 其它清理干净, 避免干扰继续.

- **目标观众已有的知识**：用过或听说过聊天式的大模型；不需要知道 Transformer、token、强化学习，这些在片中第一次出现时讲清。
- **看完能回答的一个核心问题**：为什么让模型「先思考，再回答」，它就能答对？它写下的「思考」又是什么？
- **贯穿的例子**：一道真实的乘法 25992 × 92138（本片实验 L1 的 `n5-03`），同一个模型三种问法：只许说答案（错在中间两位）、先写过程再答（对）、先写答案再写过程（错，最后一步凑回第一行的错数）。开场、第 02 章、第 03 章、第 05 章与结尾都回到这道题。
- **逐章推进与答案**：
  - 开场：同一个模型、同一道题，只差顺序，结果一错一对；起名 CoT，抛出三个问题。
  - 01 一句话：这个做法从哪来（2022 年谷歌的示范题；同年「Let's think step by step」）。留下问题：一句话为什么管用？
  - 02 草稿纸：模型一次写一个 token，每个 token 只有固定层数的计算；直接答等于用四块字的工夫算完整道题；写下的中间结果就是草稿纸。光多写点没用（S1 消融），有用的是内容；理论与本片 100 题的数据。
  - 03 顺序：步骤放在答案后面不管用（S1 消融与本片复现）；答案先写下，过程往往去配合它。「写在前面是在算，写在后面只是在解释。」
  - 04 说出来的理由：写在前面的思考也不一定是真正的原因（S8、S9）；人也一样（S10 丝袜实验）。
  - 05 学会思考：思维链从一句提示变成训练出来的习惯（o1、R1-Zero 的强化学习与「顿悟时刻」）；本片实验：思考模式题越难想得越久。
  - 结尾：回到那道题，回答核心问题，并说明边界——写下的字帮它走到答案，却未必说得清它为什么走到那里。
- **决定不讲的材料与理由**：自一致投票、涌现规模（约 100B）、MultiArith 等数据与主线无关或会增加名词；o1 的 AIME 数字没有读到一手原文；思维链监控与安全的讨论只留一句结论，不展开。
- **时长上限与语言**：6–7 分钟；仅中文（`["zh"]`）。
- **新名词**（控制在 4 个）：思维链（o9）、token（c2）、层（c5–c7）、强化学习（r7）。
