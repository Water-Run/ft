# 03 视觉系统

本片的视觉系统已定稿，样式在 `src/css/style.css`，四张参考关键帧在 `src/design/kf.html`（`?k=1` 片名、`?k=2` 文件与屏幕、`?k=3` 大数字与比例条、`?k=4` 1981 与早期终端）。用文字查看任一张：

```
node tools/look.js --url "/design/kf.html?k=2"
```

设计思路一句话：**现代主义的版式，装着一件老物件。** 版式是平涂、直角、强对比、不对称的；「老」由像素点阵字和墨色终端来表达，「今天」由等宽字和无衬线大数字来表达。

## 1. 画面与坐标

- 画面 1920×1080，左上角为原点。
- 底部 `y = 968 … 1080` 是常驻的墨色**字幕条**，内容不能放进去。**内容区是 1920×968。**
- 内容区的安全边距：左右各 96，上 56，下 40（即内容在 `x 96…1824`、`y 56…928` 之内）。故意出血到画外的大字除外（见第 5 节）。
- 12 列网格：列宽 122，列间距 24，第 n 列（n 从 0 起）的左边缘 `x = 96 + 146 × n`。元素的左边缘尽量落在列线上。

## 2. 颜色

只有这七个，全部以 CSS 变量给出。场景代码和样式里只写 `var(--…)`，不写色值。

| 变量 | 色值 | 用途 | 可以放在它上面的文字颜色 |
|---|---|---|---|
| `--paper` | `#ECE8DF` | 底色（纸） | `--ink`、`--dim` |
| `--sheet` | `#FBFAF5` | 「文件」这张纸，只用于 `.sheet` | `--ink`、`--dim` |
| `--ink` | `#0C0C0C` | 终端底色、正文字、色块、字幕条 | `--paper`、`--term`、`--lit`、`--amber` |
| `--amber` | `#FFB000` | **唯一的强调色** | `--ink` |
| `--dim` | `#6B665D` | 次要文字、行号 | —（只作文字，只放在纸色或 sheet 上） |
| `--term` | `#CCCCCC` | 终端里的普通输出 | —（只作文字，只放在墨色上） |
| `--lit` | `#FFFFFF` | 终端里被敲入或被回显的命令 | —（只作文字，只放在墨色上） |

规则：

- 琥珀色放在纸色底上时**只能做色块**（上面压墨色字），不能做文字——对比度不够。琥珀色做文字只在墨色底上。
- 一个画面里琥珀色只标一件事：此刻旁白正在讲的那个东西。不要同时有三处琥珀。
- 不用透明度做「浅色」。需要次要就用 `--dim`。

## 3. 字体

| 名称 | 字体 | 表达什么 | 用在哪 |
|---|---|---|---|
| `"Sans SC"` | 思源黑体 | 中文 | 标题 900、陈述 700、说明 500 |
| `"Grot"` | Inter | **今天** | 大数字（2026、3164、4.45%、45）、片名里的 Shell、章节号 |
| `"Pixel"` | VT323（像素点阵） | **当年** | 1981、1983、`A>`、早期 DOS 的终端与文件 |
| `"Mono"` | JetBrains Mono | 今天的代码与终端 | cmd.exe 的终端、今天的 `.bat` 文件、文件名 |

「当年的东西用像素字，今天的东西用等宽字 / 无衬线」是本片的核心视觉对照，不要混用：1981 年的终端不能用 Mono，Windows 11 的终端不能用 Pixel。

Pixel、Mono、Grot 都只有拉丁字母、数字和符号。样式里已经把它们的中文回退设为 "Sans SC"；自己写 `font` 时也照这样写（例如 `font: 900 30px/1 "Grot", "Sans SC"`），不要让中文落到系统字体上。像素字的醒目效果只对拉丁字母和数字成立，**不要指望用它写中文标题**。

## 4. 字号阶梯

只用这几档（类名在 `style.css`）。需要更大的出血大字时在元素上单独设 `font-size`。

| 类 | 字号 | 用途 | 一屏最多 |
|---|---|---|---|
| `.n-pixel` | 460（可到 760） | 当年的大数字、提示符 | 1 |
| `.n-grot` | 300（可到 400） | 今天的大数字 | 1 |
| `.t-hero` | 176（可到 200） | 片名、章节标题 | 1 |
| `.t-h1` | 104 | 一屏的主陈述 | 1 |
| `.t-h2` | 60 | 次级陈述、与大数字搭配的单位 | 2 |
| `.t-body` | 38 | 说明文字 | 3 |
| `.t-note` | 28 | 出处、标注（全片最小字号） | 2 |
| 终端 `.slab.now` | 34（Mono） | 今天的终端 | — |
| 终端 `.slab.old` | 60（Pixel） | 当年的终端 | — |
| 文件 `.sheet` | 34（Mono）/ `.sheet.old` 56（Pixel） | 文件里的代码 | — |

**每一屏都要有悬殊的大小对比**：最大的字至少是最小的字的 4 倍。一屏只有一个最大的东西。经过镜头缩放后，任何文字的实际大小不得小于 26px（`scan.js` 会查）。

## 5. 版式规则

1. **不对称。** 主体放在左侧或右侧的三分之二，不要整屏居中。大数字、大标题靠左对齐到 `x = 96` 附近。
2. **留白是内容。** 一屏不超过 3 组东西（一组 = 一个部件，或一个大字加它的说明）。宁可分两步出现，也不要挤。
3. **平涂、直角。** 色块、终端、纸张都是没有圆角、没有描边、没有阴影的矩形。区分层次靠颜色对比和大小，不靠边框。
4. **出血。** 大数字和大提示符可以有一部分伸到画外（见 `kf.html?k=1` 的 `A>`）。给这种元素加 `data-bleed` 属性，工具就不会把它报成「被切掉」。
5. **对齐。** 同一屏里的元素共用左边缘或共用顶边缘；说明文字的左边缘与它说明的东西对齐。
6. **线。** 需要线时用 6px 粗的墨色或琥珀色实线（`.rule`、`.blk`），不用细线、虚线、箭头装饰。指向关系优先用「琥珀色块把两样东西连起来」（见 `kf.html?k=2` 里从文件伸向屏幕的光束）。

## 6. 部件

### 6.1 屏幕（终端）：`.slab`

一块直角墨色平面。没有窗口标题栏、按钮、边框。

```html
<div class="slab now" style="left:1010px;top:150px;width:814px;height:500px">
  <div class="hd">Windows 11 · cmd.exe</div>            <!-- 左上角一行琥珀色说明：这是哪台机器 -->
  <div class="row"><span class="in">D:\batlab&gt;selfmod.bat</span></div>   <!-- .in：敲入或被回显的命令，白色 -->
  <div class="row">1</div>                               <!-- 普通输出，灰色 -->
  <div class="row"><span class="hi">3</span></div>       <!-- .hi：此刻要强调的，琥珀色 -->
</div>
```

- `.slab.now`：今天。Mono 34px。`.hd` 写 `Windows 11 · cmd.exe`、`Windows Server 2008 · cmd.exe` 这类。
- `.slab.old`：当年。Pixel 60px，文字是纸色。`.hd` 必须含「示意」，例如 `COMMAND.COM 的屏幕（示意）`。
- 每个 `.row` 是一行；空行也要放一个空的 `.row`。`<`、`>`、`&` 写成 `&lt;`、`&gt;`、`&amp;`。
- 终端里的内容只能来自 `research/FACTS.md` 与 `research/lab/` 的真实回显。

### 6.2 文件：`.sheet`

一张纸，上面是带行号的代码。

```html
<div class="sheet" style="left:96px;top:150px;width:760px">
  <div class="name">selfmod.bat</div>
  <div class="ln" data-n="1">@echo off</div>
  <div class="ln on" data-n="2">echo 1</div>             <!-- .on：这一行正被解释器读到，整行琥珀底 -->
</div>
```

- `.sheet`：今天的文件，Mono。`.sheet.old`：当年的文件，Pixel。
- 行号由 `data-n` 给出。
- 「正被读到的那一行」用 `.on`（配合引擎的 `classAt(行, 'on', 起, 止)`）。

### 6.3 「文件 → 屏幕」机制图

本片反复使用的核心图形：**左边是文件，右边是屏幕，琥珀色标出解释器此刻读到的那一行，并用一条琥珀色的「光束」把这一行和屏幕连起来。** s2、s3、s4 三个「痕迹」都在这张图上讲，s1 用它的像素字版本。观众看过一次就能读懂后面的。完整写法见 `src/design/example_scene.js`。

### 6.4 小部件

| 类 | 是什么 |
|---|---|
| `.tag` | 直角标签，墨底纸色字（Mono 28px）。`.tag.amber` 为琥珀底墨色字。用于给东西贴名字：`运行途中追加`、`PowerShell 1.0` |
| `.blk` | 琥珀色块（绝对定位，自己给位置和宽高）。`.blk.ink` 为墨色块。做光束、比例条、强调底 |
| `.rule` | 6px 墨色粗线。做时间轴 |
| `.cur` | 光标块（琥珀色） |

### 6.5 需要你自己画的图形

- **时间轴**（open、s1、s5 用）：一条 `.rule`，年份刻度写在线的上方或下方。1981、1983 用 Pixel 字，1993、2006、2026 用 Grot 字。批处理的存续可以画成一条从 1981 延伸到 2026 的琥珀色粗条。
- **软盘**（s3、end 用）：5.25 英寸软盘的平面图形——一个墨色正方形，中心一个纸色圆孔（`border-radius: 50%` 是唯一允许的圆角），下方一道纸色的读写槽。全部用平涂的 `div` 拼，不用图片和 emoji。给最外层加 `data-name="软盘"`。
- **比例条**（s5 用）：一条 96px 高的横条，分成琥珀段和墨色段（见 `kf.html?k=3`）。

新增的样式写在 `style.css` 末尾「场景自用」一节之后，同样只用七个颜色变量。

| 元素 | 规格 |

## 8. 封面

`src/cover.html`，两个版式：`?r=169` 为 1920×1080，`?r=43` 为 1600×1200。单独设计，不用视频截帧。

- 用同一套颜色与字体。建议以片名帧（`kf.html?k=1`）为基础：墨色底、纸色的「古代来的」与「Shell」、琥珀色的像素提示符 `A>`。
- 主标题字高不小于画面高度的 1/8；缩到 360px 宽仍能读清「古代来的 Shell」。
- 底部约 15% 不放文字（平台会在那里叠加时长与播放量）。
- 4:3 版不是把 16:9 版裁一刀，要重新摆：元素可以上下排。
- 页面就绪后要置 `document.body.dataset.ready = '1'`（模板里已有，保留并把要预载的字体改对）。
