# 热点

刚发生的技术热点，快速讲清：发生了什么、为什么严重、原理大概是什么、影响到谁、现在该怎么办。面向关心技术新闻、不一定是专业人士的观众。

## 定位

| | |
|---|---|
| 讲什么 | 刚发生的技术热点事件（首集：PHP2Shell 漏洞） |
| 面向谁 | 关心技术新闻的观众，不要求专业背景 |
| 怎么讲 | 生动形象、通俗易懂、节奏紧凑；只用核实过的新闻与官方材料，各方说法冲突时并列说出是谁说的 |
| 每集多长 | 3–5 分钟 |
