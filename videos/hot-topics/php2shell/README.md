## 简报

<!-- 立项时写，准备方或制作方都可以写。策划者在会话里提的要求，原话与日期照录在这里，优先于任何缺省做法（docs/roles.md 第 2 节）。 -->

- 目标观众已有的知识：知道网站、服务器、补丁是什么；不需要会写 PHP。
- 看完能回答的一个核心问题：**PHP2Shell 是什么漏洞，为什么让全世界的网站连夜下线？**
- 逐章怎样推进，各章的答案：
  - 开场：荷兰政府网站下线、日本首相发帖，起因是 PHP 的两个漏洞。
  - 01 它是什么：PHP 本身的两个远程代码执行漏洞，免登录，官方评 9.2 分。
  - 02 原理：访问中途被打断后，内存收回了、记录还指着它（退了房、房卡没作废）；下一次访问可能用上这份旧记录。修复：不再中途跳出、结束时清零。最早可追溯到 2012 年的 PHP 5.4，藏了 14 年。
  - 03 时间线：8 月 Calif、Wiz 发现（OpenAI 参与），10 月 20 日泄露，21 日发布修复。
  - 04 影响：各国机构建议下线；荷兰、日本、维基媒体、4chan；是否已被利用说法不一。
  - 05 怎么办：升级到修复版本；8.1 及更早官方不再更新；本片信息截止时间。
- 决定不讲的材料与理由：漏洞利用的具体路径与技术细节（片子是新闻解读，不是技术教程；也不传播攻击方法）；未经证实的传闻（如「高市早苗的网站被黑」，见 FACTS「没有进入成片的事实」）；各家对 PHP 份额、发现先后的不同说法只取有出处的一种或并列。

## 设计

策划者要求「富有节奏感的叙事, 紧张的配乐和视觉」，并要求赶工，所以没有做多方向关键帧，直接定一个方向。

- **视觉：「深夜的告警屏」。** 身份色取自 PHP 官方标志紫 `#777BB3` 与 php.net 深蓝 `#404F82`（`research/MATERIALS.md`）。危险只用一种红，「部分有效 / 说法不一」只用琥珀色，「已修复」只用绿色，全片不换义（F20）。平涂，不用渐变与装饰符号。
- **底纹**：每个场景铺一层淡网格（#1A1F44，80 px），随镜头一起动，像监控屏；暗底上缓慢的镜头漂移因此在像素上可见（成片静止段检查曾报 6 处）。
- **常驻元素**：左上「PHP2Shell + 两个 CVE 编号」，右上「信息截至 北京时间 2026-10-22 00:00」。
- **章节卡**：红色告警横幅，上下各一条琥珀黑斜纹，章节号写成 `0X / 05`。
- **每章主画面（F18）**：
  - 开场：「网站墙」，荷兰四个站点逐张盖上 OFFLINE；接着是首相的帖子（日文原文配中文释义，F11）和只剩 It works! 的浏览器窗口。
  - 01：一百格方阵点亮近七成，接远程执行示意和 9.2 分严重程度条。
  - 02：「工作进程走廊」，退房后的旧房卡打开已不属于它的房间；然后是修复两条、补丁里的「置空」一行（php-src 原文）、2012→2026 的 14 年。
  - 03：横贯的时间轴，一根红色引线从爆料一路烧到修复发布，镜头跟拍。
  - 04：头条墙，卡片文字直接取自已确认的字幕；末尾两栏并列冲突的说法。
  - 05：版本表（绿 / 琥珀 / 红）、按大版本分段的占比条、截止时间印章。
- **和近期作品的区别（F21）**：不用速通系列的纸色瑞士版式与秒尺，也不用垃圾回收一片的绿色内存条；底色、配色、章节卡与转场都为本片重做。
- **配音**：MiniMax `Chinese (Mandarin)_News_Anchor`，语速 1.2，由 WaterRun 选定（见 `review/NOTES.md`）。赶工，没有单独做试听页。
- **配乐**：本片自带 `tools/music.py`，紧张的小调脉冲，按章节编排。
- **渲染**：1080p60，GPU，运动模糊 2 个子帧（赶工，从 4 降到 2）。
