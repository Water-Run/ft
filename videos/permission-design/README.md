# 权限机制的设计

用几分钟完整讲清一个操作系统的权限机制：它试图解决什么问题、设计思想从何而来、历史上怎样演变，以及今天如何判定「谁可以对什么做什么」。覆盖 Linux、Windows、macOS、Android、iOS 与 iPadOS。

## 定位

| | |
|---|---|
| 讲什么 | 各操作系统权限机制的设计思想、历史沿革、核心模型、关键实现、使用边界与后续演进 |
| 面向谁 | 想完整理解权限机制，而不只想快速记住几个命令或开关的观众；必要概念在本集补齐 |
| 怎么讲 | 从系统要解决的现实问题出发，沿历史与一次真实访问过程解释设计取舍；不把权限简化成一串弹窗或命令，也不假设各系统只有同一套模型 |
| 每集多长 | 几分钟；不受速通系列的秒数与定长约束，具体时长按各集完整文案确定 |
| 语言 | 只做中文（缺省） |

## 共同约定

各集真正共享的约定记在这里，一项一行。视觉与配乐按各系统的对象和历史重新设计，不沿用速通系列的秒尺、剩余秒数或统一配乐。写法见 [系列](../../docs/guides/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | `<系统> 权限机制的设计`；iOS 与 iPadOS 分集独立，不合并成一条 |
| 内容完整性 | 每集都应包括设计思想、历史沿革、主体与对象、权限判定过程、关键机制、边界与常见误解；「完整介绍」不等于只讲当前版本 |
| 独立可懂 | 每集自己解释必要概念，不要求先看其他系统的一集；跨系统比较只作辅助，不替代本集机制 |
| 取证 | 版本、年份、默认行为与机制变化以一手文档、源码或可复现实验为准；历史与现行行为分开写，不能把旧机制当作今天的现状 |
| 视觉与声音 | 为本集系统设计；界面、模型图与历史材料服务于因果解释，不套用速通系列的平面计时盘 |
| 时长 | 标题不写秒数；文案确定后在各集 `project.json` 设置对应的几分钟时长范围 |

与 [Windows工作机制深入](../windows-internals/README.md) 的分工：本系列的 Windows 一集讲权限设计的整体思想、历史与完整模型；那一系列的《权限机制：令牌、完整性级别与访问控制》继续深入 Windows 内部组件与真实操作。
