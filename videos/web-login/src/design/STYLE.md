# 视觉系统：包豪斯（Bauhaus）

本片把“验证你是你”画成一组几何形状的拼接：圆、方、三角，切成一半、四分之一，像积木一样拼。风格是**今天常说的包豪斯**：红黄蓝三块纯色、黑与米白、平涂、边缘干脆、几个大形状撑起整张、字很少、字本身也当成形状。

视觉系统已落到 `src/css/style.css`；四张参考关键帧在 `src/design/kf.html`（`?f=1` 标题、`?f=2` 哈希、`?f=3` 会话票、`?f=4` 因子/WebAuthn）。`project.json` 的 `check.style.palette/fonts` 已按本文件设置。场景实现仍归受托模型。

## 1. 一句话与设计命题

**一句话：** 身份不是一张脸，而是一组能拼合的形状；登录就是验证这组形状能不能拼成同一个图案。

**设计命题：** 把抽象概念变成可拼的几何：你知道的东西、你拥有的东西、你本身，各是一个形状；密码是单向压制，会话是盖了章的票，token 是带签名缺口的长条，WebAuthn 是带缺口的钥匙，OAuth 是三个形状传递一枚令牌。形状的“能不能拼上”就是验证的视觉隐喻。

**选的是哪一种包豪斯：** 风格卡给了两种做法——今天常见的红黄蓝几何感，和 1920 年代德绍印刷品（白纸、黑为主、红色只做一两处强调）。本片选前者：认证因子需要三种颜色区分“知道/拥有/本身”，几何拼合也比黑白印刷更能承担“验证动作”的叙事。没有使用名叫 Bauhaus 的 1975 年圆胖字体，也没有复刻红黄蓝三角圆方的通用海报。

## 2. 色彩

| Token | 色值 | 用途 | 约束 |
|---|---|---|---|
| `--bh-red` | `#E2412C` | 秘密/凭证（口令、私钥、令牌） | 纯色块；不要渐变 |
| `--bh-yellow` | `#F2C230` | 用户/声明（“我是谁”） | 纯色块；大面积时字用黑 |
| `--bh-blue` | `#2F57B0` | 通道/会话（TLS、cookie、session） | 纯色块；大面积时字用米白 |
| `--bh-black` | `#111111` | 验证者/系统/边框 | 线、字、框架 |
| `--bh-paper` | `#F1ECE1` | 米白底 | 主底色 |
| `--bh-white` | `#FFFFFF` | 反白/留白 | 少量 |

规则：

- 三原色不必每屏都凑齐；一屏最多三块大色，另加黑与米白。
- 颜色是“概念标签”，不是装饰：红=秘密，蓝=会话/通道，黄=用户/声明，黑=验证者/系统。全片不破例。
- 平涂，边缘干脆；不要渐变、阴影、圆角、描边发光。
- 字压在色块上时先算对比度；黄底用黑字，蓝底用米白字，红底用米白/黑字要实测。

## 3. 字体与字号

可用字体：`Inter`（几何无衬线，700/800）、`Sans SC`（Noto Sans SC，700/900）、`Mono`（少量技术标签）。

| 层级 | 字体 | 字号（1080p） | 用法 |
|---|---|---|---|
| 巨型形状字/片名 | `Inter` 800 / `Sans SC` 900 | 180–360px | 片名、`YOU`、`LOGIN` |
| 主陈述 | `Inter` 700 / `Sans SC` 700 | 96–140px | 一句结论 |
| 形状内标签 | `Inter` 700 / `Sans SC` 700 | 40–64px | `KNOW`、`HAVE`、`ARE` |
| 正文 | `Sans SC` 400 / `Inter` 400 | 32–38px | 解释 |
| 小字/编号 | `Inter` 600 / `Mono` 500 | 22–28px | 编号、协议名、年份 |

字要当成形状：可以竖排、沿半圆弧排、切成一半；但**可读性优先**，弧线字只用于短标签（2–6 个字符/词），不要整段沿弧线。

## 4. 版面

- 用 12 栏网格定位，但不要求左右对称；可以让一块形状转 15°/30°/90°。
- 一屏三到四个大形状撑起画面；字很少，留白很多。
- 形状可以出血、可以被画框切掉一半；切边要干脆，不要羽化。
- 文字左对齐或沿形状边缘排；不要居中堆在画面中间。
- 大形状之间用黑色粗线/空白分隔；不要卡片。
- 字幕条仍在 y≥968；形状可以延伸到字幕带后面，但正文不要压字幕。

## 5. 图形语言（全片不破例）

| 形状/组合 | 含义 | 画法 |
|---|---|---|
| 圆 | “你知道的东西”（口令/记忆） | 红色实心圆；可切半 |
| 方 | “你拥有的东西”（设备/密钥） | 蓝色实心方；可切四分之一 |
| 三角 | “你本身”（生物特征） | 黄色实心三角；可倒置 |
| 三个形状拼合 | 一个完整的“你”/多因素 | 三块拼成一个更大的几何；拼缝用黑线 |
| 黑色框架/模板 | 验证者/系统 | 一个只接受特定轮廓的黑框；形状不合就进不去 |
| 单向压模 | 口令哈希 | 形状从左侧进入黑色压机，右侧出来一个不同的形状；箭头只单向 |
| 带缺口的钥匙 | WebAuthn 私钥/公钥 | 私钥在方内，公钥在方外；缺口与随机挑战对上 |
| 盖戳的票 | session cookie | 一张米白票，蓝色票根；票根=session ID |
| 带签名缺口的蓝色长条 | JWT/token | 长条=claims，缺口/波纹=签名；内容可读，不默认加密 |
| 从画外伸进的手 | CSRF/会话劫持 | 黑色斜块从画面边缘伸进来，抓住票根；不要画具体人手 |
| 假框架 | 钓鱼 | 与真框架同形但 origin 标记错位；形状拼不上 |

不要用“锁”“盾牌”“指纹图标”“Wi-Fi 图标”这类通用图标；用几何形状本身表达。

## 6. 动效

- **拼合**：形状从画外滑入/旋转到网格位，硬停；拼缝在最后一帧闭合。
- **单向压模**：形状进入黑色压机，2–3 帧后被压成新形状；不要回弹。
- **盖章**：票根上“啪”一下出现蓝色/黑色戳；1 帧过冲。
- **错误**：形状转 90° 后拼不上，出现一条黑缝；不要抖动/闪烁。
- **弧线字**：沿半圆排的字随形状旋转，每次 15° 步进；不要连续旋转。
- **镜头**：在形状之间平移/推近；停留时不往复。
- **转场**：用形状合拢/切开/翻转；不用整屏淡入淡出。
- 形状动作 12fps 步进；镜头可以连续。不要所有元素都用同一种“淡入+上移”。

## 7. 声音

- 木块“嗒”、印章“啪”、机械卡扣、纸张滑动。
- 拼合成功/失败各有不同的短音；不要用“科技感 whoosh”。
- 配乐：木琴/马林巴/低频脉冲，节奏方正；信息密集段加一层 click；不要大混响 pad。
- 旁白出现时音乐让位；音效不盖过旁白。

## 8. 与系列的关系

本集是「XX 秒速通」的视觉例外：保留系列的**定长时间线、语速、字幕带/秒尺、左上角剩余秒数、右上角仪表的位置与做法**，只更换视觉系统。理由：登录的“因子/拼合/验证”天然适合用几何形状讲；包豪斯的“字也是形状”能把很短的标签变成构图的一部分。

具体转译：

- 秒尺 → 一条黑色粗线，走过的部分变红；刻度是小方块。
- 剩余秒数 → 黄色/米白数字，压在黑色块上；最后 5 秒逐秒跳。
- 右上角仪表 → 三个形状的旋转/拼合状态；或一个红色扇形倒计时。
- 字幕带 → 黑底米白字；字幕不进入形状内部。
- 片尾名单 → 黑底米白字，左对齐；用形状做小标记，不抢读。

## 9. 封面

- 16:9：米白底，左侧一个巨大的红圆/蓝方/黄三角拼合体，右侧黑色标题；标题字高约画面 1/5。
- 4:3：上方拼合体、下方标题；重新排，不裁切。
- 底部 15% 不放字；缩到 360px 宽仍读得清。

## 10. 禁止

- 不要用名叫“Bauhaus”的圆胖字体（1975 年的那套）；用 Inter/Sans SC 的几何字重。
- 不要做成“红黄蓝三角圆方”的通用海报；形状必须承担本片的语义。
- 不要孟菲斯（波浪线、碎点、故意不守秩序）。
- 不要风格派（只有横竖黑线和矩形）。
- 不要渐变、阴影、圆角、玻璃、发光。
- 不要居中对称、四平八稳；但也不要为了不对称而乱放。
- 不要直接复刻某张包豪斯海报的构图；参考的是语法。

## 11. 验收清单

- [ ] 一屏三到四个大形状，字很少；缩到一半仍读得清。
- [ ] 形状语义一致：圆=知道，方=拥有，三角=本身，黑框=验证者，票=session，带签名缺口的长条=token。
- [ ] 颜色语义一致：红=秘密，蓝=会话/通道，黄=用户/声明，黑=系统。
- [ ] 没有渐变、阴影、圆角、发光。
- [ ] 弧线/竖排字只用于短标签，不牺牲可读性。
- [ ] 与「计时盘」系列片并排看，是另一套版式，不是换色。
- [ ] 字幕不与形状/正文重叠；对比度达标。

## 12. 可直接给 AI 的描述

用今天常说的包豪斯风设计。形状只用圆形、方形、三角形，可以切成一半、四分之一，像积木一样拼在一起。颜色用红 `#E2412C`、黄 `#F2C230`、蓝 `#2F57B0` 三块纯色，加黑 `#111111` 和米白底 `#F1ECE1`，全部平涂，边缘干脆，不要渐变和阴影。画面要空：三四个大形状撑起整张，字很少。排得有秩序（按 12 栏网格），但不要左右对称，可以让一块形状转一个角度。文字用粗的几何无衬线字体（Inter / Noto Sans SC），把字也当成一块形状：竖着排，或者沿着半圆的弧线排。让形状承担语义：圆=你知道的，方=你拥有的，三角=你本身，黑框=验证者，票=会话。不要用名叫 Bauhaus 的圆胖字体，不要做成红黄蓝三角圆方的通用海报，不要孟菲斯和风格派。
