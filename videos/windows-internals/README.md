# Windows 是怎么工作的

Windows 有 lots of 机制是你天天在用、却从来看不见的：这个图标为什么能双击打开、锁屏之后它记得你到哪一步、登录框背后的东西从哪来、硬盘被拆走了为什么读不出文件。这个系列一集讲一个机制，把它拆到能看见。

## 定位

| | |
|---|---|
| 讲什么 | Windows 内部那些用户天天遇到、却看不到的机制：权限、锁屏、登录、加密等等 |
| 面向谁 | 用着 Windows、想知道「它到底怎么做的」的观众；做桌面端、运维与安全方向的观众 |
| 怎么讲 | 一次真实操作贯穿：先让你看见现象，再走一遍系统内部实际发生的事、哪个组件在负责、出错会怎样；严谨核查官方文档与本机实测，版本与年份逐项标明 |
| 每集多长 | 2–5 分钟 |
| 语言 | 中文与英文（缺省） |

**收录的机制**（片单顺序）：权限机制 → 锁屏 → 登录 → BitLocker。顺序按「你在屏幕上操作时，Windows 依次要确认什么」排：先是你能不能做这件事（权限），再是你离开时它做了什么（锁屏），然后是你怎么证明自己（登录），最后是数据在盘上怎么保护（BitLocker）。每集独立可懂，不必按顺序看。

## 共同约定
各集真正共享的约定记在这里，一项一行。视觉与配乐默认每集取自本集的讲解对象（经验规则 F16、F21），除非下面写明了策划者的决定；某一集的设计决定写在那一集的 README。要改约定先改这里。写法见 [系列](../../docs/guides/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | `<系统>：<一句话讲清它是什么>`，例如「权限机制：令牌、完整性级别与访问控制」 |
| 结构（建议） | 一个你能复现的现象 → 内部机制是什么、谁在负责 → 一次真实操作走一遍 → 边界与常见误解 → 小结 |
| 演示与取证 | 以 Microsoft Learn 的官方文档与本机实测为准（本机或虚拟机上真实点一次），版本与年份逐项给出处；界面截图用真实的 Windows 界面，不画成示意图 |
| 视觉与声音 | 视觉取自 Windows 自己的界面与官方文档部件（对应 F16），各集按机制的不同选画面语言；连续性体现在结构与讲法上 |
| 术语与读法 | 同一批术语（令牌、完整性级别、会话、凭据、TPM）在各集写法与读法一致；组件名用官方英文原名加中文解释 |
