# Lua 源码解析

一集读懂 Lua 解释器的一个子系统：从值、字符串、表这些数据结构，到编译与执行，再到闭包、元表、垃圾回收、协程、错误与 C API。策划者 2026-10-20 新开这个系列，原话：「新增系列视频: Lua源码解析, 你来进行合适的分集」；分集由受托方 Claude Opus 5.5 拟定，见下表。

## 定位

| | |
|---|---|
| 讲什么 | 一集一个子系统：它要解决什么问题、源码里怎么做、为什么这样做 |
| 面向谁 | 写过 Lua 或别的脚本语言、能读一点 C 的人；没读过解释器源码 |
| 怎么讲 | 每集从一个能在 Lua 里看到的现象出发（例如一张表越用越快、一个闭包记住了循环变量），再进到源码里的数据结构与关键函数，最后回到那个现象。源码只截原文片段，行号与版本随片署名 |
| 每集多长 | 待首集确定 |
| 语言 | 中文与英文（缺省），待策划者确认 |

| 分工 | 与这三条已有的片子不重复：「编程语言」系列的单集「Lua 解释器的实现」（一集讲全貌）、「Lua 语言的设计哲学」（为什么这样设计语言）、「Lua 语言的发展史」（版本演进）。本系列逐个子系统读源码；与独立片《垃圾回收的艺术》的分工写在第 11 集的条目里 |

分集的思路：先讲数据（值、字符串、表），再讲代码怎么变成指令并执行（编译、字节码、虚拟机、调用），然后是建立在它们之上的语言机制（闭包、元表、垃圾回收、协程、错误），最后是与 C 的边界（C API）。顺序只是建议，每集可以单独开工。各集条目里的源文件是初步对应，开工取证时按所选版本核对。
