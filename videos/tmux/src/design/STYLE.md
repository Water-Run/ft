# 视觉系统：卡带未来主义（Cassette Futurism）

本片把 tmux 画成一台 1970 年代的多路终端控制器：不是“电脑里的一个窗口”，而是一间摆着机架、CRT、磁带机和拨杆的控制室。风格是**卡带未来主义**：七十年代的人想象的未来——绿字显像管、厚重按键、磁带、米色塑料、螺丝和压字标签。

这份文件是设计方向，不是最终 `style.css`。当前 `src/css/style.css` 仍是「XX 秒速通」系列基座的计时盘样式；实现时按本文件替换，并把 `project.json` 的 `check.style.palette/fonts` 改成这里的值。

## 1. 一句话与设计命题

**一句话：** 用一台老式多路终端控制器，解释 tmux 怎样把多个 pty 装进 session/window/pane，并在 client 离开后继续运行。

**设计命题：** tmux 的核心是“一个 server 管很多 pty，client 只是来看和按键”。画面要让人**看见**这件事：server 是机架，session 是磁带仓，window 是频道，pane 是并排的 CRT，client 是一台接进来的终端。所有的“分离/接回/切换”都做成物理动作：拔线、插线、拨杆、换台。

## 2. 色彩

| Token | 色值 | 用途 | 约束 |
|---|---|---|---|
| `--cf-black` | `#0B0D0A` | CRT 内部、机架深处 | 大面积底色；不要用纯黑 `#000` |
| `--cf-green` | `#74FF9A` | 荧光绿字、活动读数 | 只压黑底；56px 以下需实测对比度 |
| `--cf-amber` | `#FFB23E` | 琥珀色次读数、警示前的提示 | 只压黑底；不要和红同时抢眼 |
| `--cf-cream` | `#D8CFB4` | 米色塑料外壳 | 大面积实体；不要做渐变 |
| `--cf-charcoal` | `#2B2D2A` | 炭灰面板 | 面板主体 |
| `--cf-olive` | `#4A4F3A` | 军绿面板 | 第二层机架/模块 |
| `--cf-rust` | `#A8432F` | 铁锈色条纹、旧漆 | 只做窄条/小面积，不做字色 |
| `--cf-red` | `#D63A2C` | 警示灯 | **只给警示**：电源故障、kill-server、断开 |
| `--cf-paper` | `#E8E1CC` | 压字标签纸 | 标签底；字用黑 |
| `--cf-steel` | `#8C8F86` | 螺丝、金属边 | 小面积 |
| `--cf-ink` | `#151713` | 标签字、轮廓 | 压字/描边 |

规则：

- 黑底只给 CRT 和机架内部；米色/炭灰/军绿是实体面板。不要整屏黑底加绿字——那是“终端”，不是“控制室”。
- 荧光绿只用于 CRT 里的字和活动 LED；琥珀只用于第二层读数。红色只给警示灯，且一屏最多一处。
- 所有颜色平涂；不用渐变、不用半透明玻璃、不用大面积投影。机身可以用 2px 硬边高光/暗边模拟塑料厚度，但不能是柔和渐变。
- 扫描线只出现在 CRT 矩形内部，周期 3px、透明度 8%–12%；不要盖在米色塑料或标签上。噪点只作为 CRT 信号噪声的短促图案，不做全屏 overlay。

## 3. 字体与字号

可用字体：`VT323`（像素点阵，需在 `style.css` 声明 `@font-face`）、`Mono`（JetBrains Mono）、`Sans SC`（Noto Sans SC）、`Inter`。

| 层级 | 字体 | 字号（1080p） | 用法 |
|---|---|---|---|
| 片名/大数字 | `VT323` | 180–320px | 片名、server PID、时间码、计数器 |
| 主陈述 | `Sans SC` 700 | 84–120px | 一句结论 |
| 面板标签 | `Mono` 700 + 全大写 + 字距 0.08em | 24–32px | `SESSION`、`WINDOW`、`PANE`、`DETACH` |
| 终端命令 | `Mono` 500 | 40–56px | `tmux new -s demo`、`tmux attach` |
| 终端回显 | `Mono` 400 | 34–44px | 回显小一级并变暗（绿 70%） |
| 正文/注解 | `Sans SC` 400 | 32–38px | 中文解释 |
| 小字/编号 | `Mono` 400 | 22–26px | 编号、时间码、来源 |

中文不要用 VT323；中文用 `Sans SC`，拉丁/数字用 `VT323` 或 `Mono`。一行标签不超过 12 个汉字或 24 个拉丁字符。

## 4. 版面

- 12 栏机架网格；每个模块是一个“面板”，面板之间留 12–20px 的接缝；接缝里可以露出更暗的机架底。
- 模块的标签贴在控件**旁边**，不是居中放在上方；标签用压字标签纸或丝印。
- 不对称：主机架偏左或偏右，留出一块空的机架/桌面；不要四平八稳的居中。
- 四角可有螺丝（直径 8–12px 的圆 + 一字槽），但不要每个小元素都加螺丝；螺丝是“模块”的标志，不是装饰贴纸。
- 字号对比要狠：片名/大数字至少是正文的 4 倍。
- 字幕条仍在 y≥968；CRT 和面板内容不要伸进去。

## 5. 图形语言（全片不破例）

| 图形 | 含义 | 画法 |
|---|---|---|
| 磁带仓/磁带盘 | session | 一个带两个卷轴的矩形仓；标签写 session 名；活动时卷轴转 |
| 频道旋钮/频道牌 | window | 圆形旋钮 + 数字牌；切换时“咔哒”跳到下一格 |
| CRT 矩形 | pane | 黑底、绿字、扫描线；分屏就是物理挡板把一块 CRT 切成两块 |
| 机架电源灯 | server | 机架顶部一颗绿灯；kill-server 时变红/灭 |
| 插头/电缆 | client | 一根粗电缆从左侧终端接到机架；detach 就是拔掉，attach 就是插上 |
| 按键块 | 命令/前缀 | 方形键帽，侧面有厚度；`C-b` 是一个键帽组合 |
| 纸带/打孔带 | 历史时间线 | 一条带孔的纸带，年份打在上面；不要用现代时间轴 UI |
| 红色警示灯 | 危险/终止 | 只在 kill-server、断开、错误时亮 |

不要用“通用科技感”的图标（齿轮、云、盾牌、聊天气泡）。每个图形只表达一个意思。

## 6. 动效

- **UI 12 帧步进**：面板、数字、指示灯按 12fps 更新（60fps 下每 5 帧保持同一状态），不要平滑缓动。镜头运动可以连续。
- **打字机**：终端命令逐字出现，每个字停留 1–2 帧；回显整行刷出，不要淡入。
- **开机闪烁**：CRT 先出一条白线，再闪 2–3 次，稳定；每次 2–4 帧。
- **换台雪花**：切换 window 时，CRT 内出现 6–8 帧黑白噪点（只在 CRT 内），然后稳定到新画面。
- **拨杆/按键**：按下有 1 帧过冲、1 帧回弹；不要弹簧缓动。
- **磁带转动**：卷轴匀速转，速度与“数据量/时间”相关；不要突然加速。
- **镜头**：沿机架做慢速推/移，站与站之间移动；停留时最多极慢单向推近。不要往复平移或环绕。
- **转场**：用拔插电缆、换台雪花、挡板合拢、纸带刷过；不用整屏淡入淡出。

## 7. 声音（与画面同步登记）

- 继电器“咔”、按键“嗒”、磁带机“嗡”、CRT 高频底噪、风扇低频。
- 换台用短促的静电/雪花声，不用 whoosh。
- 关键动作（detach、attach、kill-server）各有不同的机械声；kill-server 只给一次短促的断电声。
- 配乐：低频脉冲 + 磁带机节奏 + 稀疏的合成器音符；120 BPM 附近，跟随秒尺。不要用“科技感 pad”铺满。

## 8. 与系列的关系

本集是「XX 秒速通」的视觉例外：保留系列的**定长时间线、语速、字幕带/秒尺、左上角剩余秒数、右上角仪表的位置与做法**，只更换视觉系统。理由：tmux 的题目本身就是“终端/会话/窗格”，卡带未来主义的控制台能把 server/client/pane 变成可见的物理对象；这不是为了换皮。

具体转译：

- 秒尺 → 纸带/打孔带边缘，走过的部分变琥珀。
- 剩余秒数 → 绿色七段/VFD 数字，最后 5 秒逐秒跳。
- 右上角仪表 → 磁带计数器（session/window/pane 三个读数）或 VU 表。
- 字幕带 → 机架底部的黑色铭牌，字幕用米白字；不要绿字压米色。
- 片尾名单 → 机架上的铭牌/纸标签，保持可读。

## 9. 封面

- 16:9：左侧是米色/军绿机架与一台 CRT，右侧是黑底绿字的 `TMUX` 与 128 秒；一颗红色警示灯只在角落。
- 4:3：上方机架、下方 CRT 与标题；重新排，不裁切。
- 主标题字高约为画面高度的 1/5；缩到 360px 宽仍读得清。
- 底部 15% 不放字。

## 10. 禁止

- 不要霓虹粉紫、赛博朋克雨夜、蒸汽波石膏像、Y2K 半透明塑料。
- 不要毛玻璃、圆角卡片、渐变光晕、柔和投影。
- 不要整屏扫描线/噪点/暗角；扫描线只在 CRT 内。
- 不要把所有东西装进同一种“深色面板 + 细描边”的卡片。
- 不要用“全大写加宽字距的小号英文注脚”当装饰；标签只在需要时出现。
- 不要把红色当强调色；红色只给警示。
- 不要直接复刻某部电影/游戏的控制台；参考的是风格语法，不是具体构图。

## 12. 可直接给 AI 的描述

用卡带未来主义（Cassette Futurism）设计，像 1970 年代的多路终端控制室：炭灰和军绿机架、米色塑料外壳、螺丝、压字标签、磁带仓、并排的 CRT。主屏幕黑底，文字用荧光绿 `#74FF9A` 或琥珀 `#FFB23E` 的像素/等宽字体（VT323 + JetBrains Mono），加只在 CRT 内部的扫描线和轻微硬边重影；不要全屏噪点、暗角或模糊光晕。信息按机架模块排：全大写标签（SESSION、WINDOW、PANE、CLIENT）、编号、时间码、条形读数；红色 `#D63A2C` 只给警示灯。实体控件：拨杆、旋钮、方形键帽、指示灯、磁带卷轴。动效用 12 帧步进、打字机、开机闪烁、换台雪花、拔插电缆，不要平滑缓动。不要霓虹粉紫、毛玻璃、渐变光晕、圆润扁平卡片。
