# 存储介质

从磁带到闪存，逐类讲解存储介质：一位数据在物理上是怎样被记下、又怎样被读出的。

## 定位

| | |
|---|---|
| 讲什么 | 各种存储介质的特点、历史沿革与物理底层：一位数据怎样被记下、又怎样被读出 |
| 面向谁 | 用过存储介质、想知道底下是什么的观众 |
| 怎么讲 | 深入讲解物理原理与沿革；务必严格事实核查，容量、密度、寿命等参数逐项给出处并注明口径与日期；统一视觉风格与节奏 |
| 每集多长 | 第 1、3 集约 15 分钟，第 2 集约 9 分钟 |
| 语言 | 只做中文（缺省，2026-10-24 起） |

## 共同约定
各集真正共享的约定记在这里，一项一行。视觉与配乐默认每集取自本集的讲解对象（经验规则 F16、F21），除非下面写明了策划者的决定；某一集的设计决定写在那一集的 README。要改约定先改这里。写法见 [系列](../../docs/guides/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | 待首集确定 |
| 结构（建议） | 物理原理 → 一位数据的写入与读出 → 寻址与读写机构 → 容量与速度的演进 → 局限，以及它被什么取代 |
| 衔接 | 各集按年代先后排列，结尾引出下一种介质；容量、密度、速度用同一套单位与同一种比例图，便于跨集比较 |
| 视觉与声音 | 按本页定位保持系列视觉风格与节奏；首集将实际共用的版式与节奏约定写回这里。各集的图形取自自身对象、配乐按内容设计，不把上一集的具体方案当作模板（F16、F21）。 |
