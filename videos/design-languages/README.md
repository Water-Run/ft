# 设计语言与视觉规范

每集讲一套设计语言：它为什么出现、原则是什么、由哪些构件组成、怎样落到产品上。面向看得懂界面、想理解背后规范的观众。

## 定位

| | |
|---|---|
| 讲什么 | 快速入门一套设计语言：它的构件、原则，以及它带来的直观感受 |
| 面向谁 | 看得懂界面、想理解背后规范的观众 |
| 怎么讲 | 直接展示这套设计风格最显著的特点，富有冲击力，深入浅出；引用官方规范与真实产品界面作为取证材料，注明出处 |
| 每集多长 | 3–5 分钟 |
| 语言 | 中文与英文（缺省） |

## 共同约定
各集真正共享的约定记在这里，一项一行。视觉与配乐默认每集取自本集的讲解对象（经验规则 F16、F21），除非下面写明了策划者的决定；某一集的设计决定写在那一集的 README。要改约定先改这里。写法见 [系列](../../docs/guides/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | 与设计语言的官方名称一致，如 `Metro`、`Spectrum`、`Carbon Design`、`Material 3`、`Fluent 2`、`Ant Design`、`Adwaita`、`Primer`、`Apple HIG` |
| 结构 | 待首集确定 |
| 视觉 | **特别约定：本系列不维持统一的系列视觉。** 每一集的视觉系统贴合它所讲的那套设计语言本身——讲 Carbon 就按 Carbon 的规范排版，讲 Apple HIG 就按 Apple HIG 的规范排版。连续性体现在结构、术语与讲法上，而不是统一的配色与部件 |
| 声音 | 待首集确定 |
