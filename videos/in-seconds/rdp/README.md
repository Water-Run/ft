## 简报

**受众。** 系列定位：入门、普及、低认知负担（见系列说明「受众」）。不假设观众知道什么是协议、端口、编码；会用 Windows，可能用过 QQ 远程、向日葵一类软件或游戏串流。

**核心问题。** 隔着网络操作另一台 Windows 电脑，画面是怎么传过来的？RDP 的做法「优雅」在哪里？

**解释路径。**

1. 引子：在家打开公司那台 Windows 电脑，字清清楚楚——问题：画面怎么传过来的？点出 RDP。
2. 它是什么：程序在远端跑，你这边只「看」和「按」；画面往下、按键往上；Windows 自带，默认 3389 端口。
3. 历史：1997 Hydra → 1998 终端服务器版（一台服务器多人共用，便宜终端，基于 T.120 会议协议族）→ 2001 XP 专业版人人可用 → 2012 Windows 8 新图形管线与 UDP → 2015 Windows 10 起 H.264 4:4:4。
4. 主线：两种传画面的思路。视频流（Parsec、Moonlight 一类）抓整屏、编码、发送、解码、显示；RDP 在 Windows 里面，拿到的是绘图操作，发「怎么画」：填矩形 10 字节、字形先缓存、一行 9 个字 47 字节、搬一块屏幕 14 字节。同类变化交给 H.264 实测：滚动一帧 23159 字节；彩色小字经 4:2:0 压缩发虚。
5. 画面之外：虚拟通道，剪贴板、文件、打印机、声音各走各的，复制的字传过去还是字。
6. 边界：游戏、视频整屏都在变，命令说不清；Windows 8 起的新管线保留填色、搬移、缓存命令，图像交给 H.264，RDP 10 再用 4:4:4 保住文字。游戏选视频串流，桌面上的字和窗口是 RDP 的长项。
7. 收尾：回到开头那行清楚的字——传的是「怎么画」，不是「画成了什么」。

**不讲。** 安全与漏洞（BlueKeep 等）、NLA/CredSSP 认证细节、RemoteApp、多显示器、授权与 CAL、Citrix ICA 的技术细节、连接序列的十个阶段。

**名词预算。** 旁白里主动教的只有：RDP（远程桌面协议）、视频流（把屏幕当视频传）、绘图命令、缓存、通道。端口、T.120、H.264、4:4:4 只上画面当标签。

## 取舍与未解决的问题

- **经典指令与今天的 Windows。** 规范样例的字节数来自 MS-RDPEGDI（经典绘图指令）。Windows 8 之后的服务器何时仍发这些指令，规范没写；文案把它说成「RDP 的做法」并在画面标「经典绘图指令」，新管线只讲有出处的部分（填色、搬移、缓存、H.264 混合、4:4:4）。
- **对比口径。** H.264 字节数是本机实验（`research/lab/02`），与规范样例不是同一块屏幕；旁白只说同类变化的量级，不说倍数。
- **「主流视频流远程」的名单。** 有一手出处的是 Parsec（官方博客）与 Sunshine + Moonlight（README）。国内常见的远程软件没有读到技术原文，不点名。

## 设计（候选，待选）

三个方向都取自 Windows 自己的视觉谱系（策划者 2026-11-07：「风格契合"MS Windows"的感觉」），讲法各不相同；样张在 `src/design/keyframes.html`（`?k=A1…C2`），截图放在审片页。

| 方向 | 外观 | 讲法 | 贯穿的对象 |
|---|---|---|---|
| A Fluent | Windows 11：亚克力窗口、蓝色光晕、8 像素圆角 | 并排比较两条路径：上道视频流（整帧），下道 RDP（小命令） | 左右两台电脑上的同一份记事本 |
| B Classic | Windows 2000：灰色立体按钮、深蓝渐变标题栏、蓝色桌面 | 追踪同一扇窗口：「线上的字节」窗口逐条收到规范样例里的真实字节，记事本跟着画出来 | 你电脑上的那扇记事本与字形缓存（字母 d） |
| C Metro | Windows 8：深色底、纯色磁贴、细字重大字号 | 把字节画成磁贴，面积严格按字节数 | 每一步一行磁贴，RDP 的块小到只剩一个点 |

常驻元素按系列约定：底部字幕带上的秒尺、左上剩余秒数、右上角仪表——本片的仪表是「这一步各传了多少字节（RDP / 视频）」。

字体只用仓库自带的 Inter、Noto Sans SC、JetBrains Mono（Segoe UI 是微软的字体，不随仓库发布）；不用 Windows 徽标。

配乐小样（`tools/music_demos.py`，程序合成、旋律原创）：A 开机（76 拍，铺底与 FM 钟琴）、B Metro（112 拍，切分方波拨弦）、C 九八（100 拍，FM 电钢与鼓机）。选定后改写 `tools/music.py`。

配音候选（`tools/audition.py`，只试听，不写 timing）：MiniMax speech-2.8-hd、语速 1.2 的温润青年、不羁青年、青年大学生、温柔学姐、温暖少女，都是近几部没用过的音色。

审片页的重建：`python -I videos/in-seconds/rdp/tools/music_demos.py`；`tools/audition.py <cues.json> <ffmpeg> <ffprobe>`（cues.json 由 script.js 导出代表句）；`look.js --url "/design/keyframes.html?k=A2"` 截关键帧后复制到 `out/audition/keyframes/`；`node videos/in-seconds/rdp/tools/audition_page.js`。
