## 连贯阅读

先通读问题、解释与章节推进，再到逐句表定位意见。下文按源稿顺序连接字幕，保留原文字与标点；不含静默 cue。口播读法与停顿另按配音规则核对。

### open · 无章节卡

用 ToDesk、UU 远程连过别人的电脑吗？ 它们把那边的屏幕录成视频，一帧帧发给你 Windows 自带的远程桌面，有更优雅的做法 它叫 *RDP*，发过来的不是录像，是画面的画法

### history · 无章节卡

RDP 诞生在 1998 年 那时电脑贵，微软想让一台服务器分给很多人用 每人一台便宜的终端，程序全在服务器上跑 项目代号就叫 Hydra，九头蛇 2001 年，Windows XP 专业版也带上了它

### stand · 无章节卡

两种远程，最根本的区别，是站的位置 ToDesk、UU 远程站在屏幕外面 那边每秒截几十次屏，压成*视频*发过来 它只认像素，不管像素是怎么来的 RDP 站在 Windows 里面 Windows 画窗口、写字，本来就是一句句*指令* 在这儿填一块颜色，在那儿写一个字 RDP 在它们变成像素之前接过来，交给你的电脑自己画

### bytes · 无章节卡

比如在远程的记事本里打一行字 录像的办法，把变了的那片像素压一遍，六百多字节 RDP 呢，每个字的样子，第一次出现时就存到你这边 一个字母 d，九个字节 之后只说几号字写在哪，这一行九个字，四十七字节 往下翻一页，录像这一帧要两万三千多字节 RDP 只说一句把这块往上挪，十四个字节 再补上露出来的几行 远程桌面连接的选项里，卫星、56K 拨号都列着 在 56K 拨号上，刚才那一帧录像要传三秒多 而 RDP 那句指令，两毫秒就到了

### adapt · 无章节卡

因为传的是画法，画在多大的纸上，由你这边说了算 连上的那一刻，你的电脑会报上自己的屏幕大小、缩放比例 还有键盘布局，连时区都报 那边的桌面，就照你的屏幕重新排好 窗口拉大拉小，远程的分辨率也跟着变 录像的办法只能录屏幕本来的样子，尺寸不对就整张缩放 复制的字、要打印的文档、放出来的声音 也都有专门的*通道*送到你这边

### limit · 无章节卡

不过，这一切的前提，是它和 Windows 绑得很深 被连的那台电脑得是 Windows，家庭版还不行 它懂的，也只是 Windows 的画法 游戏、电影这种整屏都在变的画面，指令说不过来 所以 Windows 8 以后，图片和视频那一块 RDP 也交给视频编码去传 ToDesk、UU 远程只认像素，反倒哪个系统都能连 又拼高帧率、低延迟，游戏也能玩

### end · 无章节卡

录像的办法，看到的是结果 RDP 知道每一笔是怎么画上去的 所以它能照着你的屏幕，重新画一遍
