# 逐句画面设计

风格：**卡带未来主义**。设计由策划者转交；创作署名与分工以 [project.json](../../project.json) 为准。旁白唯一源稿为 [script.js](../js/script.js)，本页按句号记录画面，不另抄旁白。

整体舞台沿来稿保持「左算右存」；指令为蓝色，数据为黄色。下面的画面描述与四幕时间范围按来稿保存，尚未展开为场景实现。

现象反差 → 拔线痛点 → 搭起“左算右存”舞台

| 句号 | 画面 |
|---|---|
