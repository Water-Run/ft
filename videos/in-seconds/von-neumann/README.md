## 简报

**主问题**：不改一根电线，同一台计算机为什么能换着干不同的活？

**观众**：没学过计算机组成的普通观众（系列定位）。看完能复述：步骤和数据放在同一个存储器里，控制器一格一格地取、拆、做；换用途就是换存储器里的指令；代价是共用的那条通道。

| 场 | 时间 | 回答主问题的哪一步 |
|---|---|---|
| open | 0–36 秒 | 现象（同一块芯片算账、打游戏）→ 片名 → 以前换题要重新插线 → 1945 年报告的五部分 → 关键：步骤和数放进同一个存储器 |
| program | 36–59.5 秒 | 存储程序：指令也是 0 和 1；存储器是编号的格子，控制器按编号往下读 |
| cycle | 59.5–92 秒 | 一个例子走完取、拆、做；循环几十亿次；换指令就换用途（回答开头） |
| bottleneck | 92–120.5 秒 | 代价：同一条通道、一次一个 → 1977 年命名为瓶颈 → 今天的分开缓存 → 结论 |
| credits | 120.5–128 秒 | 片尾名单，不配旁白 |

**不讲的材料**：图灵 1936 年的通用机器、存储程序的功劳归属、AI 芯片的存内计算（理由见 [NOTES](review/NOTES.md)，事实见 FACTS「未进入成片的事实」）。
