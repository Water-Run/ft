## 简报

**主问题**：不改一根电线，同一台计算机为什么能换着干不同的活？

**观众**：没学过计算机组成的普通观众（系列定位）。看完能复述：步骤和数据放在同一个存储器里，控制器一格一格地取、拆、做；换用途就是换存储器里的指令；代价是共用的那条通道。

| 场 | 时间 | 回答主问题的哪一步 |
|---|---|---|
| open | 0–39.3 秒 | 现象与提问（同一块芯片算账、打游戏，怎么做到的？）→ 蓝图，停顿，片名 → ENIAC：题目的步骤靠接线，换题拔了重插好几天 → 1945 年报告 → 核心三样 → 步骤不再靠接线，存进存储器 |
| program | 39.3–55.4 秒 | 存储程序：编号的格子；前几格指令、后几格数据；指令也写成 0 和 1 |
| cycle | 55.4–95.3 秒 | 取、拆、做，每步先点名、停顿、再走；第 2 格；越转越快到几十亿圈；换指令就换用途（回答开头） |
| bottleneck | 95.3–123 秒 | 代价：一条通道、一次一个 → 1977 年有了名字，停顿 → 冯·诺伊曼瓶颈 → 两块缓存、就近拿 → 结论 |
| credits | 123–128 秒 | 片尾名单（5 秒，WaterRun：「结尾……5s足够」），不配旁白 |

**不讲的材料**：输入与输出两部分（第 3 稿起为降低认知负担只讲核心三样）、图灵 1936 年的通用机器、存储程序的功劳归属、AI 芯片的存内计算（理由见 [NOTES](review/NOTES.md)，事实见 FACTS「未进入成片的事实」）。

## 设计

策划者 2026-10-31 的选择：画面 B「技术手册」（先答「画面A」，随后改为「画面算了 B吧」）、配乐 A「巴洛克脉冲」、配音「zh-CN-YunyangNeural 老式」。试听页 `out/audition/index.html` 不入库；关键帧源码 [src/design/keyframes.html](src/design/keyframes.html)。

**导演方案。** 全片是一本五十年代说明书里的一张图（图 1），观众看着这张图被画出来、被使用、被改进。贯穿的主画面是方框图：左边控制器与运算器，右边编码纸式的九个存储格，中间双线的通道，两头输入与输出。一条指令或一个数是一段穿孔纸带（孔 = 1），在通道里真的走一趟；红铅笔只标「此刻」。

r03 之后 WaterRun 的意见（2026-10-31，原话）：

> 右上角莫名其妙的一直正在读 优化好
> 轮到第二个和如今不要闪烁 优化好衔接
> 如今几十亿是所有元素在动, 不止通道
> [截图：飞转时只有通道在动] 控制器 运算器 存储器 三循环, 等等... 全部富有冲击力
> 遮挡bug也都处理好 如[截图：左上角「021 秒」被方框线穿过]
> 可以出正式片了

据此的偏离与做法：

- **右上角的仪表**：系列约定是「全片都在走的读数」。按上面的原话，本片的「正在读 第 NN 格」只在指针在场时显示（0:58 起），其余时间收起；左上、右上两处常驻元素加纸色衬底，镜头推近时方框线不再穿过。
- **从第 2 格到几十亿圈**：同一个过程逐帧算出，一圈比一圈快（1.5 秒起每圈乘 0.66，最快 0.04 秒），再减速停下；每一圈指针、格子红框、小环红圈、代码表、控制器里的纸带与读数、运算器的数、屏幕上的结余、通道里的纸带一起动。为了让程序能一圈圈跑下去，算账程序第 4 格由「停」改为「回 第1格」：加 5、加 3、存进第 7 格、回到第 1 格，屏幕显示第 7 格的结余；旁白未涉及这一格，文案不变。瓶颈一场接着用飞转停下时的结余与累加数。

第 3 稿（r02）起的做法：每一步先点名、停顿，停顿里画出这一步要走的路线，再让纸带走完，走完停住；镜头在「拆」时推近控制器、讲瓶颈时推近通道；转场靠对象变形连接（ENIAC 的接线拉直成纸带存进存储器，报告封面完整打出后才离开）。下表是 r01 的安排，r02 的逐场内容见 NOTES 的第 3 稿改动表。

| 场 | 观众要看懂 | 主画面怎样变 |
|---|---|---|
| open | 换用途不改电线；以前换题要重新插线；1945 年的五部分 | 线描芯片驱动的屏幕在账本与井字棋之间切换、里面的电路不动 → 扉页 → ENIAC 接线板上的线拔掉重插、日夜交替 → 打字机打出 EDVAC 报告封面 → 五个方框依次画出，步骤和数从输入框飞进存储器 |
| program | 指令也是 0 和 1，与数据存在同一排编号的格子里 | 推近存储器，纸带分成两列并标名；「加 第8格」「5」两张标签打出来又揭掉，露出同样的孔；格子一格格画出，纸带各自落格；指针从第 1 格往下读 |
| cycle | 取、拆、做三步；循环；换指令即换用途 | 第 1 格的纸带经通道进控制器，拆成「加」「第8格」，虚线指到第 8 格，那里的 5 送进运算器，0 变 5；第 2 格再走一遍后整套循环飞转；第 1–4 格整块换成游戏程序，输出框从 8 变成棋盘 |
| bottleneck | 共用一条通道的代价；1977 年的名字；分开的缓存 | 推近通道：纸带在通道口排成一列，一次放过一个，运算器的齿轮转一下就停；红圈与图章「1977 冯·诺伊曼瓶颈」；旁边长出指令缓存、数据缓存，队伍转进缓存，控制器与运算器就近取用；程序换回算账；图注打出 |

声音：配乐全程是「机器在走」的继电器滴答与脉冲音对位，瓶颈段停在属和弦上空转，加缓存后恢复并终止在主和弦；音效用打字机（报告封面、标签、图注）、纸带走带（drive）、老式蜂鸣（beep）、图章（thud）。配音为 Yunyang，经 `tools/vintage_voice.py` 收窄频带并加轻微饱和与短回声；唱片底噪由配乐全程铺一层，不逐句加在人声上。

**样式检查**（`project.json` 的 `check.style`）：调色板换成本片的颜色；`flat` 关闭，因为方格纸的格线与纸边暗角（渐变）、纸张与纸带的投影是「技术手册」这套视觉系统的一部分；`no_radius` 保留（只有纸带的孔与三步小环是正圆）。

**制作步骤**（配音之后）：`node kit/tools/tts.js videos/in-seconds/von-neumann` → `python videos/in-seconds/von-neumann/tools/vintage_voice.py` → `node kit/tools/audio.js videos/in-seconds/von-neumann` → 渲染。

## 复盘

（交付后补全。制作中记下的工具问题，交维护者处理：）

- `mix.py` 没有给旁白加滤波的入口，「老式」配音只能用本片的 `tools/vintage_voice.py` 在 `audio/` 里就地处理；建议 `project.json` 的 `audio` 段支持旁白滤波链。
- `preview.js` 的静止检测（freezedetect，-48 dB）对米色纸上的细线画面不敏感：纸带移动、标签打字、齿轮转动都被算作「基本不动」。`scan.js` 的 STILL 已无错误；r01 里 `preview.js` 报的 12 段逐段看过，都有内容在变，只是画面变化的像素少。
- 引擎的 `draw()` 在描线开始之前留着圆头线帽的点；本片改用 `parts.js` 的 `drawIn()`。`tl.set(…, 0)` 在 t=0 那一帧不生效，开场要藏的元素改为构建时直接隐藏（`hide0`）。
