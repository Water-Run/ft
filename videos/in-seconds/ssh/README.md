# 256 秒搞懂 SSH

本片讲一次真实的 SSH 连接：从敲下 `ssh` 命令到登录框出现，中间那一秒里协议到底做了什么。全片按一次连接的时间顺序走，每一步说清「这一步防住了什么」。中英双语，成片时长恰好 256.00 秒。

制作流程与标准见仓库的 `docs/`；片中每一句陈述的出处见 `research/FACTS.md`，测绘路线见 `research/MAP.md`，视觉与配乐方向见 `research/STYLE.md`。

目标观众已有的知识：用过 `ssh` 连过机器；知道公钥、私钥这两个词，但不知道它们在协议里出现在哪一步；不知道 SSH 是协议不是程序；不知道传输层与用户认证是两层；不知道「协商」这件事的存在。

看完应能回答的一个核心问题：按下回车、SSH 还没登录成功的那一秒里，到底发生了什么？

逐章怎样推进问题、最后回答什么：现象（那一秒屏幕上什么都没发生）→ 它是什么（协议、1995、RFC 4253、传输层只认服务器）→ 算法清单协商（各发一份按偏好排序的清单，取第一个共同的，没有就断）→ 密钥交换（迪菲-赫尔曼：各算一半、结果相同、这个数不过网）→ 主机密钥（私钥签交换哈希、公钥验签、再跟本地 known_hosts 对照）→ 密钥派生（六次哈希 A–F，连包头一起加密）→ 用户认证（ssh-userauth，公钥认证，私钥签一份含会话标识与用户名的数据）→ 边界（第一次连接的盲区、转发认证代理、端口转发）→ 结论（协商算法、换出密钥、验明服务器、证明自己，四件事在登录框出现之前就做完了）。

本片决定不讲的材料及理由：SSH 1 历史与专利、OpenSSH 治理与移植史、端口转发与 agent 转发的配置写法、默认算法顺序（「支持什么」不等于「默认选什么」）、包格式的每个字段与 MAC 具体算法、认证方法全集、密钥长度的横向比较。完整清单见 `research/FACTS.md` 的「查过但决定不写进旁白」。

## 设计

制作方 Claude Opus 5.5 的方案（2026-10-24）。逐句分镜见 `brief/storyboard-detail.md`。

- **主画面：一块控制台。** 左 CLIENT（你的电脑）、右 SERVER（`127.0.0.1:2222`）、中间一条线。旁白反复说的「不从网上传 / 不出本机」直接画成东西有没有走上这条线：上线的是一枚枚卡带，按格跳过去；留在本机的私钥、秘密数、共同密钥锁在机器下方的琥珀格里。
- **颜色语义全片不换。** 荧光绿＝屏幕与通过；琥珀＝秘密与钥匙（不上线的）；米色＝纸面与文件；铁锈斜线＝冒充者；红色只在警示灯上。
- **每章一个主画面**：四道关模块、走过三个年份的磁带、两张 KEXINIT 清单、两边的保险格、哈希台与 known_hosts 对照台、询问框、两把钥匙并排、十格读数。
- **右上仪表**由一条进度条改为四道关读数：铭牌 `SSH-2.0`（取自版本标识串），当前关琥珀框，走完变绿。
- **换场**：显像管换台，雪花两帧，新画面从中线上下展开。
- **配乐**重写为按四道关分段的 8 位编曲（`tools/music.py`）：A 小调 120 拍，两路带抗混叠的方波、16 级阶梯三角波低音、噪声鼓；对算法 Am–F–C–G，换密钥 Dm–F–Am–E，认主机 Am–E–F–E7，盲区撤掉琶音只留持续低音，收束处主旋律唱完整句。
- **推翻的准备方建议**：计时盘占位与旧开场不用；配乐不沿用单一循环；扫描线由 270 个 DOM 元素改为一张 SVG；灯与螺丝改方形（`no_radius`）。
- **为事实改掉的画面**：带毫秒的时间码改成十格读数（没有耗时实测），磁带标签只写 `SSH` 与 `1995`，指纹移到 known_hosts 卡外。

**卡带未来主义**，主色荧光绿。保留定长 256.00 秒、定长时间线、底部字幕带与秒尺、左上角剩余秒数、右上角仪表的位置。旁白语速是 MiniMax 的 1.0，不是 edge-tts 的 +6% / +8%。

## 读法

送去合成的文本与字幕不同的地方在 `src/js/script.js` 的 SAY 表：SSH 读作「S S H」、Diffie-Hellman 读作「迪菲-赫尔曼」、known_hosts 读作「known hosts」、OpenSSH 读作「Open SSH」、ssh-ed25519 读作「ssh ed25519」、curve25519-sha256 读作「curve25519 的 sha256」、chacha20-poly1305 读作「chacha20 的 poly1305」、ssh-userauth 读作「ssh userauth」、RFC 4253 读作「R F C 四二五三」。h2 一句的读法是「哈希值」而不是字母 H。

已合成中文全片并用 `asr.js` 筛查（2026-10-24）：多数差异是同音字。须人耳确认：「chacha20」被识别成「CH20」，「认明」「拍板」的声调，Tatu Ylonen 的读法（仍是拉丁拼写）。完整清单见 `review/NOTES.md`。
