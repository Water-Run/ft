| F10 单集独立可懂 | | 删除不必要的“上一期第几个问题”；直接讲本章问题，必要比较在本片补齐背景。 | 不看前集也能理解；逐句检查前集引用及其必要性，不要求记住前集编号。 |
| F11 外文材料的中文解释 | | 需要观众读的论文标题、引文和术语附中文释义，注明译文或意译及依据；资料原文作辅助。 | 实际中文成片中能同时找到可读的中文解释；不强迫观众自行翻译英文论文或追读文献卡。 |
| F12 读音、断句与口播 | | 列专名、多音字、数值和长句的试听清单，按语义组织停顿，字幕切分不机械决定口播停顿。 | 检查实际音轨对应时间；ASR 仅作筛查，读错、断句错和不自然处须人耳确认后复测。 |
| F13 背景、年代与观看路线 | | 从观众熟悉的情境引出对象，说明是什么、年代、用途和为什么值得看；给出本片路线，必要的新旧对照固定版本与任务。 | 首次观看能复述对象、时代和主线；背景长度支持解释，历史地位和比较有一手依据，不用今日数据倒推过去。 |
| F14 片尾署名与旁白分开 | | 署名、credit 和制作指令放在独立制作说明；片尾用空字幕、pause 和 credits:true 保留时间，不设置 tts。 | 连贯正文无制作指令，TTS 排除片尾；实际成片名单与开源链接可读，片尾没有人声朗读。 |
| F15 不写制作者口吻的自我说明 | | 画面与旁白只放观众需要的内容。不写说明制作取舍、脱敏、默认处理或防御性限定的标注，如“只列常量名，不列值”“示意 · 按源码分支构造”；不展示的东西直接不展示。数据来源用一行简短署名；口径限定只在观众会因此误解时，用一句自然的话放进正文。 | 逐屏检查最终 MP4 的所有文字标注与旁白，列出每处说明性小字，问“正常人做视频会不会写这句”；不会写的删去。 |
| F16 视觉取自讲解对象 | | 开工先取讲解对象自己的视觉材料（官网样式表的颜色与字体、官方文档的部件、标志），按这些部件语汇作图，并有一个随时在画面上的身份标识；做到随便截一帧都能认出在讲什么。 | 从成片任取若干帧，不看字幕与旁白，判断能否认出讲解对象；逐项列出所用颜色、字体、部件各自取自哪份官方材料。 |
| F17 配音语气与精神度 | | 配音的问题不只是读对读错。开工配音前先试听候选音色与语速，确认语气不塌：句子有起伏，该强调处有重音，长句不被念成一串平读；技术讲解要有往前推的感觉，不做成念稿。音色仍按对象年代与定位选择（P13）。 | 开工前把代表段的试听给策划者确认再合成全片；成片后连续试听开头、难点段和章间，记录语气与节奏的问题。响度、真峰值和语速数值合格不能代替听感，ASR 也不检查语气。 |
