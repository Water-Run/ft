# 分镜细化（制作方 Opus 5.5，2026-10-24）

## 全片的空间

整部片子是一块飞船控制台。左边是 **CLIENT**（你的电脑，一台带显像管的终端机），右边是 **SERVER**（一台机架，铭牌 `127.0.0.1:2222`，取自实验），中间横着一条 **线**（网络）。旁白里反复出现的「从网上传 / 不出本机」就是东西有没有走上这条线：

- 走上线的东西是一枚枚小卡带（数据块），按 12 帧一步往前跳。
- 留在本机的东西（私钥、秘密数、共同密钥 K）锁在机器内部的琥珀色格子里，永远不碰线。
- 线上的数据未加密时是绿色明文字，NEWKEYS 之后变成实心块。

颜色语义全片不换：荧光绿 = 屏幕文字与「通过」；琥珀 = 秘密与钥匙（不上线的东西）；米色 = 纸面与文件（RFC、known_hosts）；铁锈斜线 = 冒充者；红色只在警示灯上，表示断开或报错。

常驻层：左上剩余秒数；右上铭牌 `SSH-2.0` 和四道关的格读数（01 算法 / 02 密钥 / 03 主机 / 04 用户），走完一关点亮一关；底部字幕带与秒尺。

换场：显像管换台——雪花一闪，新画面从中间一条亮线上下展开。

## 实现后的调整

- 相邻两句不必各换一个画面（F22）：四道关、两张 KEXINIT 清单、控制台都整组在场，只推进正在讲的那一格。
- 画面上原计划的「时间码 00:00.000 → 00:01.000」改成十格读数和「那一秒」三个字：旁白里的「一秒」是口语，FACTS 里没有这条连接的耗时实测，带毫秒的读数会被看成测量结果。
- 换场统一为显像管换台：雪花两帧，新画面从中间一条线上下展开（四格）。
- 镜头：每章先给控制台全景，再推到正在讲的部件；阅读保持时一律极慢推近（`parts.js` 的 `camPath` 自动补），不往复晃。
