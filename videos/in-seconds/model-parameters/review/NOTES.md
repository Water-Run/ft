**目标观众**：按策划者 2026-10-20 的指示，本片面向**更入门**的用户——用过聊天机器人、听说过大模型，但不知道模型仓库里有什么、参数量是什么、上下文长度怎么算。不假设知道配置文件、token、注意力头、MoE。

**核心问题**：看到一个模型的那些参数，每个是什么、单位多少、量级多大、怎么读？

**逐章答案**（完整版见 `research/MAP.md`「逐段推进」与本片 README「内容」）：

| 场景 | 本章回答 |
|---|---|
| open | 答案不是一个数字，而是一串参数；这些数字写在模型仓库的一份配置文件里 |
| p1 参数量 | 是模型里学出来的数字的个数；单位是个；名字里的 M 百万、B 十亿、T 万亿；这一列从一亿多到两万多亿 |
| p2 结构参数 | 同一份文件里还写着模型长什么样：层数 42、隐藏维度 2048、注意力头 16 |
| p3 上下文长度 | 模型一次最多能读多少东西；单位是 token（词表里的一条）不是字；上限 13 万 |
| p4 词表 | 模型认识的所有词条；中文一个 token 一两个字，英文四五个字母；所以上下文长度不能按字数算 |
| edge 边界 | 参数量大不一定更强；混合专家模型存了 240 亿参数，每次只用 25 亿 |
| concl 结论 | 先看单位，再看量级，最后看口径；参数量只是一项 |

**时长预算**：成片必须恰好 96.00 秒（`project.json` 的 `check.duration` 是 [95.9, 96.1]）。中文稿估算总长 96.00 s，各场余量 0.7–1.2 秒（估算按每秒 5.2 字、每句 0.35 秒起算；实际配音后余量会更大，这些余量留给画面运动与阅读时间，不压留白）。片尾 7.5 秒静默，不配旁白。

**本稿的取舍，请重点看这几处**：

1. **不出现模型名与厂商名**（画面与旁白都不出现）。按 README 的禁用商标约定，片中那一列只显示各模型名里的参数标记（150M / 2B / 24B-A2B / 2.4T-A95B）与实测参数量。若希望出现完整模型名，请说一声。
2. **不点名任何模型**。旁白只说「这一列」「这个模型」。好处是观众不被品牌分心，坏处是少了具体抓手——若觉得太虚，可以点名。
3. **p1_4 的口径是「这一列里」**，不是「最小的模型 / 最大的模型」：同期模型的实际跨度更大（4,576 万 → 2.45 万亿，见 `research/lab/out_07_scale_survey.txt`），说成普遍结论就不成立。
4. **p4_3 的换算值是这一个分词器、这几段文本的实测值**（中文 1.70–1.78 字/token，英文 4.22–5.12 字符/token），不是语言换算的定值。
5. **p3_4 说的是架构上限**（`max_position_embeddings` = 131072），服务方给的窗口可能更小，本片不涉及。
6. **e2 / e3 用的实测值**（240 亿 / 24.5 亿），官方模型卡写的是 24.0B / 2.45B，与实测吻合；名字里的「A2B」是约数。
7. **不讲的材料**：具体模型之间的横向对比与跑分、训练细节、推理框架、部署与量化、MoE 的机制展开、完整字段表、模型卡怎么读。理由见 `research/MAP.md`「决定不讲的材料及理由」。
