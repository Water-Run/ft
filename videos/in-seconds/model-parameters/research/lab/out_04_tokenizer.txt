    同一个词被切成几个 token：
      tokenization     → 2 个 token：token | ization
      unbelievable     → 3 个 token：un | bel | ievable
      hello            → 1 个 token：hello
      模型参数             → 2 个 token：模型 | 参数
      上下文长度            → 2 个 token：上下文 | 长度
      参数量              → 2 个 token：参 | 数量

    同一句话换一种写法，token 数就变了：
      3.14                 3 个 token
      3.14159              4 个 token
      三点一四                 3 个 token
      2026年10月20日          7 个 token
      October 20, 2026     7 个 token
