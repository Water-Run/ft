# 讲解测绘

2026-10-20。本片由《96 秒速通模型卡》改题重规划，本文件按新题目重写。事实与出处只在 `FACTS.md`，视觉方向在 `STYLE.md`，两者都不由本文件改动。

## 主问题

**看到一个模型的那些参数（参数量、层数、隐藏维度、上下文长度……），每个是什么、单位多少、量级多大、怎么读？**

看完应能回答：拿到一份模型参数表，能说出每项的单位与量级，并知道「参数量不等于能力」这类口径陷阱。

## 讲法

不抽象开场。先给一个观众见过的情境——有人问「这个模型多大」，回答不是一个数字而是一串参数，且每个参数的单位不同、量级差着好几个数量级；再问第二个问题：这些数字该怎么读。

之后逐类参数往下走，每类都按同一套讲法：**它是什么 → 单位是什么 → 量级多大 → 怎么读**。同一张参数表贯穿全片，随讲到的部分逐行点亮。

## 决定不讲的材料及理由

- **具体模型之间的横向对比与跑分**：超出「读懂参数」的范围，且要处理各家口径不一致，属于另立选题。片中出现的那一个真实模型只作为参数的载体，不评优劣。
- **训练细节、推理框架、部署与量化**：与「参数是什么、怎么读」不是一条线，96 秒塞不下。
- **MoE 的总参数与激活参数机制**：只在本片点一句口径，不展开；展开是第 5 集《Dense/MoE》的事。
- **逐个字段的完整参数表**：只讲观众最常问到的几类；完整字段表会挤掉量级与单位的解释。
- **模型卡怎么读**：原《96 秒速通模型卡》的内容，随改题一并作废。

## 取证（第 1 步，已完成 2026-10-20）

- 一份真实模型仓库的配置文件字段：`hidden_size`、`num_hidden_layers`、`num_attention_heads`、`max_position_embeddings`、`vocab_size` 的确切含义与官方说明出处。**→ 主例子 `openbmb/MiniCPM5-2B`；官方定义取自 transformers 文档的 LlamaConfig。**
- 参数量的官方口径与可复算的计数方法。**→ safetensors 官方格式说明 + 实验 02 的三条路径（逐张量数出、分片索引换算、Hub 公布数）互校。**
- 上下文长度的定义：token 而非字；上限的来源。**→ `max_position_embeddings` = 131072，是架构上限；服务侧限制本片不讲。**
- token 与字词的换算关系。**→ 实验 04 用主例子的真实分词器实测：中文 1.70–1.78 字/token，英文 4.22–5.12 字符/token。**
- 量级对照：同一口径下的可比性。**→ 实验 07 普查了 2026-08 之后发布的 97 个模型（跨度 4,576 万 → 2.45 万亿）；片中那一列取其中四个。**
- MoE 的总参数与激活参数。**→ 实验 03 从真实权重分出专家与非专家：23,971,587,712 总参数，激活 2,454,808,192；官方模型卡写 24.0B / 2.45B，与实测吻合。**
