## 设计

选定 A「机柜剖面」、配音 `zh-CN-YunxiNeural`、配乐「金属机架」（2026-11-25，策划者授权按推荐选定，理由见陈列页）。B 方向的设计说明保留作记录。

- **A · 机柜剖面（选定）。** 取 Xen 的硬件分层与 VirtualBox 的虚拟设备做板卡。x4–x5 把最底下的板标成「裸金属 · bare metal」，并空出一格「这里没有操作系统」；x6–x7 让 Dom0 与客体并排插在 Xen 上。v4–v6 用一次写入贯穿客体的磁盘与宿主的文件，镜像落点给一次短声。j7–j9 在操作系统机柜旁展开字节码与每步之后的栈。c3–c4 让两台机柜的物理底座对齐，标出 VMware 的同类产品，留时间读监控器的相对位置。c6–c7 把虚拟机与容器并排：一边每台各带操作系统与内核，一边共用宿主系统的一个内核。c8 把 JVM、Linux 客体、VirtualBox、Windows、硬件叠成一摞。
- **B · 逻辑分析仪。** 用开机和运行事件做两道时间轨。x4–x7 和 v1–v3 的客体启动位置对齐，可读出各自先经过哪些层。j7–j9 复用游标，每次推进一格就把数字实际压入、取出或返回，最后保留输出供阅读。j8 的加法由一次短促的步进声落点。
- 「金属机架」（`tools/audition_audio.py` 的 `metal_rack`）是选定的配乐：钢板敲击的非谐波泛音、六个方波叠成的金属镲、1:1.4 的调频钟声，加上低频铺底。正式制作时移植进 `tools/music.py`，按场景定点重排段落。
- 配乐小样都有低频铺底。背板时钟突出稳定脉冲，机房长音突出和声与空间，指令步进突出干燥短拍。三个方向都按约 60 秒给出引子、展开、推进与收束。
- 底部保留秒尺、字幕安全区，左上保留剩余秒数，右上仪表显示当前观察对象。两套关键帧的时刻是构图参考。从第 2 版审片页起，关键帧的时刻和剩余秒数按所对应的句号推算（`src/design/audition.js` 的 `cue`）。监控器板卡加印 Hypervisor。
