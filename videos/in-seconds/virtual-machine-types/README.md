## 设计

- **A · 机柜剖面。** 取 Xen 的硬件分层与 VirtualBox 的虚拟设备做板卡。x4–x7 让同一套底座上长出 Xen 和两条支线。v4–v6 用一次写入贯穿客体的磁盘与宿主的文件，镜像落点给一次短声。c7–c8 保持两台机柜的物理底座对齐，留时间读监控器相对位置。
- **B · 逻辑分析仪。** 用开机和运行事件做两道时间轨。x4–x7 和 v1–v3 的客体启动位置对齐，可读出各自先经过哪些层。j7–j9 复用游标，每次推进一格就把数字实际压入、取出或返回，最后保留输出供阅读。j8 的加法由一次短促的步进声落点。
- 配乐小样都有低频铺底。背板时钟突出稳定脉冲，机房长音突出和声与空间，指令步进突出干燥短拍。三个方向都按约 60 秒给出引子、展开、推进与收束。
- 底部保留秒尺、字幕安全区，左上保留剩余秒数，右上仪表显示当前观察对象。两套关键帧的时刻是构图参考。从第 2 版审片页起，关键帧的时刻和剩余秒数按所对应的句号推算（`src/design/audition.js` 的 `cue`）。监控器板卡加印 Hypervisor。
