## 连贯阅读

先通读问题、解释与章节推进，再到逐句表定位意见。下文按源稿顺序连接字幕，保留原文字与标点；不含静默 cue。口播读法与停顿另按配音规则核对。

### open · 无章节卡

一台电脑，怎么同时开两套系统？ 从操作系统的角度看。 它要用处理器计算，用内存放数据。 它还得读写磁盘，才能存文件。 软件可以为它提供一套虚拟的处理器、内存和磁盘。 在虚拟硬件上启动的操作系统，叫*客体系统*。 这种提供整机环境的，叫*系统虚拟机*。

### type1 · 无章节卡

真实的硬件怎么分给这两套系统？ 靠中间这层*虚拟机监控器*。 用 Xen 举例。机器开机后，Xen 直接运行在硬件上。 它给不同的虚拟机安排处理器时间、分配内存。 典型的 Xen 还会先启动一个*管理域*。 它负责管理客体和设备，也跑在 Xen 上。 监控器直接管硬件，这种架构叫*第一类*，也叫裸机型。

### type2 · 无章节卡

另一台电脑先启动 Windows。 打开 VirtualBox，启动一套 Linux。 外面的 Windows 叫*宿主系统*。 假设客体要往自己的磁盘写数据。 这次写入被转到宿主的*磁盘镜像*文件。 客体看到一块盘，宿主管理一个文件。 监控器依托宿主，这叫*第二类*，也叫宿主型。

### process · 无章节卡

那 Java 虚拟机也要启动一套操作系统吗？ Java 虚拟机简称 JVM，由现成的操作系统启动。 Java 源码编译成类文件，里面是 JVM 要执行的*字节码*。 来看这个加法方法。 头两条指令，依次把二和三放进*操作数栈*。 加法指令取走这两个数，再把结果五放回去。 最后一条指令把五返回给调用方，程序打印五。 实现可以逐条解释，也可以编译成机器指令。 同一份类文件，能交给不同平台上兼容的 JVM。 这种为程序提供执行环境的，叫*进程虚拟机*。

### compare · 无章节卡

两种架构给 Linux 的，都是一套虚拟硬件。 第一类和第二类，分的是监控器的位置。 第二类也可以用处理器的虚拟化功能。 进程虚拟机给程序提供执行环境。 系统虚拟机和进程虚拟机可以套着用。 刚才那个客体里，就能启动 JVM 来算这道加法。 所以先问，谁在使用这台机器？ 如果是操作系统，再看监控器在硬件上，还是在宿主系统上。
