== 环境
$ node -v
v24.21.0
$ curl --version
curl 8.22.0 (Windows) libcurl/8.22.0 Schannel zlib/1.3.2 WinIDN WinLDAP
$ $PSVersionTable.PSVersion
7.6.7
$ [System.Environment]::OSVersion.VersionString
Microsoft Windows NT 10.0.26340.0
本实验只监听 127.0.0.1 的临时端口；端口号由内核分配，每次运行都会变。

== 200 成功：内容就在响应里
$ curl -i http://127.0.0.1:53440/ok
HTTP/1.1 200 OK
Content-Type: text/plain; charset=utf-8
ETag: "demo-v1"
Cache-Control: max-age=60
Date: Wed, 21 Oct 2026 01:31:49 GMT
Connection: keep-alive
Keep-Alive: timeout=5
Transfer-Encoding: chunked

ok

== 201 成功：新建了资源，Location 指向它
$ curl -i -X POST http://127.0.0.1:53440/created
HTTP/1.1 201 Created
Content-Type: text/plain; charset=utf-8
Location: /ok
Date: Wed, 21 Oct 2026 01:31:49 GMT
Connection: keep-alive
Keep-Alive: timeout=5
Transfer-Encoding: chunked

created

== 204 成功：动作生效，但没有内容要回

== 401 与 403 的分界：同一个资源，凭据不对是 401，凭据有效但权限不够是 403
$ curl -i -H 'Authorization: Bearer good-token' http://127.0.0.1:53440/private
HTTP/1.1 403 Forbidden
Content-Type: text/plain; charset=utf-8
Date: Wed, 21 Oct 2026 01:31:49 GMT
Connection: keep-alive
Keep-Alive: timeout=5
Transfer-Encoding: chunked

forbidden

== 401 与 403 的分界：凭据有效、权限也够，这次是 200
$ curl -i -H 'Authorization: Bearer good-token' -H 'X-Demo-Role: admin' http://127.0.0.1:53440/private
