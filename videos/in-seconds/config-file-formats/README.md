## 设计与声音（制作方取舍）

- 时间：五幕按实测配音自然排布（28.1 / 28.2 / 25.5 / 28.4 / 32.3 秒），片尾名单定在 142.5–150 秒。
- 画面（r2 重做）：全片只有一份活的配置文件（server 里套 db）。四个数据值是一直在场的红字；换格式时旧语法飞散、数据与键名滑到新位置、新语法从四面砸进来，于是「同一份数据、换一种写法」是看得见的。每种格式的结构都在这份文件上演：INI 的 [db] 想套进 [server] 被顶回；XML 的 <port> 与 </port> 拉开再夹住 8080，框出层层嵌套并长出一棵树，标签与数据飞成方块（95 比 20）；JSON 砍落闭合标签，压成一行变成 JSONL 日志；YAML 少一个空格报错、少两个空格 5432 把 8080 撞掉；TOML 一颗圆点落进 [db]。开场先讲清因果：服务器端口 80 → 改文件里的数字 → 红点送回 → 服务器换成 8080；之后服务器缩在左上角、一根红线连着文件，结尾放大回来。换场是左半幅一块红板压过去再抽走，文件不断。纸色字压在 #D4291F 上只有 3.9:1，所以红色块里不放小字。
- 配音：MiniMax 当日已到 Token Plan 上限，改用 Edge `zh-CN-XiaoxiaoNeural`，+14%。「力量感」主要靠语速与配乐的军鼓、铜管和弦重击承担；若嫌不够硬，MiniMax 恢复后可换音色重配（不改文案）。
- 配乐：`tools/music.py` 由起点改写为 C 小调、120 拍的「印刷车间」：军鼓、每小节第一拍的铜管和弦重击、每秒一声铁砧；结论句 e6 处抬起。只有数值自检，听感待人确认。
