# 构成主义海报规范与逐句画面

风格：**构成主义风格的海报**。创作署名与分工以 [project.json](../../project.json) 为准。旁白唯一源稿为 [script.js](../js/script.js)，下表只保存画面与句号。

## 视觉定调锁死

同时，所有分镜严格锁死在你的构成主义海报规范内：只有 2D 平涂色块、一两条切开画面的大斜线、逐字放大且裁切出画的粗黑无衬线巨字，以及油墨纸纹质感。

### 色板与肌理

米色纸底（#E9E0CC），大块平涂红（#D4291F）与平涂黑（#1B1816）（仅在区分数据类型时点缀极少量深灰蓝）。零渐变、零阴影、零 3D，色块边缘带轻微套色错位与纸张油墨噪点。

### 斜线与字体的承重结构

每一幕由一到两条斜线硬生生切开画面；格式名（INI、XML、JSON、YAML、TOML）采用极粗无衬线大字，斜向排布、字母一个比一个大，边缘直接被画框裁掉一部分，让巨型文字本身充当版面的骨架。

### 策划者指定的设计风格原文

构成主义风格的海报。用一两条斜线把画面切开，大块红（#D4291F）和黑（#1B1816）平涂，米色纸底（#E9E0CC），颜色最多再加一种。标题用很粗的无衬线大字，可以斜放、一个比一个大，被画面边缘裁掉也没关系，让字撑起整个版面。不要渐变、阴影和 3D，整张带一点油墨和纸纹的印刷感。
