== 2b. 最近 100 条的编号范围与空号 ==
$ gh api 'repos/nodejs/node/issues?state=all&per_page=100' --jq '[.[].number] | {max: .[0], min: .[-1], count: length}'
{ "count": 100, "max": 67479, "min": 67373 }
$ gh api 'repos/nodejs/node/issues?state=all&per_page=100' --jq '[.[].number] | . as $n | [range(.[0]; .[-1]; -1)] | map(select(. as $x | $n | index($x) | not))'
[ 67464, 67390, 67389, 67387, 67385, 67384, 67381 ]
（注：67479−67373+1=107 个号位，实存 100 条，7 个空号。）

== 8. /issues/N 与 /pull/N 互相跳转（只保留状态行、Date、Location；会话 Cookie 不入库）==
$ curl -sI https://github.com/nodejs/node/issues/67474 | grep -Ei '^(HTTP/|Location:|Date:)'
HTTP/1.1 302 Found
Date: Sun, 15 Nov 2026 02:21:01 GMT
Location: https://github.com/nodejs/node/pull/67474
$ curl -sI https://github.com/nodejs/node/pull/67469 | grep -Ei '^(HTTP/|Location:|Date:)'
HTTP/1.1 302 Found
Date: Sun, 15 Nov 2026 02:20:45 GMT
Location: https://github.com/nodejs/node/issues/67469
（注：67474 是 PR，/issues/67474 跳到 /pull/67474；67469 是 Issue，/pull/67469 跳到 /issues/67469。）
