## 简报

- 目标观众已有的知识：会打开网站、家里有路由器；不知道什么是 IP、IPv4，不要求理解二进制、子网、路由或 DNS。历史专名（如阿帕网）不进旁白。
- 看完能回答的一个核心问题：IPv4 地址怎样让数据在本机、同一网络和跨网络之间找到正确去处？
- 用哪个具体例子走完解释，关键因果与边界是什么：主例是 `192.168.1.10/24` 向文档示例地址 `203.0.113.80` 发包。先把 32 位地址写成四段十进制，再用 `/24` 分出网络与接口；目的不在同一网络时交给默认网关，由路由器逐跳转发。随后用同一台计算机上的 `localhost`、`127.0.0.1` 说明环回，用 `192.168.0.0/16` 说明私有地址及公网访问时的地址转换。文档示例地址不代表真实服务器。
- 逐段怎样推进，各段的答案：`open` 由打开网站问出「设备那么多，靠什么找」，答「靠地址」，再起名 IP，交代第四版定于一九八一年、用到今天；`address` 回答地址是三十二个零或一、八个一组写成十进制；`prefix` 回答地址分网络与设备两截、/24 的意思、目的地址在别的网络；`route` 回答同网直送、别的网络先交给家里的路由器、路由器查表一站站送；`special` 讲 127.0.0.1 指本机（localhost 只上画面）、192.168 私有地址各家内网都能用、上公网时整个内网共用一个公网地址；`limit` 回答为何共用（32 位约 43 亿）、二〇一一年全球统一管理的地址池分完、接班的 IPv6 有 128 位且找路办法照旧。无章节卡。
- 决定不讲的材料与理由：不讲分类编址、DHCP、ARP/MAC、DNS 的一般机制、TCP/UDP、分片、TTL、IPv6 的写法与机制（IPv6 只在结尾出现：接替 IPv4、128 位、找路办法不变），各 RIR 各自用完的日期与 IPv6 使用比例（未取得可引用的原文与印证），也不展开 `0.0.0.0`、`169.254.0.0/16`、组播和广播等其他特殊用途地址。100 秒只保留理解主例及策划者点名地址所必需的内容。

## 设计

**选定 B**（WaterRun 2026-11-01：「风格B」），配乐「CRT 终端」，配音 03 云健。第 3 轮按第 3 稿更新 B 的四张帧并新加「127.0.0.1 与 192.168」一帧：本机窗口里 127.0.0.1 绕回自己、localhost 只作标签；两家内网都用 192.168.1.10、各自共用一个公网地址。`check.style.palette` 已改为 B 的六色。A 的页面保留作记录，不再使用。

第 2 轮按策划者「画面更具备90s计算机质感, 包括主题色」重做，比较两种九十年代电脑语汇下的两种解释方法；第 1 轮黑底橙色、卡带标签式的两组方向作废。两组都只用九十年代电脑的通用语汇，不用任何产品标志与产品名。

1. **A · DOS 蓝屏 · RFC 文本模式**（`src/design/dos.html`）：VGA 16 色里取蓝底 `#0000AA`、灰 `#AAAAAA`、亮白、亮黄 `#FFFF55`（此刻的焦点）、青 `#00AAAA`（选中行），双线窗框加实心黑影，顶行是剩余秒数、本段「文件名」和 32 位寄存器读数，底行字幕带上沿是 100 格秒尺。主画面取 IPv4 自己的原始材料：开场是 RFC 791 首页与 1981 → 1983 → 今天的时间线，片名「100 秒速通」用点阵汉字；地址段把 RFC 791 §3.1 头部图的逐位刻度尺原样搬上来，源、目的两行换成真实的 32 位，/24 切线分开网络与接口；路由段是一行五个节点与一张路由表；结尾是 IANA 的 256 个 /8 方格图，最后五块高亮，旁边 32 格对 128 格比较位数。讲法是「摊开来拆」。
2. **B · 九十年代桌面 · 窗口与对话框**（`src/design/desktop.html`）：青色桌面 `#008080`、银灰 `#C0C0C0` 立体窗口（白、黑两色斜面）、藏青 `#000080` 标题栏与选中态；任务栏就是字幕带，秒尺是分格进度条；右上角的仪表是四格 IP 地址框，显示此刻在讲的地址。开场是「关于 IPv4」对话框与 RFC791.TXT 窗口；地址段是属性框里填好的地址、位视图里反白前 24 位、弹框给出「不在本网络」；路由段是网络路径窗口、判断框与路由表；结尾是地址空间整理图（256 格全满）、「地址池已空」提示框与 IPv6 位数条。讲法是「在那台电脑上动手」。

**成片的画面**（第 6 轮，B 方向）：全片一张常驻的网络图（你家、三台路由器、另一个网络、隔壁一家、远方网络）与下方「地址」窗口；顶部是网页加载条与年表。数据包只沿连线走、停在路由器上。
- 引子：你的电脑打开网页，下方随读音填上 203.0.113.80 → 四个数一亮，网上的电脑铺满、各自亮出地址，对上的那台描框 → 「关于 IPv4」窗口（片名卡，「100 秒速通」只上画面）：大字 IPv4、Internet Protocol 互联网协议；读到「第四版」时排出版本来历：最初的 TCP（1974）、TCP 第 2 版（1977）、第 3 版（1978）、拆出 IP 的第 4 版（1978，反白）。
- 历史：同一个窗口接着排 1981 RFC 791 定稿（排出 32 格「地址 32 位」）、1983 全面改用（1 月 1 日）、今天仍在使用；说完窗口收进顶部年表。
- 主线：地址展开成 32 格，每 8 格一组，写成 203 / 0 / 113 / 80，注明 0–255，「4 个数 × 8 位 = 32 位」；第 24、25 位之间断开，前一截藏青「网络」、后一截描框「设备」，图上同网地址的前一截一起反白；「/24」「前 24 位」「= 前三个数」。送法：两行比较（同网直送手机；不同网交给家里的路由器），一站站过三台路由器，地址窗口右边的查表记录逐行添上，进远方网络逐台核对后一截，进到 80，网页走满。127.0.0.1 原地掉头（localhost 只作标签）；192.168：你家与隔壁一家都是 192.168.1.10，注解私有地址。
- 不够用：32 格 → 2³² = 4,294,967,296，约 43 亿；年表亮起 1994，「1994 年：提出地址转换」，你家两台设备出门都换成 198.51.100.7；年表亮起 2011，地址池 256 块最后 5 块填满，「地址池已空」。
- 收尾：回到 203.0.113.80，前一截找网络 → 路由器接力 → 后一截找设备，数据包再走一遍；最后「接班者：IPv6」窗口只露出名字与 128 格（第一行是 IPv4 的 32 位）。
- 片尾：「制作名单」窗口。

配乐 `tools/music.py`：策划者选的「CRT 终端」小样（第 1 轮 Kimi K3.1 Pro 设计）按场景重排为 100 秒——开场稀疏，地址段加低音，路由段加继电器与同步脉冲，「不够用了」撤掉节奏，收尾回到路由段的节奏，在 z2（IPv6）抬起，片尾只留铺底。
