# 汽车的系统工程

把汽车当作一个整体来讲：同样的零件，调校之后为什么表现不同；各个子系统之间怎样相互制约。面向对汽车感兴趣、没有工程背景的观众。

## 定位

| | |
|---|---|
| 讲什么 | 汽车的各个系统：结构、原理，以及系统之间怎样相互制约 |
| 面向谁 | 对汽车感兴趣、没有工程背景的观众 |
| 怎么讲 | 深入讲解，以科普和纠正误区为主，通俗易懂；视觉美观、引人注目、富有节奏感；视频较长 |
| 每集多长 | 5–10 分钟 |
| 语言 | 只做中文（缺省，2026-10-24 起） |

## 共同约定
各集真正共享的约定记在这里，一项一行。视觉与配乐默认每集取自本集的讲解对象（经验规则 F16、F21），除非下面写明了策划者的决定；某一集的设计决定写在那一集的 README。要改约定先改这里。写法见 [系列](../../docs/guides/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | 待首集确定 |
| 结构（建议） | 一个可以感知的现象 → 涉及的部件与物理原理 → 各项指标之间的取舍 → 厂商的典型做法 → 小结 |
| 演示与取证 | 结构与参数以厂商技术资料、维修手册与公开的测试数据为准，逐项给出处；示意性质的图形在画面上标「示意」 |
| 视觉与声音 | 每集取自本集的讲解对象，不设系列统一的视觉与配乐（F16、F21） |
