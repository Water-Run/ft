# 老旧燃油车

把燃油车（内燃机动力）的关键系统拆开讲：一次燃烧如何变成驱动力，动力如何按需要传到车轮。面向对汽车感兴趣、没有工程背景的观众。

## 定位

| | |
|---|---|
| 讲什么 | 燃油车的关键技术：发动机的工作循环与效率、进气与增压、变速与驱动 |
| 面向谁 | 对汽车感兴趣、没有工程背景的观众 |
| 怎么讲 | 深入讲解，以科普和纠正误区为主，通俗易懂；用真实结构与厂商技术资料作取证材料，逐项给出处；示意性质的图形在画面上标「示意」；统一视觉风格与节奏 |
| 每集多长 | 5–10 分钟 |
| 语言 | 中文与英文（缺省） |

**收录的系统**（片单顺序）：四冲程循环 → 燃油喷射与点火 → CVVT → 涡轮增压 → 马力-扭矩曲线 → 变速器原理 → 变速箱群观 → 差速器与传动轴。顺序按「一次燃烧怎么发生、怎么被榨出效率、动力怎么传到车轮」排；每集独立可懂，不必按顺序看。

**与「汽车的系统工程」系列的分界**：`../automotive-systems-engineering/` 讲的是整车层面——零件之间的相互制约、碰撞安全、混动过渡。本系列专讲燃油车自身的机械与控制。变速箱群观原在那个系列，2026-10-20 移到本系列。

**与「动力总成」系列的分界**：`../powertrains/` 讲的是具体动力总成产品（EA211 DJS+DQ200、PSA EC5 与 AT8）本身；本系列讲的是通用机制，一集讲一个系统。
