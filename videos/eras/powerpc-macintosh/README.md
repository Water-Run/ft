## 设计

**A · 从机器看时代。** 用邦迪蓝侧面引出厚显像管，再切正面给 o2–o4 的找盘动作留出时间。A1 用当年印刷品的衬线标题与大片留白；A2 让五色实物并排，颜色直接回答 c8–c10；到 g2–g5 切为黑底无衬线与金属穿孔的特写。物件原图、缩放方式与许可见 [视觉材料](research/MATERIALS.md)。

**B · 从桌面看换芯。** 同一只手在不同系统上双击。b4–b10 借 System 7 的线条窗追一次旧指令，a2–a9 借 Aqua 的透亮按钮和 Dock 解释 Classic，e3–e8 在 Intel Mac 同一窗口并列比较通用版与翻译的路径。三张都标为示意。可以选 A 作为全片主线，在机制段采用 B；最后选择以策划者原话为准。

**声音。** 只给 o2–o4 做同文试听。M1 用电钢琴模仿指尖落下的轻重；M2 用三拍玻璃音和切分配五色的横移；M3 以持续低声部配 G5，高潮后收回到一枚高音。在代表段试装时把光驱托盘开合、双击后出现的窗口和风扇调速作为可听的动作落点。
