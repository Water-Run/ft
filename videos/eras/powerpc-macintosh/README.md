## 这支片子讲什么

1994 年到 2006 年初那十二年的麦金塔：1991 年 Apple、IBM、Motorola 结成三方联盟；1994 年整机换掉 68k 中央处理器；1998–2003 年用 G3、G4、G5 做出「肌肉感」；2005 年 6 月 Apple 宣布改用 Intel，2006 年 1 月第一批 Intel 机器落地。

- 观众：见过或用过那批机器的人，知道「麦金塔」就是苹果电脑，也知道后来换了 Intel，但不知道中间这十二年发生了什么。

## 写法

语体：

- 客观陈述事实，冷静、克制；不用比喻套话、口号、感叹号。
- 句子可以有画面感——写那台机器摆在谁的桌上、开机时是什么声音，比写「性能大幅提升」更管用；但冷静克制不变：不喊口号、不堆形容词，事实与出处照旧一条不落。
- 不用第二人称，不用「请」等敬语，不写问候与情绪词。
- 短：一句旁白不超过一行字幕——中文不超过 26 字宽（汉字算 1，拉丁字母与数字算 0.5）；标签不超过 12 字。
- 数字、拉丁字母与汉字之间留一个空格：1994 年、PowerPC 601、1 GHz。
- 术语全片写法统一；第一次出现就用一句话讲清它是什么、为什么需要。先给现象再给名字：「换掉 68k 的那颗新芯片」先说这个，再叫它 PowerPC；「片上做多媒体运算的那块电路」先说这个，再叫它 Velocity Engine；讲 1 GHz 前端总线，先说「一条总线一次能搬多少数据」再给数字。
- 不写制作者口吻的自我说明：正文里不出现「二手来源，仅作交叉印证」「据 Apple 新闻稿」「本片不展开」这类取舍说明。出处由画面上一行小字署名承担。
- 不出现「上一期」「本系列」「这是第几集」。

结构与节奏：

- 开头 5 秒要有钩子：一个具体的现象、一个反差、一个问题，或那个年代里的一个具体时刻。
- 结论句之后留 0.6 秒以上停顿；换话题处留 0.7–1.1 秒；镜头要移到下一站时，把上一句的 gap 留够镜头走完的时间。
- 每章末尾一句交出下一问。
- 讲「更快」「更强」要说明和什么比、口径是什么。64 位是处理器能力，不等于当时的系统就能用满。

读法（写进 SAY 表）：

- 字幕写正式拼写，读法只写在 SAY 表或 tts 字段里。
- 至少处理：PowerPC、68k、PowerPC 601、Velocity Engine、Mac OS X、Developer Transition Kit、Intel Core Duo、G3/G4/G5、Otellini。
- 长词写在前面；缩写要逐字母读时，字母之间加空格。
- 拿不准的读法不要瞎猜：写一个稳妥的读法，并列进「待决问题」。

片尾：

- 只上画面，不配旁白，也不进正文：cue 写成 ['credits', null, { pause: 10, credits: true }]。
- 署名、模型分工、开源链接不写进任何一句旁白。

## 视觉系统

<!-- 颜色、字体、图形语言、转场；全片保持的约定（同一个图形只有一个含义）。 -->
<!-- 使用的参考作品、来源、借鉴方法与本片的设计选择；未使用外部参考则写明。不得直接抄袭现成产品。 -->

本系列约定**不维持统一的系列视觉**（见 `videos/eras/README.md`「视觉」一栏）：每一集的视觉贴合那个年代实际的设计语言。本片由策划者追加了明确要求（2026-10-21）：

> 设计风格需要严格符合那个年代的苹果风格。

### 这条要求怎么算做到

「那个年代」= 1994–2006 年这十二年，那十二年里 Apple 换过两套工业设计与两套界面语言。可检查的判据：

1. **每个视觉元素都要能追到 Apple 自己当年的材料**，出处与取法见 `research/MATERIALS.md`（iMac G3 五色机身、Power Mac G5 与 MacBook Pro 的铝壳、1994 年 Power Macintosh 小册子里的产品与界面、68k 同期机型、Mac OS 8/9/X 的菜单栏与窗口、开机灰色 Apple 标志）。追不到出处的元素不画。
2. **不做「像那个年代」的现代设计**：不用现在的扁平卡片、圆角面板、渐变光斑、通用衬线大标题；不用今天 macOS 的界面截图；不把 Macintosh 当成一个抽象的苹果符号。
3. **界面的年代跟着片子走**：本片从 System 7 讲到 Mac OS X，界面语言要能分出先后；同一个图形在全片只有一个含义，不换喻。
4. **4–6 分钟的体量下更要一眼认得出**：每章的主画面要能单帧认出是那批麦金塔（F18），不是靠字幕说明。

### 已经定下来的闸门调整

| 项 | 原值 | 现值 | 理由 |
|---|---|---|---|
| `check.style.flat` | `true`（模板默认） | `false` | 当年那套设计语言本身用阴影、斜面、渐变与条纹（Aqua 窗口、菜单栏、金属机身的反光）。平涂规则会把「严格符合那个年代」挡在门外。按 `docs/standards.md` 第 2 节末段：讲解对象自己的视觉语汇要求某种做法时，以对象为准并相应调整 `check.style` |
| `check.style.no_emoji` | `true` | `true`（不变） | 与年代无关 |
| `check.style.palette` | 未设 | 仍未设 | 当年的界面与机身照片都经压缩与色彩管理，凭记忆写 hex 无法复查。制作方从 `research/MATERIALS.md` 列出的官方图片取样，把实际色值与来源写回该文件，再据此定稿 `palette` |

### 制作方要定的，本 README 不替它定

配色、字号阶梯、图形语言、转场、每章主画面的具体做法，按 `docs/guides/visual.md` 由制作方在第 4 步定稿，写进本 README 的「设计」一节。准备方只提供材料与约束（`research/MATERIALS.md`），不给方案。

### 字型的一个现实问题

`kit/assets.json` 目前只有 Noto Sans SC、Noto Serif SC、Inter、JetBrains Mono、VT323 五款（都是 OFL 许可）。当年的系统字型是 Charcoal（Mac OS 8/9）与 Lucida Grande（Mac OS X 拉丁文），仓库里没有；要用得请维护者往 `kit/assets.json` 增补字体文件与校验和（准备方不能改 `kit/`）。未增补时只能用现有字体近似当年的字面气质，并在本 README 写明这是近似，不要让观众以为那就是 Charcoal。

### 原创边界

不抄现成成品：Apple 自己的标志、界面、产品照可以展示并注明出处（这是本片的讲解对象本身），但版式、构图、分镜与动效按本片内容重新设计，不逐像素复刻任何现成页面或宣传片。

## 与「电子发展史」系列的分工

「电子发展史」（`videos/silicon-history/README.md/`）按厂商与产品线梳理：每一代改了什么、为什么这样改、结果如何，指标口径全系列统一，配统一视觉。该系列的《苹果的芯片自研之路》讲的是苹果芯片**产品线本身**的演进。

本片在「过去的电子时代」系列，讲的是同一个时代**在当时是什么样子**：1991–2006 这十二年里麦金塔的产品形态、竞争位置、行业文化，以及为什么在 2006 年被换掉。两边的分界：

| | 电子发展史 | 本片 |
|---|---|---|
| 讲什么 | 逐代产品的架构、工艺、关键指标 | 那批机器长什么样、当时的人怎么用它、它在产业里站在哪一边 |
| 依据 | 芯片手册、数据手册、官方规格 | Apple 官方新闻稿与历史材料、Apple 支持站技术规格、产品本体与界面语言 |
| 视觉 | 统一视觉风格 | 本系列特例：贴合 1990 年代末到 2000 年代初的麦金塔本体（半透明彩色外壳、铝制一体机、Aqua 界面） |

不互相照搬：本片不复述《苹果的芯片自研之路》里按型号排列的参数表，也不复用该系列的图表与时间线画法；「过去的电子时代」系列讲体感、竞争格局与文化。

## 与系列内其他集的关系

本系列的中文定名是「过去的电子时代」（2026-10-21 策划者定，见 `videos/eras/README.md` 与 `videos/catalog.json`）。系列约定**各片之间没有承续关系**：不设系列统一结构，不设系列统一配乐与统一音色，不出现「上一集」「本系列第几集」。本片的章节结构、旁白语气与声音设计由本片自己定，不套用其他集的做法。

本片片名不含系列名，就叫《PowerPC 时代的麦金塔》。

《英特尔的酷睿年代》是另一条时间线上的片子（2006–2024 的 PC 侧），与本片的交点是 2006 年这一次换芯。两集各自独立可懂，不互相引用编号；本片讲「换掉的一方」，那一集讲「接上的一方」。
