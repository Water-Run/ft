# 过去的电子时代

每集讲一个已经过去的技术时代：那个年代的技术面貌是什么、为什么是那样、又怎样被下一个时代取代。

各集之间没有承续关系：可以先看《CRT 一统天下的时代》，也可以从《PowerPC 时代的麦金塔》看进去，每一片都自带背景、独立成立。

## 定位

| | |
|---|---|
| 讲什么 | 以前的电子软硬件的某个时代：那个年代的技术面貌、为什么是那样、怎样被下一个时代取代 |
| 面向谁 | 见过那些年代的老设备、对那个时代有兴趣的观众 |
| 怎么讲 | 重视历史与文学：把观众带进那个 Era 再说服人。开场从那个年代里的一个人、一台具体的机器或一个具体的时刻入手，句子可以有画面感；事实与出处照旧一条不落，不喊口号，不写成产品说明书。视觉与配乐每集取自本集的讲解对象（见下方「视觉」） |
| 每集多长 | 5–20 分钟，视内容而定 |
| 语言 | 中文与英文（缺省） |

## 共同约定
各集真正共享的约定记在这里，一项一行。视觉与配乐默认每集取自本集的讲解对象（经验规则 F16、F21），除非下面写明了策划者的决定；某一集的设计决定写在那一集的 README。要改约定先改这里。写法见 [系列](../../docs/guides/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | **片名不含系列名。** 每集标题自足，单独看就是一个话题：《PowerPC 时代的麦金塔》《DOS 时代的 Windows》《CRT 一统天下的时代》。命名式样是「<主题>时代的<对象>」或同等的时间感命名；不写「过去的电子时代·××」这类带系列名的标题 |
| 独立 | **各片之间没有承续关系。** 不设系列统一结构，不设系列统一配乐与统一音色，不出现「上一集」「本系列第几集」；每片自带背景，单看一遍就懂（F10）。有交点的两集（如《PowerPC 时代的麦金塔》与《英特尔的酷睿年代》）各讲各的，不互相引用编号 |
| 共同的问题 | 每集问同一个问题：那一年代的机器为什么长成那样，又怎样被下一个时代取代 |
| 叙述 | 重视历史与文学，沉浸进那个 Era。从具体的人、具体的机器、具体的时刻进入；行文不做条目罗列。事实与出处一条不落（记在各片 `research/FACTS.md`），口径限定该说时说 |
| 视觉 | **特别约定：本系列不维持统一的系列视觉。** 每一集的视觉贴合那个年代实际的设计语言与观感——DOS 时代的字符界面、Win8 平板的方块磁贴、CRT 时代的辉光与扫描线，都以史料为据还原（示意画面按规定标「示意」）。连续性体现在讲法与观感上，不在配色与部件上 |
| 声音 | 每集按那个年代的消费电子气质单独设计，不设系列统一配乐（F06、F17） |
