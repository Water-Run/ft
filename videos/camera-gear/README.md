# 摄影器材

讲相机里几个关键部件的工作原理与演变：感光元件、镜头、快门。

## 定位

| | |
|---|---|
| 讲什么 | 摄影器材的机械原理：感光元件、镜头、快门这类部件怎样工作、怎样演变 |
| 面向谁 | 玩过相机、想知道里面怎么动的观众 |
| 怎么讲 | 深入讲解机械原理本身，技术向的摄影科普；参数与结构逐项给出处；统一视觉风格与节奏 |
| 每集多长 | 5–10 分钟 |
| 语言 | 中文与英文（缺省） |

## 共同约定
各集真正共享的约定记在这里，一项一行。视觉与配乐默认每集取自本集的讲解对象（经验规则 F16、F21），除非下面写明了策划者的决定；某一集的设计决定写在那一集的 README。要改约定先改这里。写法见 [系列](../../docs/guides/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | 待首集确定 |
| 结构（建议） | 这个部件做什么 → 工作原理 → 关键参数及其对成像的影响 → 技术演进 → 选择时的取舍 |
| 演示与取证 | 光路与机械结构按真实产品的公开资料绘制；参数对成像的影响尽量给出实拍或可复算的例子 |
| 视觉与声音 | 按本页定位保持系列视觉风格与节奏；首集将实际共用的版式与节奏约定写回这里。各集的图形取自自身对象、配乐按内容设计，不把上一集的具体方案当作模板（F16、F21）。 |
