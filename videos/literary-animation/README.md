# 文学作品动画化

把一部文学作品做成动画：作品本身是主角，画面跟着原文走。策划者 2026-10-20 新开这个系列，原话：「新增系列: 文学作品动画化. 包括蛋, 项脊轩志」。

## 定位

| | |
|---|---|
| 讲什么 | 一集一部文学作品（短篇小说、散文等），把作品本身做成动画 |
| 面向谁 | 待首集确定 |
| 怎么讲 | 待首集确定：以原文朗读为主线，还是改编之外另加讲解，由策划者定 |
| 每集多长 | 待首集确定 |
| 语言 | 中文与英文（缺省）。古文作品的英文版用哪一种译文，各集开工时定 |
