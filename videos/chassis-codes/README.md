# 底盘代号与车型发展史

每集讲一个品牌的底盘代号体系：代号怎样编排、各代平台与车型怎样沿革。面向认得车、想理清代号与世代关系的观众。

## 定位

| | |
|---|---|
| 讲什么 | 汽车知识科普：一个品牌的底盘代号体系与车型沿革 |
| 面向谁 | 认得车、想理清代号与世代关系的普通观众 |
