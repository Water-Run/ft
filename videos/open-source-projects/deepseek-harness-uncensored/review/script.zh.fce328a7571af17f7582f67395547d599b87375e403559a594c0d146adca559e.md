### open · 无章节卡

这，是一个 DeepSeek Harness，DSH 现在它黑化了 成了 DeepSeek Harness Uncensored DSHU 多了一个 Uncensored 多了开箱即用的破甲体验 更自由的探索未至之境

### box · 01 开箱即用

先说最要紧的：破甲提示词直接内置了 装好，填上模型的凭据，就能用 不用再到处找提示词，也不用自己改配置 破甲这部分，用的是 dsh-purge 的成果 具体是它还在用 MIT 许可时的那一版 DSHU 的源码，基于官方的 DeepSeek Harness 0.2.2-rc.5 但它跟官方版是分开的 程序目录、配置、会话、更新渠道，都各管各的 两个装在同一台电脑上，谁也不碍着谁

### modes · 02 四种模式

新建会话的时候，输入框上面能选模式 一共四种：缺省、网安、逆向、写作 破甲是四种模式共用的 不一样的是，每种模式带的工具、手册和资料 手册也是用到哪本读哪本，不会一上来就把上下文塞满 每种模式还有自己的颜色，蓝、红、绿、黄 选了哪种，标题、侧栏和按钮就跟着换色 不过第一条消息发出去，模式就定下来了 这样聊到一半，工具和手册不会突然全变

### default · 无章节卡

缺省模式就是平时用的，写代码、修 bug 都在这 你把需求丢给它，它自己找位置、改代码、跑验证 做完会告诉你改了哪些文件、跑了哪些检查 哪些没跑，也给你标出来

### security · 无章节卡

网安模式，做安全审计和渗透测试 里面有七类现场手册，按调查的阶段来用 目标、证据、发现都记进*案件*，最后能整理成报告 还可以开*独立代理*，让访问目标的流量走你指定的代理 模型请求和登录这些，还是走原来的网络 第一次进网安，要先读一遍责任说明 软件不会帮你判断目标有没有授权 所以，只在授权范围内用

### reverse · 无章节卡

逆向模式，用来拆程序、二进制、文件格式和协议 结论要落到地址、偏移，或者实际跑出来的现象上 猜的和验证过的，分开写 REA 6.9.0 是内置的，不用另外装 想用 Ghidra、IDA、Hopper 这些，也能接进来 清点样本的时候只读字节，不会去运行它

### writing · 无章节卡

写作模式，写你想写的东西，小说、剧本、长文都行 人物、设定和文风卡放在 story 目录里 勾上哪些，哪些才会发给模型 一张*文风卡*，从六个方面描述一种文风 措辞、句法、节奏、意象、对白、结构 这个模式里没有终端，也不跑代码，就专心写 哦对了，现在对话也能删掉了 会先停下任务，再把旁问、随问和子会话一起删干净 工作区里的文件不会动

### asides · 03 通用增强

下面这些，哪种模式都能用 主线正在跑一个长任务，你突然想问点什么 不用等它停 输入 /side，右边会开一个*旁问* 它知道主线已经做完了哪些 你可以接着聊方案、追问细节，也能发图 只想问一句进度，就用 /btw，这个叫*随问* 主线正在跑的那一步，它也看得到 但它只读，不改文件也不跑命令，答完就收 不管是旁问还是随问，主线都不会停 打字停一下，输入框里会冒出灰色的后半句 按 Tab 就收下

### spend · 无章节卡

左下角一直挂着账户余额 现在是高峰还是低峰、多久以后切换，也写在这 每个对话花了多少，输入框下面就有 点一下金额，还能看这个对话的费用曲线 要是你用惯了各种 Coding Plan，喜欢盯着额度百分比 DSHU 也给你准备了经典的 5 小时和周限额 一共六档，从十五分钟到三十天 每档单独开关、单独设金额，默认都关着 额度用完，对话会暂停，还会告诉你大概什么时候恢复 开了自动恢复，额度一回来就接着跑 这些都是本地估算，不是账单

### memory · 无章节卡

另外还有跨对话记忆 偏好和项目约定存一次，以后的对话自己会去找

### outro · 无章节卡

DSHU 以 GPL-3.0-or-later 开源在 GitHub 安装包有四个平台 Windows x64、Linux x64 Linux ARM64 和 macOS ARM64 都在 GitHub 的 Release 页面 更自由地，去探索未至之境
