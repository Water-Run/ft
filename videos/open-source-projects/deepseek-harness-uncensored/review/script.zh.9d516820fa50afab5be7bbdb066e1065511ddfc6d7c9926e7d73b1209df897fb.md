### open · 无章节卡

这，是一个 DeepSeek Harness 现在它黑化了 成了 DeepSeek Harness Uncensored 多了一个 Uncensored 更自由的探索未至之境

### box · 01 开箱即用的破甲体验

DSHU 沿用 dsh-purge 早期的 MIT 版本 直接内置了破甲提示词，开箱即用 不用再到处找提示词，也不用自己改配置 现在 DSHU 的源码，基于官方的 DSH 0.2.2-rc.5 但它跟官方版是分开的 程序目录、配置、会话、更新渠道，都各管各的 可以独立并存

### modes · 02 四种模式

新建会话的时候，输入框上面能选模式 一共四种：缺省、网安、逆向、写作 破甲是四种模式共用的 不一样的是，每种模式带的工具、手册和资料 每种模式有自己的颜色，蓝、红、绿、黄 选了哪种，标题、侧栏和按钮就跟着换色 默认情况下，第一条消息发出去、对话建好以后 模式就固定下来了，不能改变 这样聊到一半，工具和手册不会突然全变

### default · 无章节卡

缺省就是默认 缺省模式，就是平时日常开发、调试之类的模式 其实啥都能干，作为通用模式 你不知道选什么的时候，选这个就行

### security · 无章节卡

网安模式，做网络安全审计和渗透测试 里面有七类现场手册，按调查的阶段来用 目标、证据、发现都记进案件，最后能整理成报告 还可以开独立代理，让访问目标的流量走你指定的代理 再套一层马甲 当然这只是一个实验功能，不要过于依赖 第一次进网安，要先读一遍责任说明 你自己要确保目标是有授权的，否则后果自负

### reverse · 无章节卡

逆向模式，内置 REA 用来拆程序、二进制、文件格式和协议 如果你想用 Ghidra、IDA、Hopper 这些，你也能接进来

### writing · 无章节卡

写作模式，写你想写的东西 你可以把人物、设定和文风卡放在 story 目录里 并勾上你这次想要用到的 这个模式里没有终端，也不跑代码，就专心写 哦对了，现在对话也能删掉了

### asides · 03 通用增强

DeepSeek Harness Uncensored 还提供了 一系列便于使用的通用增强 主线正在跑一个长任务，你想搞明白进度如何 直接 /btw，这叫随问 和 Claude Code 的 /btw 类似 主要用来问各种简单的一次性小问题 输入 /side，右边会开一个旁问 这个则类似于 Codex 的 /side 在旁边打开一个同步的对话 自动跟进主线已经完成的进度 你可以用 /clear 清理对话 也可以设成关掉旁问时自动清理 DSHU 另外引入了可选的输入预测功能 打字停一下，输入框里会冒出灰色的后半句 按 Tab 就能收下

### spend · 无章节卡

进入页面，你会发现左下角一直挂着账户余额 现在是梁文峰还是梁文谷、还有多久 设置里还有总余额的变化曲线，鼠标悬停就能读数 具体到每个对话花了多少，你可以在会话的底部查看 要是你用惯了各种 Coding Plan 感觉没有额度百分比很不舒服 对于有这种癖好的用户 DSHU 也带来了经典的 5 小时和周限额 还不满足的话，还有更多限额可选 给自己上一些防沉迷控制

### memory · 无章节卡

对了，DSHU 还有跨对话记忆 偏好和项目约定存一次，以后的对话自己会去找

### outro · 无章节卡

DSHU 以 GPL-3.0-or-later 开源在 GitHub GitHub Release 上的安装包准备了四个平台 Windows x64、Linux x64 Linux ARM64 和 macOS ARM64 DSH 是 TypeScript 写的，你当然也可以自己打包一个 DeepSeek Harness Uncensored，更自由的探索未至之境
