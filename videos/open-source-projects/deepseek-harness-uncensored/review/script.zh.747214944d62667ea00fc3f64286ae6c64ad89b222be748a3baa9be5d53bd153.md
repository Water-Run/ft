### open · 无章节卡

这，是一个 DeepSeek Harness，DSH 现在它黑化了 成了 DeepSeek Harness Uncensored DSHU 多了一个 Uncensored 多了开箱即用的破甲体验 更自由的探索未至之境

### box · 01 开箱即用

DSHU 是一个开源的桌面智能体工作台 源码基于官方 DeepSeek Harness 0.2.2-rc.5 破甲提示词已经内置，装好就能用 不用再自己找提示词、改配置 破甲这部分，用到了 dsh-purge 项目的成果 用的是它以 MIT 许可发布的那一版 它也不会挤掉你已经装好的官方版 DSHU 有自己的程序目录、配置、会话和更新渠道 两个装在同一台机器上，互不影响

### modes · 02 四种模式

新会话的输入框上方，有一个模式菜单 缺省、网安、逆向、写作，一共四种 四种模式共用同一套破甲提示词 区别在于各自带哪些工具、工作手册和资料 手册按需加载，用到哪本读哪本 每种模式有自己的主题色：蓝、红、绿、黄 会话标题、侧栏色条和按钮，都跟着变 第一条消息发出之后，模式就锁定了 免得做到一半，工具和手册全换掉

### default · 无章节卡

缺省模式，管日常使用和通用开发 交给它一个需求，它自己定位、修改、验证 最后告诉你改了哪些文件、跑了哪些检查 没跑的，也会标出来

### security · 无章节卡

网安模式，用于安全审计和渗透测试 应用审查、配置检查、问题复现、修复验证 七类现场手册，按调查阶段取用 目标、证据和发现都写进*案件*，最后整理成报告 打开*独立代理*，访问目标的流量从你指定的代理出去 第一次进入网安，要先读完责任说明 软件不会替你判断目标是否已获授权 请只在授权范围内使用

### reverse · 无章节卡

逆向模式，分析程序、二进制、文件格式和协议 结论要落到地址、偏移或运行观察上 推测和已验证的内容，分开写 内置 REA 6.9.0，装好就有，不用另装 Ghidra、IDA、Hopper 等引擎，按需接入 样本清点只读字节，不执行样本

### writing · 无章节卡

写作模式，写你想写的东西：小说、剧本、长文 人物、设定和文风卡，放在 story 目录下 只有勾选的资料，才会发给模型 一张*文风卡*，用六条轴描述一种文风 措辞、句法、节奏、意象、对白、结构 写作模式不挂终端，也不挂代码执行工具

### asides · 03 通用增强

四种模式之外，还有几项日常用得上的增强 主线正在跑一个长任务，你突然有个问题 不用等它停下来 输入 /side，右侧打开一个*旁问* 旁问接着主线已经完成的进展聊 讨论方案、追问细节，还能附图 只想问一句进度，就用 /btw，这叫*随问* 随问读取主线的实时状态，连正在跑的那一步也算 它只读，不改文件、不跑命令，回答一段就收 旁问和随问，都不打断主线 停下打字一会儿，输入框里会出现灰色的后半句 按 Tab 采用，不合适就接着打

### spend · 无章节卡

侧栏常驻账户余额 并标出现在是高峰还是低峰，离下次切换还有多久 如果你习惯了各种 Coding Plan，爱看额度百分比 DSHU 也带来了经典的 5 小时和周限额 一共六档，从十五分钟到三十天 每档单独开关、单独设金额，默认全关 额度用完，对话自动暂停，并给出预计恢复时间 打开自动恢复，额度回来就接着跑 这些都是本地估算，不是账单

### memory · 无章节卡

说过一次的事，不用每个新对话再说一遍 项目约定、个人偏好、做过的结论，都能存成*记忆* 每条记忆有作用范围：全局、某个工作区或某种模式 不会串到无关的对话里

### outro · 无章节卡

DSHU 以 GPL-3.0-or-later 开源 安装包覆盖四个平台 Windows x64、Linux x64 Linux ARM64 和 macOS ARM64 在 GitHub 的 Release 页面下载 更自由地，去探索未至之境
