# 开源项目

每一集介绍一个开源项目：它解决什么问题、谁会需要它、一次真实任务怎么走、它背后怎么做到、代价与边界在哪。面向想用这个项目、或想看它怎么写的人。

## 定位

| | |
|---|---|
| 讲什么 | 一个开源项目：它是什么、解决什么问题、怎么用、怎么实现、边界与代价 |
| 面向谁 | 听说过这个项目但没动手的人；想用却没有头绪的人；想看它怎么写的人 |
| 怎么讲 | 一次真实任务贯穿：先把项目是什么交代清楚，再走完一遍真实使用，然后拆它内部的实现；不写成功能清单或更新日志 |
| 每集多长 | 3–8 分钟，按项目的实际体量定 |
| 语言 | 中文与英文（缺省） |

## 共同约定
各集真正共享的约定记在这里，一项一行。视觉与配乐默认每集取自本集的讲解对象（经验规则 F16、F21），除非下面写明了策划者的决定；某一集的设计决定写在那一集的 README。要改约定先改这里。写法见 [系列](../../docs/guides/series.md)。

| 项 | 约定 |
|---|---|
| 标题 | `<项目名>：<一句话讲清它是什么>`，例如「luainstaller：把 Lua 脚本交给没有 Lua 的人」 |
| 结构（建议） | 它是什么、谁会需要它 → 一次真实任务（真实输入、真实输出） → 内部怎么做到 → 边界与代价 → 小结 |
| 演示与取证 | 同一项任务贯穿各集，屏幕上出现的命令与输出必须原样出自 `research/lab/` 的回显；项目自己的文档、界面与产物是主要取证材料 |
| 视觉与声音 | 各片视觉取自项目自己的界面、文档与产物（对应 F16），不共用一套版式；连续性体现在结构与讲法上 |
| 术语与读法 | 同一批术语（项目名、命令行参数、依赖）在各集写法与读法一致；英文原名首次出现时给出原文 |
