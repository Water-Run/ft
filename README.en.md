# ft

ft is the source repository of explainer videos and project introduction videos made by large language models, together with the toolchain that turns those sources into finished films. The name is the picture itself: a film is a pure function of time, and any frame is f(t). Each video is an HTML animation whose only input is the time t: the narration is synthesized sentence by sentence, on-screen actions are anchored to the word boundaries of the narration, headless browsers render frames in parallel, and ffmpeg encodes and packages the result. Films are 1920×1080 at 60 frames per second; unless stated otherwise, each one is produced in Chinese and in English.

[中文](README.md)

The documentation under `docs/` is written in Chinese; the Chinese text is the reference version.

## Layout

| Path | Contents |
|---|---|
| `videos/standalone/<video>/` | Standalone videos: narration script, scene sources, research material, configuration |
| `videos/series/<series>/<video>/` | Videos that belong to a series; each series has its own guide |
| `videos/catalog.json` | The catalog: every delivered and planned video |
| `kit/engine/` | The timeline engine: tweens, frame functions, camera, captions, sound-effect registration |
| `kit/tools/` | Tools: narration, frame inspection, scanning, the gate, mixing, rendering, packaging, covers, environment check |
| `kit/template/` | Skeleton of a new video, bilingual by default |
| `kit/delegation/` | Brief skeleton for delegated production |
| `docs/` | Workflow, quality standards and topic documents |
| `assets/` | Binary dependencies such as fonts and the speech-recognition model; not tracked, fetched by a tool |

Finished films, narration caches and intermediate render files are not tracked.

## How it works

- **The picture is a pure function of time.** No CSS animations, timers or callbacks; a given moment looks the same whether it is reached by playing forward or by jumping straight to it. Any frame can therefore be rendered independently, and several browsers can each render a segment that is later concatenated.
- **The narration sets the timing.** Each sentence is synthesized on its own, returning its duration and the moment every word is spoken. Animation times are written as "when this word of this sentence is spoken", so the picture rearranges itself when the script changes. One set of scene code can thus serve several languages.
- **Every fact has a source.** Each fact shown or narrated is recorded in the video's `research/FACTS.md`; bytes, numbers and terminal output on screen are generated by scripts from experimental data.
- **Checks are done in text.** The tools describe any frame as "the elements visible at this moment, with position, font size, colour and text", and use that to check overlap, contrast, out-of-frame content, empty screens, stillness and determinism. A model that cannot see the picture can work from the same output.
- **Sound is synthesized by code.** Music and sound effects use no external material; mixing is deterministic.
- **Two ways of producing a video.** Self-made: one maker carries the work from research to the finished film. Delegated: a preparer supplies research, narration, the visual system and a brief, and another model completes the scenes and the finishing steps.

## Quick start

Requirements: Node.js 22.12 or later, Chrome, ffmpeg with libx264, Python 3 (`edge-tts`, `numpy`). See [docs/environment.md](docs/environment.md).

```bash
npm ci                                   # dependencies
node kit/tools/assets.js --fetch         # fonts
node kit/tools/doctor.js                 # environment check

V=videos/standalone/luainstaller
node kit/tools/timeline.js $V            # timeline
node kit/tools/look.js     $V a6         # the frame at the end of sentence a6: text description and screenshot
node kit/tools/check.js    $V            # the production gate

node kit/tools/tts.js    $V              # synthesize narration (needs network access)
node kit/tools/audio.js  $V              # mix
node kit/tools/render.js $V              # render
node kit/tools/finish.js $V              # package the finished films
node kit/tools/covers.js $V              # covers
```

Creating a video:

```bash
node kit/tools/new.js standalone/<video> --title "中文标题" --title-en "English title"
node kit/tools/new.js series/<series>/<video>          # an entry already in the catalog
```
